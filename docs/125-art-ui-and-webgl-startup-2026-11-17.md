# PETSHOP 美术、界面与 WebGL 启动交接

更新于 2026 年 11 月 17 日。完整玩法、数值、操作和工程入口见[当前完整内容](124-current-game-content-2026-11-17.md)。这里记录角色重制、全地图美术、暖色界面及第一章试玩的灰屏修复。

## B 版 3D 人物

- 主角采用概念 B 的微缩人物方向。最终比例以概念图为准，保留自然肩宽、躯干与腿的比例，缩短手臂及手的垂落距离。发型、眉眼、面部轮廓、橙棕短袖、领口、胸袋、短裤和鞋分别建立轮廓与材质。随角色姿势与穿衣状态切换相应部位。
- 先制作手机店员、程序员同学、花店女店主和运动教练四个专属样例，然后将同一形体和材质标准接入通用 NPC。固定人物根据身份选发型、体形、肤色与服装风格，路人按稳定组合选择变体。制服、工装、日常外套、运动服、短裤、长裤和裙装共用模块与配色系统。保留固定 NPC 的身份、立绘和关系数据。
- `PlayerCharacterModel` 读取并缓存 `Resources/Characters/PlayerB-*.bytes` 的网格。 `NaturalFigure` 负责人物组合，`CityNpcClothing` 负责按身份和天气配衣，`FigureMotion` 驱动人物动作。柔和哑光材质使用 `PlayerSoftClay.shader`。运行入口涵盖街道角色、店内人物及适用的预览和现场活动。
- 源网格生成工具在 `tools/sculpt_player_b.py`、`tools/sculpt_npc_b.py`、`tools/sculpt_npc_neighborhood.py` 和 `tools/sculpt_npc_wardrobe.py`。专属样例使用独立资源，其余人物以共享模型组合区分。

## 暖色界面

- 主场景上叠加暖白和浅陶土面板，顶部、出行底栏及场地操作条采用深橄榄灰。琥珀色标识当前选中状态和主要操作，绿色表示完成或收益，砖红色表示风险与退出，灰蓝用于信息。PETSHOP 封面仍按比例覆盖主菜单。
- `Ui.FlatSkin.cs` 与 `Ui.cs` 提供共用的面板、按钮、行、选中、禁用、输入、页签、下拉及进度显示。库存、采购、货车和场地等界面使用语义色，便于区分缺货、预算提示与可操作项目。
- 覆盖常用 HUD、任务和提示、家居／工作台、店务、顾客与员工、个人／NPC／通讯录、日程和结算、中介与资产、账本与证券、活动和小游戏。原有功能入口及玩法按[当前完整内容](124-current-game-content-2026-11-17.md)执行。

## 第一章 WebGL 试玩与启动内存

- 试玩范围仍限城郊。开业五家城郊门店、自有现金达到 ¥1,000,000 并结清贷款后，等待主线邀请，找齐三页商铺图后当面交给唐蔚。交付后显示试玩完成，可以继续在城郊经营。社区、公园和花园保持锁定。
- Unity Play 旧构建已下载资源并进入引擎初始化，随后申请约 295 KiB 的 `VertexData` 时报告内存分配失败。当时 `ALLOC_GFX` 已用约 580 MiB，之后出现 `RuntimeError: null function`。这是该次灰屏的直接证据。首次下载大小及 JavaScript 解压另外影响正常加载时间。
- 试玩启动先建立 UI 并显示主菜单。选择「新游戏」或「读档」后显示「正在布置城郊街区…」，给浏览器一次绘制机会，再建立场景和会话。该提示为加载状态，无百分比。正式版继续使用原有完整场景初始化。
- 试玩渲染从玩家住处出发，沿现有图搜索可达路网，在检查点截断区域。根据当前地图配置，城郊连通部分包含 281 个道路节点，全图有 1,074 个节点。运行时只生成该范围的交互建筑、路面、门前铺装与靠近城郊的细节。保留必要的远景底面、水面及边界设施。核心地图、任务和存档数据沿用既有规则。
- 本轮主要减少启动阶段生成的三维网格。构建仍使用 `PCSHOP_FIRST_CHAPTER_TRIAL`、Gzip 和浏览器解压回退，未在这轮实现资源下载裁剪。
