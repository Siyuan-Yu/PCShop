# 最高售价倍率提高到3倍（2026-11-02）

本次把此前限制为1.6倍的调价入口统一放宽到3倍，并取消普通商品购买意愿的5%保底。玩家可以坚持高价，靠在岗销售员、服装镜子或餐馆饮料加成争取成交，也可能因购买意愿为0而卖不出去。

## 定价与成交

- 店内统一加价、配件/普通商品独立倍率、单品金额调价、家中工作台远程调价：上限共用 `ShopSettings.MaxMarkup = 3`，原0.9倍下限不变。
- 餐馆菜单同样最高3倍，保留0.8倍下限，已下单的菜价不追溯修改。菜单显示购买意愿，新顾客是否点单使用与预览一致的基础价格曲线及本店有效销售员加成。
- 配件金额按当前市场价（盒装含原包装溢价）、普通商品按当前行情参考价计算可选范围；最高金额按原有整元方式四舍五入。报价确认及读档不再截回1.6倍。
- 普通商品基础购买概率为 `clamp(0.95 - (倍率 - 1) × 1.6, 0, 0.97)`。保留原价格敏感程度，仅取消5%保底；约1.59375倍起基础概率为0。
- 有效销售员最多加25个百分点；服装镜子加5个百分点；餐馆饮料加20个百分点。原有盒装信任加成继续有效。各类加成仍按商品/店型适用条件计算，最终概率限制在0—100%，基础概率为0不禁止加成后成交。
- 旧倍率和已确认金额照常读取；新存档保留3倍统一倍率、单品倍率、确认售价和菜单倍率。行情变化仍不会主动重写已确认的绝对售价。

| 普通商品倍率 | 无加成基础购买意愿 | 有25个百分点销售加成 |
| --- | --- | --- |
| 1.0 | 95% | 100% |
| 1.25 | 55% | 80% |
| 1.5 | 15% | 40% |
| 1.6—3.0 | 0% | 25% |

表中不含电脑店附带杂货系数、盒装信任、服装镜子、模型热度或餐馆饮料加成；实际预览按对应商品计算。其他独立经营系统的参考价/报价规则不由原1.6倍上限控制，本次不改写它们。
