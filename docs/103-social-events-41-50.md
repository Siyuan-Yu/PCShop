# 随机事件 41–50：庆功、湿地训练与人物邀约

本批按确认方案实现。预约不立即认识人物或发奖励；实际到场开始活动时认识人物，完成后结算交情、属性及劳务报酬。已认识的人物仍可再次发出邀请。拒绝、改天或提前取消不扣交情；正式预约后逾期未到仍沿用已有爽约规则。

新增的高档消费项目另见 [第 104 篇](104-premium-venue-services.md)。本批专属活动使用自己的套餐、时长与付款方，不会被普通菜单替换成便宜服务。可在日程中查看约定地点、到场应付金额和伴手礼。

## 41 · 庆功饭

配置 ID `race_prize_dinner`。仅在最近一次实际正式比赛夺冠后出现，邀请该场实际具名对手，最多五位。到真实餐厅吃 90 分钟庆功宴，整桌 ¥3,000，由玩家请客，实际开始时一次扣款，不按人数重复乘价。

接受或拒绝时均不扣款、不增交情。完宴后增加到场者交情，魅力 +1。同一场胜利完成一次庆功后不能重复消费或刷奖励；中途取消后可以重新预约，重约完成也会锁定这场胜利。胜场和参与人随存档保存，旧档需再取得一次实际胜利。

## 42 · 湿地驾驶体验

配置 ID 保留 `race_track_visit_rain`，标题改为「湿地驾驶体验」。当前没有独立降雨系统，改为人工洒水训练，不伪造天气。预约当天 09:00–18:00 到城郊练习场，选择本区实际入库车辆，在接待处专属入口开始。

到场开始支付 ¥1,000，抓地力为平常 60%、制动为 80%、稳定为 90%。实际操作、碰撞、护具和电池风险沿用驾驶系统。赛道有湿地标识。完训见识 +1，退赛不发完成奖励；无普通赛事奖金、不增加正式胜场，记录独立于干地练习。维修按实际车损另付。

## 43 · 夜校同学爱好赛车

配置 ID `race_ning_study`。顾宁邀请先看一场正式比赛，不替她报名参赛。预约实际比赛日 09:00–17:00 的城郊观赛时段，免费观赛 60 分钟。到场认识，完整观赛后增加见识和交情。已认识顾宁的档仍可收到后续邀请。

## 44 · 罗师傅请你尝新菜

配置 ID `act_dinner_cook`。到罗志勇实际工作的店试菜，而不是统一去街坊餐厅。店方招待，玩家免费，用时 60 分钟。可以评价口味、分量和定价，各有对应的反馈文本；完成后增加交情和用餐效果。接受邀请不自动认识人物。

## 45 · 同桌家常馆的邀请

配置 ID `act_dinner_chef`。到杜建川实际工作的餐馆品尝招牌炖菜。店家招待，玩家免费，75 分钟。可询问炖菜故事和熟客偏好，完成后将故事加入人物经历；提前离开不解锁完成故事。

## 46 · 社区餐厅领班约饭

配置 ID `act_dinner_linhe`。约林荷下班后，19:00 起在她实际工作的餐厅吃饭交流，90 分钟。双人餐合计 ¥2,000，默认各付 ¥1,000；也可选择玩家请客，一次付全桌 ¥2,000。赴宴开始才扣款，可聊值班经历及餐厅经营。

## 47 · 农贸市场的王婶请客

配置 ID `act_dinner_farm`。到王桂芬真实住处吃家常饭，主人请客，玩家免费，90 分钟。预约同时登记她的做客邀请，仍需按实际住处和在家时段赴约。

可直接赴约，或购买 ¥1,000 的「家常臻选礼盒」。礼盒实际入背包，可保存、取放或另行赠送。带礼赴宴时从背包实际扣一份，完成后额外交情 +2。提前取消不吞掉礼盒；如果礼盒已被挪走或另送他人，到场会暂缓该份带礼预约，不额外扣餐费。礼盒也进入烟酒茶行的普通礼品目录。

## 48 · 练歌房的新歌

配置 ID `act_ktv_singer`。到温音实际工作的练歌房试唱新伴奏。两小时包间原价 ¥2,000，由店方招待，玩家免费。包含选歌试唱、合唱与伴奏反馈，完成后增加交情和魅力。

试唱结束后若想继续，必须在普通菜单自行选择下一项付费服务；不会自动续费，也不会把后续服务继续算成店方请客。

## 49 · 音响助理的调试局

配置 ID `act_ktv_fuzhi`。到傅知实际工作的场所试听设备，90 分钟，不收包间费。完整完成后 ¥1,500 劳务报酬实际入账，提前离开或取消不支付，存读档不会重复支付。

可比较人声、低频或杂音。智力低于 50 也能选，但发现专业问题的成功率为 0%；达到 50 后从 50% 起，每点加 1 个百分点，最高 100%。找到专业问题后，完成时额外交情 +2、见识 +1，每次活动最多一份发现奖励。未能定位问题不影响完整配合后的基础报酬。

## 50 · 合唱团的练习

配置 ID `act_ktv_luoya`。和罗雅、温音、傅知这些实际存在的人物预约可达的练歌房，使用双方可参加的晚间时段。排练两小时，场地和指导原价 ¥3,000，由合唱团承担，玩家免费。

包含热身、合唱和休息交流。到场认识实际团员，完成后按参与人结算交情、魅力与共同经历；之后仍可随机收到邀约。
