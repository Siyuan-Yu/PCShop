# 快餐店点餐与堂食

更新日期：2026-11-01。

## 问题与实现

好味快餐（城市布局中的 `shop08`，业务为“快餐”）此前只进入“邻居的店”通用介绍页，没有可购买商品。现在独立接入堂食菜单，保留原有打工入口；不会覆盖玩家自有电脑店、空铺、委托经营资产或出租物业页面。

进入营业中的快餐店即可选餐。每项显示价格、饱腹增量、营养、心情和用餐分钟数。点击“买一份吃”或“买一杯喝”当场扣费并吃喝，时间正常流逝，不需键盘输入，不占背包或车辆空间。餐品会先补饱腹再推进时间，避免玩家在用餐过程中仍因饥饿扣健康。原有时间流逝仍会少量消耗饱腹。

## 边界与存档

- 营业时间沿用普通街铺：每天09:00–21:00。非店内、关门、空铺、玩家自有店铺或工作中均不能点餐。
- 现金不足、未知餐品和已饱时拒绝购买，不扣费、不推进时间。
- 收支记入“餐饮”账本，注明店名与餐品；饱腹、营养、心情及现金沿用现有存档，无需新存档字段。
- 本次提供堂食，没有增加外带库存、外卖配送或餐饮经营系统。
