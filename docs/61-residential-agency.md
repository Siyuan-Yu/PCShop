# 中介商铺版与住宅版（2026-11-04）

> 后续住宅界面已按用户反馈改回片区鸟瞰选房，并增加真实住户产权与收租，当前以[第63篇](63-residential-map-and-tenanted-ownership.md)为准。本篇纯卡片及仅四档自住的说明是初版记录。

进入现有任一家房产中介，顶部新增**商铺 / 住宅**切换，不增加第二栋中介建筑。住宅入口从开局可见，不依赖“经营”系统、主店或知名度解锁。

## 玩家流程

- 商铺版保留现有鸟瞰选址、客流/商圈、户型、报价及签约流程。
- 住宅版显示当前住处和现金，按本片区优先列出四档现有住宅：城郊旧居、改善住宅、豪华公寓、花园别墅。每张房源卡显示街区、所属片区、月租和售价。
- 选择房源只查看详情，不移动、不花钱。可在该房源所属中介租住，或直接全款/按揭购买；其他片区可预览并前往对应中介，未开放的片区不能绕过主线成交。
- 交易先显示确认窗口，列出首月租金或房价/首付、搬家费、总付款、付款后现金、贷款及维护规则，再点“确认办理”。取消无影响。
- 自有住宅在同页显示剩余贷款、提前还款和出售；已有自住房须先出售后换房。目前仍只支持一处玩家自住住宅，未增加多套住宅投资系统。

## 现有数值与新的直接购房

| 住宅 | 月租 | 售价 |
| --- | --- | --- |
| 城郊老破小 | 450元 | 仅出租 |
| 宜居改善住宅 | 1200元 | 18万元 |
| 公园豪华公寓 | 3000元 | 45万元 |
| 花园独栋别墅 | 12000元 | 180万元 |

租住支付新房首月租金与500元搬家费，次月按新月租结算；重复租当前住处不会重复扣费。原有租住后买房仍可使用。

新增直接购买指定住宅，无须先租进去。不同住处购入加500元搬家费；购买当前租住住宅不再收搬家费。不额外收首月租金。例如从旧居直接全款买改善住宅支付180500元，按揭支付54500元，贷款126000元。

按揭仍为三成首付、36期等额本金、月利率0.4%，买后月租为0，月维护费为购入价0.1%。出售沿原规则按九折并结清贷款，之后继续租住。家具、冰箱食品、储物、已摆家具和存档结构沿用现有住宅系统，没有另造一套仓库或房贷数据。
