# VS1 验收说明（一个月流程）

## 怎么跑
1. Unity 2022.3.6f1 打开工程，打开 `Assets/Scenes/Main.unity`，点 Play。
2. 首次进入会弹开局说明；有存档时会问"继续 / 新游戏"。
3. 场景里只有相机、灯光、后期和一个 `Game` 物体（挂 `GameController`），其余在 Play 时才生成；如果 `Game` 上显示 Missing Script，说明脚本引用丢了，可用菜单 `PCShopSell/Create Main Scene` 重新生成，或运行 `GameSceneBuilder.VerifyMainSceneFromBatch` 校验。所有世界、灯光、UI 都由 `GameController` 运行时按 `Assets/Resources/Data/city_layout.json` 生成：所有世界、灯光、UI 都由 `GameController` 运行时按 `Assets/Resources/Data/city_layout.json` 生成。场景可用菜单重新生成（编辑器脚本 `GameSceneBuilder.CreateScene`）。

## 操作
| 操作 | 作用 |
|---|---|
| WASD / 方向键 | 街上在街道范围内任意方向自由走（W = 屏幕往上，镜头怎么转方向跟着转；走到街边会贴着边滑，进不了楼里）；在店里是老板走动；离开店铺面板也靠它 |
| 右键拖动 / Q R / V | 街上自由转视角（左右旋转、俯仰）；V 复位；进店后视角固定，出来恢复 |
| 出租屋（开局和回家都在这里） | 一间真实的破旧小屋：WASD 在屋里走；走近床 / 衣柜 / 电饭锅 / 门，头顶出现 ▼ 提示后按 F：睡觉小睡、换衣服、做饭吃饭、出门回街上；房间信息看右上角“我的”；家具要买（家具城当天 / 网购 2 天）再自己摆；屋里时间照常流逝 |
| F | 走到门口附近（6 米内）进入；头顶和左下角会提示"按 F 进入 xxx" |
| 底栏"快捷前往：去我的店 / 回家 / 电子市场" | 自动走过去并进门（途中按 WASD 随时接管）；打车只能用这个 |
| 左键地面 / 建筑 / 名牌 | 不再移动；店内点地板仍能让老板走过去 |
| 底栏载具按钮 | 切换步行 / 打车 / 小电驴 / 三轮车（买了才能用） |
| 空格、1~4、滚轮 | 暂停，1×/2×/4×/8×，缩放 |
| 店内点顾客头顶"结账"标签（或点顾客） | 收现金 |
| 右上"行情""菜单" | 行情与新闻；存档/读档/新游戏/账本/帮助 |

打开面板会暂停时间；店内右侧面板只有"柜台"页不暂停（边看店边收银）。

## 开局与目标
- 第 1 年 1 月 1 日（周一）8:00，在城中村出租屋，现金 ¥10,000，**还没有店**：先去商业街中段的「安居房产中介」租铺子（最便宜的街尾空铺月租 ¥1,500，签约付首月 + 押金 + 中介费共 ¥4,500）。开局窗口或菜单里的“作弊 / 验收”按钮可直接租下街尾小店并拿到起步货（入门内存×3、入门硬盘×3、入门 CPU×1），等于之前的 ¥5,000 开局。
- 月目标：第 30 天结算时 **净资产 ≥ ¥8,000（现金 + 店内和随身库存按市价九折）且雇过至少 1 名员工**。
- 失败：现金连续 3 天为负即破产。

## 验收清单（建议按顺序走一遍）
1. **守店结账**：走到"我的电脑店"（商业街最东头、离地铁最远），进店即开门；顾客挑货后头顶出现黄球并排队，点击结账收现金。离店就关门，店里的人会离开。
2. **定价**：店内"定价"页调加价倍率（0.9~1.6），观察成交率和流失变化。盒装比散件贵约 12%，顾客更信任；"库存"页可拆包装（不可逆，更省空间）。
3. **库存容量**：小店 40 格。盒装 1 格/件（2 公斤）、散件 0.5 格/件（重量减半），显卡和电源机箱占 2 倍。这是“后仓”；顾客只买货架上摆着的（见第 33 条）。
4. **1788 网购**：只能在店里电脑上下单（"1788"页）。开局可见 3 家店：贵但稳、便宜但次品多、价格适中靠谱。第 4 天会收到"老周电子"的推荐（更便宜靠谱），下单满 2 次会冒出"闪电优选"（看着便宜、次品率高）。运费 ¥15，次日 10:00 到店，次品自动剔除并提示。
5. **线下档口**：约 2 公里外的电子市场，工作日 9:00–18:00 营业。批发价约市价 86%，每家每天可砍价一次（看魅力，累了更难；失败当天涨 1%）。买的货进"随身货"，回到自己店自动卸货。
6. **出行**：步行 6 格、打车 15 格（起步 ¥10 含 2 公里，之后 ¥2/公里，上车先付）、小电驴 ¥1,800 / 10 格、三轮车 ¥2,500 / 40 格。车行在电子市场，9:00–19:00。商业街西头地铁站可坐地铁到市场（¥3，12 分钟）。
7. **交警**（唯一的实时玩法）：骑三轮车时，8:00–20:00 每天有 60% 概率交警上岗，在商业街和两条连接路上巡逻。地上的扇形是视线，被看到会变红并追你；躲进任意店里或拉开距离可甩掉。被追上罚 ¥200，30% 概率扣车（车行赎回 ¥500）。
8. **装机订单**：顾客偶尔下整机单（入门/主流/高端，两天内交付）。在"装机单"页凑齐 6 个配件后开装：把正确档次的配件拖进机箱对应位置，先装主板再装 CPU 和内存；拿错类别/档次/接口算失误，失误越多越耗时。交付收全款，技术 +2。超时订单作废并掉知名度。
9. **行情**：每天新闻推动三个宏观指标（币圈热度、AI 需求、新品周期），再影响各品类价格指数（0.6~1.8）。第 9 天固定有"矿潮"头条（显卡涨），第 19 天新一代处理器（CPU 波动）。看"行情"面板提前囤货或清货。
10. **生活**：饥饿和精力随时间下降；7:30 / 12:00 / 18:30 自动吃饭（¥15/顿）。只能在家 18:00–8:00 睡觉，或小憩。凌晨 4 点还没睡会晕倒，次日 12:00 在家醒来；健康过低会住院 2 天（¥200/天）。23:00 有睡觉提醒。精力低于 25 时砍价、装机都变差。
11. **雇人**：店内"招人"页贴招聘（¥50），次日 9:00 起有应聘者（日薪 ¥100~180，快手更贵）。员工 9:00–21:00 看店，你不在时店照常营业并自动结账。工资每天结算。
12. **房租**：每月 1 日扣店租 ¥1,500 + 出租屋 ¥450（第一个月已预付）。
13. **存档**：每天开始自动存档（路上不存），"菜单"可手动存/读。存档在 `Application.persistentDataPath/save1.json`，含随机数状态，读档后可复现。
14. **月底**：第 30 天弹出结算，显示是否达成目标。之后可以继续玩。

14b. **装修编辑模式**：店里“装修”页点“开始装修 / 继续摆放”进入编辑模式——镜头平滑转成 55° 斜俯视，有 1 米网格 / 0.25 米吸附、米数刻度和鼠标坐标读数；中键拖动 / Q E 转视角，V 复位；墙上的海报、LED 灯屏能点选拿起或 X 收进背包；点“完成”镜头平滑回去。关门时门头暗红、挂“休息中”牌、顶灯调暗。时间流逝比最初快 3 倍。1788 进货页可选“送到”店里 / 家里。截图 vs1_90 / 91 / 103 / 104 / 105。
14a. **租铺子送货架和收银台 + 街上的店标记**：第一次租铺子房东送 1 货架 + 1 收银台（搬店不送），钱花光也能开业；自己租的铺子门前有青色发光踏板和光柱，街上一眼认出来。截图 vs1_102。
14b. **新手任务条**：左上角常驻一条任务（黄色标题 + 一句话 + 灰色进度，只显示当前这一步，点开是这一步的详细说明；目标面板里没有任务）：租一间铺子 → 去家具城买货架 ×6 / 收银台 / 操作台 / 展示桌 → 歇业装修摆好 → 每类配件设置一个货架 → 进第一批货 → 卖出第一单 → 雇店员 → 买智能手机 → 开通收款码；做完一步飘字提示下一步，9 步全做完任务条消失。截图 vs1_84、vs1_89、vs1_92、vs1_100（点任务条的说明窗口）。
15. **店铺升级**（店内面板“升级”页只有 4 项）：开通收款码 ¥200（要先有智能手机，去手机店买；顾客更快结账）；招牌灯箱 ¥900（客流 +15%）；空调 ¥1,800（顾客更耐等）；监控 ¥600（挡住“小偷”事件）。前置未满足会用红字写明原因，钱不够按钮置灰。升级页不再卖智能手机和货架扩容：手机去手机店买，更高级的货架去家具城买（加固货架 ¥700 / 重型货架 ¥1,500，摆出来的货架越结实，每个能放的公斤数和后仓格数越多，货架外观立柱分蓝 / 橙色）；自助结账平台是任务奖励（第 365 天“站稳一年”达标送，之后升级页里显示“已拥有 · 奖励”）。截图 vs1_99（升级页）、vs1_89（家具城三档货架）、vs1_92（装好的店）。16. **随机事件**（每天 11:00 约 55% 概率触发，第 2 天起，同类有冷却）：城管检查、熟客推荐、停电（买了应急灯可以挡）、小偷、学生团购（需有内存库存）、同行低价竞争（加价过高才会触发）、捡到钱包、朋友请吃饭、借钱（75% 概率几天后还）、差评、发传单、感冒。弹出后必须选一项才能继续（窗口不能关），每个事件至少有一个无条件可选项；灰掉的选项会写明原因。
17. **衣橱与住处**：衣服只能网购（衬衫 ¥280 / 夹克 ¥700 / 西装 ¥1,800 的 85 折，2 天到，魅力 +2/+4/+7），到家后在衣柜里换；住处没有“升级按钮”，床/空调/窗帘等家具去家具城买或网购，再摆进屋里（睡眠恢复、水电由实际摆的家具决定）；店里摆设要歇业装修一天。电饭锅可以真做饭（开局 5 斤米，没有冰箱，别的食物去农贸市场买）。以上都会存档。
20. **店里细节**：顾客头顶有对话气泡（想买什么、有没有货）和离店原因小字，收款飘“+¥”；柜台旁按 F 依次给排队顾客结账；每天零点弹“昨日营业”小结与建议；Esc 关最上层窗口。
19. **店里顾客的购物过程**：开门营业后能看见顾客走到货架前、拿货、拿着货到柜台排队；不去结账，等够耐心他会把货放回货架再走（货架上的货这时才恢复）。
18. **智能手机与背包**：新游戏没手机，顶栏“手机”打开按键机（只能打电话、发短信，短信常没人回）；去手机店 ¥800 买智能手机（或菜单里的作弊开关），再到手机里的应用商店下载 网购 / 聊天 / 1788 app 才能用对应功能；顶栏“日程”没手机时是笔记本（无提醒），有智能手机时是自带的日历（约会、师傅上门前 30 分钟提醒）；背包有承重，米菜礼品要先买进背包；送礼要先买烟酒（烟酒茶行 / 网购），不再当场花钱。
19. **家具城（和农贸市场一样）**：顶上选“买了：装进背包 / 叫车送到家里”，再一件件点“买”。背包背不动的按钮写“背包装不下”，切到叫车就能买。叫车是面包车，每辆最多装 200 公斤，面板显示“当前第 N 辆：已装 x / 200 公斤，还能装 y 公斤”；装不下自动再叫一辆、再收一次运费（按钮会写“买（再叫一辆 +¥30）”）。车约二三十分钟送到家，家具进“我的”里待摆放（截图 vs1_66、vs1_67）。农贸市场、烟酒茶行、档口的叫车也是同样的载重规则。
27. **离开店铺要确认**：在门口按 F、走出门槛或点“离开店铺”，都会先问“要离开店铺吗？”。没人看店写明会关门（有人排队会提示），店员在班写明照常营业（截图 vs1_78）。
28. **1788 在手机里**：店里右侧面板没有“1788”和“补货”了。买智能手机、装 1788 app 后，从手机主屏打开“1788 批发”，在哪都能下单；里面“自动补货”页顶部解释了什么是常备数（截图 vs1_79、vs1_59）。
29. **顾客对话气泡**：顾客进店后头顶有白底对话框，写想买什么、店里有没有货（✓ 有货 N 件 / ✗ 没货），装机的写缺几样配件；挑中后写拿了哪件、多少钱（截图 vs1_80）。
30. **只用 WASD 走路**：整个游戏没有鼠标点地面移动。

18. **三年路线与结局**：顶栏“目标”按钮打开“目标与人脉”面板，能看到第一个月 → 站稳一年（第 365 天，身家 ≥ ¥30 万、知名度 ≥ 30）→ 有名号的店（第 730 天，身家 ≥ ¥150 万且扩建到中型）→ 三年之后（第 1095 天）。没过检查点不会结束游戏，只会让店租 +10%；第 1095 天弹出结局（勉强糊口 / 稳稳当当 / 电脑城新星 / 电脑城大亨），可以继续玩。注意：第一年和之后的门槛是按机器人跑分定的，试玩如果觉得太松或太紧请告诉我。
19. **换大铺子去房产中介**（店内“升级”页不再有扩建）：中介里不时挂出别的铺子，中型要知名度 ≥ 25、大型 ≥ 60；签了就是搬家，退旧押金、收 ¥800 搬家费，货和人跟着走。
20. **人物与交情**：在目标面板的“认识的人”里看。老张、李姐、小林会在前几周通过事件出现，阿杰和老周在第 4 天认识。可以送礼（每人每 5 天一次）、也靠事件选择涨交情；交情到了门槛有实际好处（客流、房租、进货价、救急）。
22. **进货渠道的人**（电子市场四家档口）：第一次走进档口会认识老板——老李（CPU/主板）、阿王（显卡）、钱姐（内存/硬盘）、老孙（机箱电源）。档口面板顶上有他们的交情条、进价折扣和“每样每天额度”，可以送礼、递烟打听行情（¥20，交情 ≥ 12，3 天一次）、约出去玩。交情越高：进价最多 -6%，每样配件每天的进货额度从 8 个涨到 45 个。
23. **约出去玩**：约某人“晚上 19:00”或“周末白天 10:00”（交情 ≥ 15，对方不一定答应，看交情和魅力）。到点会弹出选择去哪玩（吃饭 / KTV / 夜宵；钓鱼 / 逛电子市场 / 郊游），花钱、花几个小时，涨交情；对方最爱的活动涨 1.5 倍；放鸽子 -8，错过 -5。出去玩时对方可能顺口透露行情。
24. **行情小道消息**：老李、阿王、钱姐、老孙、老周、阿杰都会说“某类配件要涨/跌”。有真有假：老李最靠谱，阿王最不靠谱，交情越高越可信。说真话时，两天后那个品类的价格会真的朝那个方向走 10%–18% 然后慢慢回落；5 天后系统对账，“行情”面板底部的“小道消息”和人脉面板里能看到每个人的“应验率”，靠这个判断该信谁。
21. **数值**：这一批把基础客流从每小时 10 人降到 2 人，知名度涨得也慢了很多；前几周会比之前紧，请重点感受“第一个月能不能活下来”。

21. **店铺管理**：店内“定价”页可给每件配件单独加价（−/+，“跟随”恢复全局）；手机 1788 app 的“自动补货”页给配件设常备数，每天 9:00 库存（含在途）低于目标 40% 会用手机在 1788 自动补到目标（要智能手机和 1788 app，现金留 ¥500 底）；货架提示会写“缺货/快没了”；“柜台”页底部“经营报表”看近 14 天营业额和支出曲线。

22. **整机展示台与步行速度**：店正中间的展示桌走近按 F，看三档整机的配置、价格和配件是否齐，点“装一台摆上去”用库存配件装好摆上桌（桌上真的出现一台开着的整机）。想买整机的顾客会直接把展示机抱去收银台结账；展台上摆得越多，进店想买整机的人越多（窗口顶上有百分比）。顾客气泡最后一行“正在挑、比价格… N%”走满才决定买不买；步行约 3 公里/小时（500 米要 11 分钟），打车/小电驴/三轮车明显更快。

23. **点人物交谈**：档口窗口左边是老板立绘，点头像弹出对话框（上面头像 + 他说的话，下面一列居中的选项），出现一组选项（随便闲聊、赠送礼品、聊聊行情、聊聊人生、交心打听内幕、发出邀约、砍价），交情不够的灰着并写明解锁条件，说的话显示在对话框里（截图 vs1_63、vs1_64）；目标面板里认识的人有小头像和“交谈”按钮。立绘是 AI 生成的干净 2D 游戏角色插画风（正常头身比、简洁五官、淡彩底色）。

24. **店主立绘**：进烟酒茶行、手机店、家具城、农贸市场、车行，左边是店主立绘和一句话（点头像换一句），右边是商品；档口老板的立绘点开是交谈窗口。
25. **师傅在修时不能出门**：师傅进屋修东西期间（约 30 分钟），按门 / 走出去 / 打车 / 前往别处都会被拦住，提示“师傅正在屋里修……还要约 N 分钟”，门口的提示也变成“师傅在修东西，暂时不能出门”；修完才能出门。
26. **店里的人**：进店左边是人员图，自上而下老板（金框）→ 店员（灰框），上下有连线、卡片一样大（家具城最上面是店长周敏），点谁就和谁说话，弹对话框（随便聊聊、送他点东西（从背包里挑，要先去烟酒茶行买，一瓶饮料 ¥5）、听他讲自己的事、打听老板的事、看看货；店员有熟络度，同一排可有多个店员）；老板（档口老板交情 15、阿杰交情 20）没够交情时是灰色“？？？”，找店员打听老板的事每天一次涨他的交情，够了就能点老板交谈；烟酒茶行、农贸市场、车行是小店，老板直接接待（截图 vs1_16、vs1_65、vs1_33、vs1_32）。
27. **收银台、货架调价与寻路**：顾客拿货到收银台排队后，老板不走到收银台旁就结不了账（点“结账”会提示先过去）；站过去按 F 依次结账。货架窗口里能看到售价并直接 −5% / +5% / 跟随行情调价。顾客绕展示桌走，不在桌边来回卡住。长列表（烟酒茶行、档口）连续点“买”不会跳回顶上。
28. **叫车送到哪 + 店里储物柜**：任意一家能叫车的店里切到“叫车送货”，右边“送到 [家里 ▼]”点开能改成“我的店里”，商品按钮的运费跟着变，送到后按说明进厨房 / 纸箱 / 货架 / 店里储物柜（截图 vs1_66）。在店里打开背包或右侧“库存”页点“店里储物柜”，能把吃的、礼品放进去（40 公斤），配件放进去直接上货架；“一键全放到店里”不再灰着。
29. **房产中介与开局租铺**：新游戏现金 ¥10,000、没有店，顶栏写“还没有店铺”，底栏快捷按钮是“房产中介”。走进「安居房产中介」能看到在租铺面：大小、面积、离地铁站距离、客流系数、月租、签约总价，还没空出来的写“现租户租约还剩 N 天”（隔壁五金杂货约 5 个月后空出来）。点“签约租下”扣首月 + 押金 + 中介费，楼顶名牌变成青色“我的电脑店”，之后就和以前一样经营。以后再签别的铺子就是搬家，旧铺子变回橙色“旺铺招租”。验收旧流程可点开局窗口的“（作弊 / 验收）跳过找铺子”（截图 vs1_83、vs1_84、vs1_14）。

30. **租到铺子是空壳、家具要自己买自己摆**：签约后铺子里什么都没有（截图 vs1_88），顶栏写“店：关门”，店里面板顶上有红色清单，写还缺什么。去「宜居家具城」买收银台、货架（只有一种，建议买 6 个，摆好后自己设置各放什么）、展示桌、装机操作台（截图 vs1_89），货架 40 公斤、柜台等是重件，要叫车送货。回到自己店里点右上角“我的”→ 摆放模式，把它们摆好（vs1_90 / vs1_91）；至少 1 个收银台 + 1 个货架才算装好（vs1_92）。**摆完当天店还是关着，第二天才能开业**。展示桌决定能摆几台展示整机（每张 2 台）。老存档、作弊开局会自动配齐一套家具。
31. **中介费可以谈折扣**：签约要付首月租金 + 押金（一个月）+ 中介费（一个月），2000 的月租就是 2000 + 2000 + 2000。中介小陈（有立绘）可以聊天、送礼混熟，熟人度每点让中介费便宜 0.5%，最多 5 折；窗口里每条铺子写“标价 → 折后价”（截图 vs1_93）。

32. **杂货和数量显示**：烟酒饮料点心水果放进储物柜或背包后，能放进店里、收回、单独定价（在货架窗口杂货页里）。来买配件的顾客多半不买杂货，卖得慢。库存页（vs1_96）和货架窗口只显示店里有的东西，全部写具体件数，没有“缺货 / 快没了 / 有货”这类模糊说法。
33. **通用货架**：家具城只有一种「货架」¥300，摆好后的货架都是空架子（截图 vs1_97）。走到货架前按 F 打开货架窗口（vs1_98），点上面一排按钮选它摆什么：6 类配件或烟 / 酒 / 饮料 / 点心 / 水果，一个货架只摆一种；换一类，后仓里那类货自动摆上来（vs1_95 饮料、vs1_69 显卡）。每个货架 60 公斤，盒装 2 公斤（显卡、电源机箱 4 公斤），散件重量减半；两个货架设同一类，容量翻倍。顾客只买货架上摆着的，没有对应货架的货后仓再多也卖不出去。右侧面板“库存”页顶部列出每个货架的类别和载重，点“设置”也能改（vs1_96）。老存档的 6 种货架自动变成设好类别的通用货架。

## 已知限制
- 美术是程序生成的灰盒低多边形，人物是胶囊；音效只有程序合成的占位音（点按钮、收钱、门铃、出错），菜单里可关。
- 只有一个存档位。
- 交警只在骑三轮车时出现（按设计）。
- 大老板直供、主播、汽车、移动支付等属于 VS2。
- 随机事件现在共 24 个（含 12 个人物事件），文案是占位稿；店铺升级只改数值，店内模型还没有随升级变化（智能手机、货架、招牌灯箱暂无外观）。
