## 开店主线与任务时序

- 主线完成后先显示任务完成弹窗和实际奖励。玩家确认后才开始后续教学高亮。存档保留尚未确认的完成提示，已经确认的提示按原进度处理。家具买齐并关掉购物面板后，先确认购买任务完成，再按高亮前往店铺、进入装修。首次成功成交后同样先确认完成弹窗，再进入招聘教学。
- 首次打开库存、设置首个任务货架和操作柜台都使用暂停式高亮。餐馆的饮料货架会引导选择饮料分类。每个货架单独显示编号、分类、重量和件数用量，商品明细可展开。
- 店内有顾客排队时，玩家可直接在右侧柜台点「结账」。角色自动绕过店内家具走到收银位，抵达后再结算仍在排队的订单。顾客已离开时取消该次操作。靠近柜台时仍可用 `F`，方向键或 `WASD` 可以接管移动。
- 员工教学确认前置任务后才启动，依次引导查看分工、选择应聘者、点选当前目标岗位并确认。侧栏保留「聘用并安排工作」，岗位窗口显示该店完整岗位，随教学步骤高亮对应选项。
- 每天 09:00–18:00 有 4 位候选人到店，无需再花 ¥50 贴告示。需要等候次日候选人时，玩家可先自己操作柜台，完成一次成交或到关店时再回家。招聘任务按该店实际岗位及采购配置推进。

| 店型 | 开店教学所需分工 |
| --- | --- |
| 餐馆 | 服务员上菜、收桌和收款，厨师备料和烹饪，进货员补充大米和配菜。 |
| 普通零售店 | 收银员处理排队结账，进货员按计划补货。电脑店的装机、模型店的喷漆、宠物店的养护等根据后续业务安排。 |
| 二手店 | 鉴定员负责鉴定，收银员负责结账。修复业务可另设岗位。 |
| 专门场所 | 引导安排对应的值守岗位。 |

招聘教学引导点击进货员所在行的「安排进货」。采购界面可设置固定清单或库存目标，并配置频率和交通，保存有效计划后推进任务。开店分工卡保留岗位状态，采购按钮集中在员工行。

| 后续任务 | 触发规则 |
| --- | --- |
| 买一部智能手机 | 首店完成首单、招聘分工及所需采购设置，至少到下一个游戏日，且可用现金达到 ¥1,600，即 ¥800 的两倍。 |
| 买一辆小电驴 | 购机至少又过了一个游戏日，已开通收款码，且可用现金达到 ¥3,600，即 ¥1,800 基础车价的两倍。 |
| 前往银行 | 保留任务导航，玩家自行选择出发时间。到银行后再高亮借款说明与证券流程，借款可以自行决定。 |
| 开第二家店 | 在前置任务达成后，以当前符合条件的最低签约账单为基准，按首期租金、押金与中介费合计的两倍判断现金。已经签约的店铺按存档中的实际进度推进。 |

第二家和第三家店的指引按找铺、装修、备货、岗位和首单等实际经营进度更新。购机、购车的日期条件随存档保存。

## 住宅、城区和店铺面积

- 在起始出租屋和改善住宅等符合条件的住处都可打开装修。购买居家工作台后，可从「居家工作台 · 待安装」进入当前住处的摆放流程，选择合法位置后确认，也可用「摆放并完成」。住宅装修使用当前地址的家具布局。工作台装好后，同一个居家办公功能可从其他符合条件的住处打开，库存和配送仍按地址管理。
- 「我的 → 住处」可把符合条件的住处设为主住处。快捷回家指向新地址，原出租屋可以继续保留并按租约结算。睡觉、小睡和自选起床时间使用短黑屏过渡，醒来显示实际起床时间与睡眠时长。
- 城郊 28 栋住宅采用低多边形旧居外观，其中有 26 栋编号住宅、起始出租屋和另一处旧居。保留红瓦和蓝瓦坡屋顶，改用较薄的水泥窗台、简朴入口、短台阶和少量雨棚或栏杆。起始出租屋使用褪色蓝灰墙、深色墙脚和局部补瓦。其他旧居交替采用暖灰、灰褐和冷灰外墙。改造针对室外场景。
- 逐铺对照了 48 处可交易普通商铺的外景与室内。小铺 36 处，中铺 10 处，大铺 2 处。外景铺面宽深与室内使用同一档尺寸，高度也按档区分。房产列表按当前铺面数据展示规格。固定地图缓存版本升至 `5`。
- 城郊旧居街沿街商铺与住宅分别使用店铺和住宅数据。是否需要进一步调整街区布局或房产入口的展示方式仍待确认。

## 活动对话、小游戏与市场

- 用餐时点选「聊近况」或「聊彼此的工作」会显示双方台词。公园、酒吧、KTV、钓鱼、高尔夫、市场、展览和相应社交活动接入共用对话流程，选择话题后会收到对应回应。部分邀约和剧情探访也使用这一流程。
- 社区台球支持移动鼠标瞄准，按住台面上的鼠标左键或空格蓄力，松开出杆。窗口失焦会清理按住状态。足球点球与篮球练习都能在最后一球结束后进入结算，支持对应的方向键和 `WASD` 方向输入，以及鼠标或空格蓄力。
- 摩天轮两处设施都采用抬高后的尺寸。乘坐相机位于包厢内的眼位，默认面向观景窗。整圈约 24 秒，接近最高点时放慢。可用方向键、`WASD` 或按住鼠标右键转头，按 `V` 回正。社区摩天轮营业时间为 09:00 至次日 00:00。
- 农贸市场取消水果批发。已买到的水果保留，旧采购计划会过滤下架商品。人物窗口的「通讯录」和「关系图」使用相同外框，切换时窗口范围保持一致。
