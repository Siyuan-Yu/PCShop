# UI整理落地：保留员工部分（2026-11-03）

按用户对[第47篇UI审查](47-ui-interaction-audit.md)的确认实施：**员工栏、招聘、岗位、排班、员工采购清单保持现状**，处理其余重复入口、上下文错误和过长说明。本篇记录实际源码改动，不是待实施建议。

## 页面与入口

### 经营、采购和物业

- 经营的收支、采购、物业、投资、合同合作共用一个主窗口，切换页面不会再叠开两套“经营总览”。原有资产负债、直供协议、企业合同、托管门店、推广和园区能力保留在业务子页。
- 主窗口有返回路径，保留页面闭包中的筛选、搜索和滚动位置；重新进入已打开的主功能时复用窗口。人物、行情、日程、个人资料也按功能复用主窗口，子级交易确认继续保留父页。
- 采购默认当前自营店；从居家工作台的指定店铺进入时携带该店。商品页、认领/在途订单和线下货车按所选店铺展示，下单确认显示收货店。
- 1788“补货计划”进入统一采购，不再保留另一套自动补货设置页。固定清单、阈值补货等员工界面不改；采购渠道仍有各自的解锁、配额、运输和价格条件。
- 全店共用的账单预留天数、现金底线、每日补货预算和默认1788商家移入统一采购的“全店补货预算与默认商家”，编辑草稿后保存。原直供的现款和账期能力均保留，账期下单先确认30%付款与14天尾款条件。
- 园区按钮直接打开园区；托管资产按钮筛选到对应门店；物业按钮筛选到具体房源，避免返回全城总览。具体物业不再被全街区统计和十多个筛选按钮挤到屏幕下方，街区筛选改为下拉。
- 购买目录、已持有物业和住处在同一物业窗口；换住处、全款买房和按揭均先预览费用再确认。原有住宅等级、价格和贷款规则不变。
- 具体房源、住宅和资产按所属中介导航，跨片区交易预览提供“前往房源所属中介”，不再固定去第一间中介。

### 店内柜台、定价和记录

- 餐馆柜台只处理当前桌单与厨房动作；可出锅、焦糊等需处理订单优先显示。完整烹饪规则改为“烹饪说明”。
- 餐馆定价页只放菜单供应开关、菜单价格和饮料定价；供应开关即时生效，价格先预览再确认。“记录”页仅显示桌单状态、累计成交和流失，不复制厨房操作。
- 二手柜台处理卖家、收购、鉴定及原有代管设置；定价页只列已鉴定的可调价商品，记录页显示已收购物品的真实交易状态。保留库存/货架的就地定价捷径。
- 普通店统一加价、居家工作台统一加价和餐馆菜单价格都明确确认后生效。草稿按店铺隔离，界面重建后仍保留待确认数值，不会串到另一分店。
- “商品上架”更名为“商品入库”，操作后明确反馈入库件数、该商品当前陈列件数和后仓余量。货架仍受实际件数/承重与品类限制。

### 行情、日程、人物与生活

- 行情统一为价格走势、行业动态、竞争事件和模型目录；模型目录可按系列筛选，故事和规格点详情，不再整页展开全部商品长说明。
- 日程统一为我的安排/城市活动。按键手机仍只显示最近5天笔记本，智能手机保留完整日历与提醒；没有改变手机和人物活动的实际解锁、到场条件。
- 人物窗口连接已知人物、关系图、通讯录和消息。人物列表、关系图、通讯录能打开同一人物资料；资料页明确区分现场交谈、已交换联系方式的远程联系与邀约，不能借查看资料把人召到身边。
- “我的”拆为状态、饮食、住处、物品与包裹，首先显示饱腹、精力和健康；详细规则按需展开。居家工作台不可用时直接显示缺设备、需回家或正在工作等原因。
- 顶栏保留员工入口，把日程和行情的次级入口纳入个人/经营页面；C、H快捷键保留。出行主按钮明确“前往”，选择目的地只保存选择，并首次提示下一步。
- 按键手机没有实际功能的按键不再响应“这个键没用”的点击。

## 数据、关闭与说明

- 店内经营趋势显式按当前店筛选；全部门店趋势从经营总览进入。销售、经营支出和经营现金净额使用经营归属，个人消费、借款本金和内部转账不会混入趋势。
- 现金数字和“现金流水”仍能查看全部现金变化；不把全部流水当利润。资产负债页更正全店库存/在途及铺面押金的标签，补充企业持仓口径。
- 普通窗口显示“时间已暂停”，居家工作台显示实际时钟状态。仍保留大屏持续运行的原玩法，打开普通管理/确认窗口时的暂停有明确反馈。
- 地点窗口的关闭只关闭面板，离开地点使用固定的“离开……”按钮；关闭、返回与离开不再混用。B/F等场景快捷入口继续保留。
- 中介远景只保留选中房源、已租铺面和挂牌等必要标记；放大后显示其余名字。租金、签约总费用、客流、分流和户型保留在详情，完整规则放进说明。
- 财务口径、商圈规则、烹饪流程、资产估值等不再常驻长段；交易确认中的房价、交易费、首付/贷款、月维护费、付款后现金及不可退条件仍明确显示。
- 任务页内提示缩成当前目标和短提示，步骤从“查看步骤”打开；员工页的原引导不变。
