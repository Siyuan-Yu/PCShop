## 已完成的改动

- 短音效在正常进城加载遮罩下逐帧准备，首次进店、付款等操作不再临时合成波形。每次最多准备一种，已有缓存直接复用；不播放声音，不改变静音、音量或播放冷却。
- 空铺查询用本次查询的挂牌集合代替每铺逐条查找；每日按街道统计挂牌数量只扫描一次。没有跨结算缓存，保持地点遍历顺序、随机数调用顺序和签约规则。
- 店内只对构造阶段的固定房壳做静态合批，人物、车辆、可摆家具在之后创建；灯光漫射面、开关门牌、应急灯及透明材质排除在批次之外。沿用已有模型、材质和照明参数。[Unity 对运行时静态合批的说明](https://docs.unity.cn/2023.2/Documentation/ScriptReference/StaticBatchingUtility.Combine.html)明确要求批内子对象不再移动，因此没有把整个运行中的店内层级直接合并。
- 店铺视图销毁时回收该店运行时合批生成的网格。窗口自适应由 `WindowFit` 的布局和渲染回调处理，移除通用 UI 每帧额外主动调用一次的路径。
- 花园林带的树冠曾露出取样于图集底部绿色条带的实心网格。在原位置用叶簇填充，并升级地图预生成版本。同机位截图验证右侧、右下和左上不再露出实心绿块。新网格的测试覆盖 24 种朝向、树种和细节组合，预生成地图的截图单独验证实际加载路径。
- Windows 命令行巡检改为真实 PlayerLoop 帧间隔，走正常渐进加载路径，每个场景独立恢复同一合成存档，持续执行模拟、人物、UI 和渲染。旧的固定 `1/60` 循环不能代表真实帧率。
- 新增逐长帧的结算、音效、人物和 UI 分解；没有开启诊断参数时不启用诊断回调。编辑器单场景巡检的后台限速判定修正，避免一个样本时阈值为零导致误报。

## 测量口径

机器为 i7-12700F、RTX 3070、约 32 GB 内存，Unity 2022.3.6f1，Windows x64 Mono Release，1920×1080，关闭 VSync、不限制帧率。原始截图已与上一轮编辑器花园同机位核对；没有换简单场景来提高数值。

使用隔离项目 `D:/tmp/PCShop-main-build-5f4a412c` 和独立 `PCShopQA/PCShopSellQA` 应用标识。合成存档目录在每轮输出内，不加载玩家存档。用户主项目编辑器不关闭。CPU 功能测试与图形巡检串行。

P99 ≤ 8.33 ms 表示至少约 99% 的采样帧处于 120 FPS 预算内，**不等于最长帧也符合预算**。均值、P99、最长帧分别保留。休息结算和读档需单独评估，不能拿平均帧率掩盖切换卡顿。

这些是固定正常镜头的自动巡检：关闭点击射线与任务弹窗，用 `Step` 驱动真实帧间隔下的模拟、显示与 UI。它不覆盖鼠标拖拽、快速转镜头、比赛驾驶、任意大经营档、自动存盘或所有菜单组合，赛场样本是场景巡检，不是完整比赛性能验收。材质计数在各例结束时采集，不能宣称监测了游玩期间所有瞬间。

## 无效或中止的测量

- 第一轮编辑器单场景被错误判为后台限速：单样本阈值计算缺陷，已经修正。原记录保留。
- 第一次店内编辑器诊断因新脚本 `.meta` GUID 长度错误编译失败；已修正为合法 32 位并成功重新编译。
- 第一次 Windows 隐藏窗口有模拟而没有实际绘制，虽然显示约 2004 FPS，**此数无效，严禁用作验收**。计数器实际 drawCalls=0。巡检现已在暖机后检查真实绘制，未绘制即失败退出。
- 一次隐藏窗口恢复尝试发生 DX11 分辨率初始化失败，中止，不计入帧率结果。后续用正常显示的客户端完成测量。
- 花园延长到 120 秒的诊断触发了正常体力耗尽、恢复和弹窗暂停，出现 27,993 个暂停帧，故约 403 FPS 的全段均值**不能作为花园验收**。该记录的两个日结调用仍可用于定位：房产日结首次 3.479 ms、第二次约 0.095 ms，经营日结首次 4.949 ms、第二次约 0.135 ms。首次执行开销明显，但仅凭这些差值不能把全部耗时都归因于 JIT。
- 店内 v1/v2 的 30 秒样本实际仅推进 34 分钟，上一轮 162 的 60 秒编辑器店内样本也仅推进 36 分钟。新手教学冻结并不等于 `Time.IsRunning=false`，旧探针漏记了这种状态。这些样本不能证明正常持续经营的性能；原始证据保留，另存《旧巡检时钟审计》。v3 的合成夹具明确完成开店教学，检查教学冻结、手动活动、游戏结束和恢复状态，并要求游戏分钟与真实采样时长、倍率一致（允许两分钟边界差），否则不判为 120 FPS 通过。正式玩家教学规则没有改变。
- v2 正式巡检在完成四个室外样本后主动中止，以修正上述店内问题；四个已完成室外样本的时间推进均正常，但不伪称十例完成。
