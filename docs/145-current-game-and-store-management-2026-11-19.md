## 经营 → 店与采购

- 顶栏「经营」或 H 打开「店」，同一窗口的「员工」用于查看全店人员、岗位和排班。默认门店表横向铺满窗口。每行显示门店与街区、营业状态、进货员、最近到货、今日经营收入、近 7 日经营收支差额及一条待处理事项。收支差额按门店账本的经营收入减经营支出计算，包括发生在期间的进货款等经营支出。
- 选中一店后右侧展开「概况／采购」，左边保留门店、营业状态、进货员、最近到货和待办，便于继续切店。当前门店的收入和收支差额放到右上方。「返回全部门店」或再次点击当前行恢复全宽。概况按实际规则区分营业、打烊、收尾、无人值守和暂停等状态，提供营业时间、员工与排班、本店收支、经营待办等入口。库存、食材、模型委托和场馆操作按实际地点和既有权限使用。
- 进货员按本店人员配置和采购策略显示。已设员工代采且该店没有进货员时提示「未安排／需进货员」。已有进货员时显示姓名、外出进货或定期计划状态。没有员工代采的店可显示网购自动或自行补货等已知情况。「采购」详情另列具体进货员的当前状态、进货安排和已有员工进货记录。
- 「最近到货」按实际收货门店记录。网购配件、送店的网购商品或大米、直供、员工代采及货车交付商品和食材，都在实际送达时更新，并随存档保留。旧档可从已有完成记录恢复，缺少记录时显示「暂无到货记录」。背包物品的普通挪动不当作采购到货。
- 采购页下放到所选门店，沿用真实库存、补货目标、下限、负责设置、搜索和缺货筛选。顶栏右侧保留全店补货预算、直供协议与账款。从门店概况可查看本店缺货商品，原有按店采购入口仍可直接打开指定门店。G 能打开采购入口。居家工作台的「经营 → 门店」使用同一套门店组件。
- 门店采购、配件行情、员工进货和相关提示已移除「在途订单」展示、统计及筛选。配送、入库、仓位预留与防止重复补货的计算仍按原规则运行。有可以撤销的动作时，可用本店「取消采购」释放已认领的需求，或取消符合条件的网购并退款。[门店界面](../Assets/Scripts/Game/UI/GameUi.ShopManagement.cs) · [本店采购](../Assets/Scripts/Game/UI/GameUi.ProcurementShops.cs) · [到货记录](../Assets/Scripts/Core/Session/GameSession.PurchaseHistory.cs)

## 店型、员工与货源

| 业态 | 已实现玩法 |
| --- | --- |
| 电脑店 | 盒装、散件、兼容装机、整机陈列和销售、顾客带单、自动装机、企业合同及库存预留。每店个人委托之间间隔 1–2 个游戏日。 |
| 宠物用品店 | 分档用品零售、猫狗代养、补粮换水、清理、玩具互动和饲养员，按实际状态和周期结算。 |
| 服装店 | 春秋、夏、冬款及价格档。季节、温度、试衣镜、销售员和顾客预算影响销售。付款的衣服入个人衣柜，可通过试衣镜换上。 |
| 模型手办店 | 四个原创系列，常规款、限定款和漫展采购，按真实现货做陈列、销售和品牌展示。另有顾客自带模型的改胶喷漆。 |
| 二手旧物店 | 卖家候位、报价、收购、鉴定、修复、陈列及销售。最多 5 位卖家等候，每位最多等 8 个游戏小时。另有独立旧物市场。 |
| 餐馆 | 堂食从备料、下锅、出锅到上菜、收款、收桌，可销售已陈列的饮料。鱼餐预订使用指定食材、鱼种和交期。 |
| 场馆与二手车业务 | 按片区开放。场馆包含营业、值守、预约与容量。二手车衔接车源、整备、挂牌及顾客出价。 |
