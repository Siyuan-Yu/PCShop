# 三区材质制作记录

树冠、花境、草地和建筑面板先生成基础色图，再按模型 UV 整理成 Unity 实际读取的贴图。树冠和花境使用透明通道。建筑板材按表面分别设置平铺、光滑度和金属度。所有验收图均另外从运行中的游戏相机取景。

### 夏季树冠

[summerCanopies.png](../../../../Assets/Resources/OldTown/Surfaces/summerCanopies.png)

以输入图作为游戏树冠UV布局参考，为细腻手绘3D当代中国花园城市制作真正透明底的正方形RGBA树冠色彩图集。四格2x2，每格独立，左上圆形浓绿香樟的树冠，右上垂柳冠盖及下垂细长嫩绿柳条，左下花量约40%的淡粉开花乔木树冠，右下呈伞形的黄绿榉树树冠；只保留下部少量分叉枝条，不画长树干、不画地面、影子、文字或边框。团块有力度，暗绿叶丛、青绿中间色、顶部黄绿色嫩叶，弱的方向性光，让Unity主光再塑造明暗；树冠边缘有独立成团的叶簇，间隙透光，影部保持饱和，不能灰蒙蒙。物种位置和构图和参考贴图一一对应，每棵在自己象限内部完整可见、留少量透明边，不可互相跨格。无高光发白，不要秋季枯黄。用于多层树冠网格的游戏albedo，非概念图。

### 建筑表面

[pearlCeramic.png](../../../../Assets/Resources/OldTown/Surfaces/pearlCeramic.png) · [brushedAlloy.png](../../../../Assets/Resources/OldTown/Surfaces/brushedAlloy.png) · [civicGlazing.png](../../../../Assets/Resources/OldTown/Surfaces/civicGlazing.png) · [solarCells.png](../../../../Assets/Resources/OldTown/Surfaces/solarCells.png)

生成一张游戏用的四格材质原图，正方形2x2，每格恰占四分之一，严格正交、平面展开、无文字无分隔、无边缘包框。为中国近未来宜居社区的精品手绘3D经营游戏提供近距离建筑纹理，细腻写实手绘、冷中性日光、低对比、原色albedo。左上是乳白色釉面工程陶瓷外墙板，非常细的两三条灰色横缝与少量短竖缝，轻微暖冷变化。右上是细密拉丝的浅银灰铝合金板，均匀纹理，一两道纤细连接缝。左下是蓝灰青色幕墙玻璃近景，玻璃内隐约有水平扶手、少量天光和窗边座椅的剪影、下半较暗、上半较浅，各元素都保持浅反差，不展示室外风景，不画外框。右下是深蓝光伏板电池片的近景，有规整很细的银色栅格、很微妙的晶体颗粒，深浅蓝黑，每边可拼接。所有材料能被映射到真实三维模型，避免斜拍、示意说明、方向性投影或图标。

### 夏季花境

[summerBorders.png](../../../../Assets/Resources/OldTown/Surfaces/summerBorders.png)

将参考图这张透明底植物图集重绘成维护良好的夏季现代江南社区公园用的RGBA植物色彩图集。保持上三行、每行四格，最后一行留空，每种植物独立不可跨格，不要盆、土、标识、黑边、背景，真实alpha。每一格细腻手绘立体团块，暗绿下叶与鲜绿中叶，颜色清亮而有质量，避免枯黄土褐色。第一排依次为深绿阔叶灌木、嫩绿金叶灌丛、密实而修整平圆的墨绿绿篱、白色多花绣线菊。第二排为鲜绿水边芦苇、柔和青绿草簇、甘蓝、豆架。第三排浅粉淡紫绣球花团（粉紫花朵占植株的55%）、水边香蒲、深绿圆球黄杨、银白穗绿色叶芒草。专门给三维交叉面花境使用；轮廓紧凑，以丰厚叶丛与花头为主，根部连到每格底边；保持矮植株体积感和叶片之间通透。四列等间距，三行植物按参考图布局，最后四分之一透明。

### 养护草地

[tendedLawn.png](../../../../Assets/Resources/OldTown/Surfaces/tendedLawn.png)

生成一张正方形可无缝平铺的游戏草坪基础色贴图，适合中国新建城市公园和日常社区的等距三维手绘经营游戏。垂直正上方观察约6米见方的低矮草坪，满铺叶绿色从葱绿到黄绿的自然小色斑，有3到5组模糊的修剪草绒、零星少量三叶草和几朵极小的乳白小花，细笔触表现草叶方向，均匀中性天光。主色自然中橄榄绿，叶片背光偏深青绿，有稀有的嫩黄绿尖，整体比秋草偏绿。有低中高三个尺度的手绘变化，保持在正常游戏距离仍能读出地面体积。四边平铺，中心和四角相同亮度；没有泥路、边界、地平线、树、灌木、大石、明确棋盘、均匀噪点、斜投影或阴影晕角，无文字无UI。这是导入Unity的草地albedo，不是风景照片或概念图。
