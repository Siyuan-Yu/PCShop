## 0. 一句话

**像素感偏重的手绘老城**：厚实、做旧、灰暗偏暖的中国老城区日常生活；细深棕描边；一切像被生活磨过——脏渍、剥落、褪色。**不是**明亮高饱和的卡通，**不是**二次元，**不是**P5 描边风。

## 3.1 密度原则（重要）

- 游戏里不会有拥挤的人群：街上同屏行人 3~5 个即可，不要做人山人海或密集摊位。
- 室内要整洁：家具对齐、地面大片留空、不堆杂物；杂乱感只来自墙面做旧和少量点缀，不靠堆东西。
- 路人模型（char-sheet-04-crowd）是供随机抽取的人物库，不代表同屏数量。

## 5. 渲染与打光（灯光是风格的一半）

目标：**暖、低角度太阳 + 可见的柔和阴影 + 压低的饱和度与对比**。当前原型里已经调好的一组（`DayNightLighting.PaintedLook`，见 §9）：

| 项 | 数值 |
| --- | --- |
| 主光色 | `#FFE0B3`，强度中等；低角度（约 45–50°俯角） |
| 阴影强度 | 0.72（要看得见，但边缘柔） |
| 天空补光 | 强度 0.36 |
| 反射补光 | 强度 0.30 |
| 环境光 | 平的暖灰 `#BDB3A3` |
| 雾 | 暖灰尘雾 `#C7B8A3`，近 70 / 远 300 |
| 色调映射 | Neutral（不要 ACES，避免拉饱和） |
| 饱和度 | −8（白天） |
| 对比度 | +8 |
| 曝光 | −0.1 |
| 颜色滤镜 | `(1, 0.94, 0.86)` 偏暖 |
| 暗角 | 0.2，深棕 |
| 颗粒 | 0 |
| Bloom | 0.12，阈值 1.1（只让窗灯/路灯微微发光） |
| 分色 | 阴影偏冷灰 `#808594`，高光偏暖 `#948A75` |

夜晚/雨天：整体压成深蓝灰，**暖色窗灯与路灯是唯一高饱和点**；湿沥青反射暖光；参考 `scene-04-night-rain.jpg`。

## 6. 材质与质感

- **所有物体统一的手绘质感**：世界空间/物体空间的程序或手绘贴图，带点染笔触、脏渍、剥落、水渍、裂纹；不使用光滑 PBR、不使用渐变。
- **明暗：两档色阶 + 柔阴影**（暗部是亮部的暖灰偏紫，约 `×0.74, 0.70, 0.78`），亮暗交界用小范围平滑。
- **描边**：细、深棕，固定像素宽（约 1px，物体可略粗到 1.2px），**不粗、不黑、不做速度线**。地面/路面不描边。
- 墙面：灰米抹灰，斑驳，底部返潮泛脏，雨水顺窗台流下的竖向脏痕，局部露出砖色。
- 铁栏：圆杆，深棕锈色，带螺栓头。
- 布料：有织纹、磨白、污渍；围裙、床单有褶皱和厚度。
- 木头：干裂、边缘磨圆。

## 7. 建模规范

### 7.1 建筑

- 居民楼 4 层为基准：层高 ≈2.7m，首层架空基座 0.5m；面宽按 2.7m 的开间模数排窗。
- 大瓦屋顶（棕红）+ 女儿墙，屋顶放水箱、天线、杂物、楼梯间。
- 正面构件库（见 `asset-sheet-buildings-props.jpg`）：铁栏窗、带空调窗、阳台+晾衣杆+花盆、卷帘门+小瓦檐、青绿雨棚店面（货架、柜台）、单元门（台阶、信箱）、外挂排水管、楼梯。
- 窗：过梁 + 凹窗 + 窗框 + 窗台及托架 + 竖向污痕；窗内有窗帘或暗色。
- 底层贴街：纸箱、盆栽、电动车、三轮车、塑料凳、垃圾桶、水洼。
- 电线杆 + 电线（下垂弧线）：沿街 + 连到楼上。

### 7.2 地面与绿化

- 草地：深橄榄，斑驳点染，局部偏黄，不要纯色平铺。
- 道路：深沥青，芥末黄虚线，白边线，微裂、油渍、碎石；**路缘与人行道的方砖要有缝**。
- 树：圆形分层树冠，两到三层 + 顶冠，每个团块**两色点染**（暗在下、亮在上），团块要圆润柔和而不是多边形硬面；有树干、根部外扩、2–4 根枝杈。树冠约 4.5–5m 高。
- 灌木：低矮团块，同色系；偶尔带小花。

### 7.3 人物

- **比例：约 3.8 头身**（略微 Q 版，但不要大头娃娃）。身高 1.52–1.72（房东最矮，酒保最高）。
- 脸：**小圆点眼 + 一点高光**，小眉，小鼻，淡淡腮红，小嘴微笑。不要大眼睛、不要二次元反光眼。
- 头发：近黑，成束的发片，有体积；每个角色发型明确（见 §7.4）。
- 手：有手掌+手指（至少拇指+一组手指），**不要球状手**。
- 脚：鞋有鞋头/鞋带/鞋底厚度。
- 衣服：有袖子/裤腿的粗细变化、肘膝褶皱、领口袖口罗纹、口袋盖、纽扣；**布有厚度**，不是贴皮。
- 动作骨骼：髋、膝、肩、肘 4 对关节够用；站立 / 走路 / 双手交叠（房东）。

### 7.5 立绘/CG

- 立绘：**沿用现有头像的角色设计、构图和姿势（半身、3:4、淡褐灰纯色背景），只把画风换成本文的手绘像素风**：哑光笔触、细深棕描边、低饱和暖色、眼睛不要二次元高光。样例见 `concept/portraits/`。不要重新设计角色。
- CG：沿用同一画风，场景用暖低角度光，保留细描边。

## 8. UI 风格

- 面板：奶油纸色 `#EFE8D8`，次级带 `#E3DAC4`；细深棕边 `#6B5E50`；**硬边的浅棕投影**（偏移 2px，无模糊）。
- 顶栏/页脚：深暖褐 `#4A4238`，凹槽 `#352F28`，边 `#2A241E`，文字 `#F1EADA`，强调金 `#D9BC7C`。
- 按钮：主按钮芥金 `#D9BC7C` + 深棕字；次按钮奶油 `#F3ECDC`；危险按钮砖红 `#A5604A`；禁用灰。
- 强调色：锈红 `#9C5A44`；正向 `#5C7A5E`；警告 `#A5604A`；次要文字 `#6E675C`；正文 `#3A322B`。
- 图标：扁平手绘、边缘略粗糙、2 色以内；无渐变、无高光、无发光。
- 圆角小（3–6px），纸质感颗粒可选；标签页、进度条（锈红/赭黄/鼠尾草绿）、气泡对话框见 `ui-04-component-kit.jpg`。
- 字：使用现有字体，保持可读性；游戏内文字以本地化为准。

## 14. 家具、车辆与货物建模标准（大致定稿，2026-11-26，待实现）

### 14.1 总原则

- 画风：等距手绘水粉，哑光，粗暖棕描边，表面只有轻微笔触纹理。**不要**塑料光泽、像素风、写实 PBR 反光。

### 14.4 车辆

- 概念图：`concept/props/concept/vehicles.jpg`，包含轻行、逐风R、载星、雷豹、宏途、小货王、家悦、苏七、718、星矢、赤焰、出租车。
- 价位越高车越新、越干净；低价车可以有锈点和车身补漆，跑车干净、反光克制。
- 现在所有汽车都是同一个 `ParkedCar` 缩放，建模时至少要拆成：轿车、厢货、跑车、出租车四种车身；摩托分踏板车和带货斗三轮。
- 出租车保持黄色，车顶灯牌和侧面“出租车”字样。
