## 0. 一句话

**像素感偏重的手绘老城**：厚实、做旧、灰暗偏暖的中国老城区日常生活；细深棕描边；一切像被生活磨过——脏渍、剥落、褪色。**不是**明亮高饱和的卡通，**不是**二次元，**不是**P5 描边风。

## 3.1 密度原则（重要）

- 游戏里不会有拥挤的人群：街上同屏行人 3~5 个即可，不要做人山人海或密集摊位。
- 室内要整洁：家具对齐、地面大片留空、不堆杂物；杂乱感只来自墙面做旧和少量点缀，不靠堆东西。
- 路人模型（char-sheet-04-crowd）是供随机抽取的人物库，不代表同屏数量。

## 5. 渲染与打光（灯光是风格的一半）

目标：**暖、低角度太阳 + 可见的柔和阴影 + 压低的饱和度与对比**。当前原型里已经调好的一组（`DayNightLighting.PaintedLook`，见 §9）：

| 项 | 数值 |
| --- | --- |
| 主光色 | `#FFE0B3`，强度中等；低角度（约 45–50°俯角） |
| 阴影强度 | 0.72（要看得见，但边缘柔） |
| 天空补光 | 强度 0.36 |
| 反射补光 | 强度 0.30 |
| 环境光 | 平的暖灰 `#BDB3A3` |
| 雾 | 暖灰尘雾 `#C7B8A3`，近 70 / 远 300 |
| 色调映射 | Neutral（不要 ACES，避免拉饱和） |
| 饱和度 | −8（白天） |
| 对比度 | +8 |
| 曝光 | −0.1 |
| 颜色滤镜 | `(1, 0.94, 0.86)` 偏暖 |
| 暗角 | 0.2，深棕 |
| 颗粒 | 0 |
| Bloom | 0.12，阈值 1.1（只让窗灯/路灯微微发光） |
| 分色 | 阴影偏冷灰 `#808594`，高光偏暖 `#948A75` |

夜晚/雨天：整体压成深蓝灰，**暖色窗灯与路灯是唯一高饱和点**；湿沥青反射暖光；参考 `scene-04-night-rain.jpg`。

## 6. 材质与质感

- **所有物体统一的手绘质感**：世界空间/物体空间的程序或手绘贴图，带点染笔触、脏渍、剥落、水渍、裂纹；不使用光滑 PBR、不使用渐变。
- **明暗：两档色阶 + 柔阴影**（暗部是亮部的暖灰偏紫，约 `×0.74, 0.70, 0.78`），亮暗交界用小范围平滑。
- **描边**：细、深棕，固定像素宽（约 1px，物体可略粗到 1.2px），**不粗、不黑、不做速度线**。地面/路面不描边。
- 墙面：灰米抹灰，斑驳，底部返潮泛脏，雨水顺窗台流下的竖向脏痕，局部露出砖色。
- 铁栏：圆杆，深棕锈色，带螺栓头。
- 布料：有织纹、磨白、污渍；围裙、床单有褶皱和厚度。
- 木头：干裂、边缘磨圆。

## 7. 建模规范

### 7.1 建筑

- 居民楼 4 层为基准：层高 ≈2.7m，首层架空基座 0.5m；面宽按 2.7m 的开间模数排窗。
- 大瓦屋顶（棕红）+ 女儿墙，屋顶放水箱、天线、杂物、楼梯间。
- 正面构件库（见 `asset-sheet-buildings-props.jpg`）：铁栏窗、带空调窗、阳台+晾衣杆+花盆、卷帘门+小瓦檐、青绿雨棚店面（货架、柜台）、单元门（台阶、信箱）、外挂排水管、楼梯。
- 窗：过梁 + 凹窗 + 窗框 + 窗台及托架 + 竖向污痕；窗内有窗帘或暗色。
- 底层贴街：纸箱、盆栽、电动车、三轮车、塑料凳、垃圾桶、水洼。
- 电线杆 + 电线（下垂弧线）：沿街 + 连到楼上。

### 7.2 地面与绿化

- 草地：深橄榄，斑驳点染，局部偏黄，不要纯色平铺。
- 道路：深沥青，芥末黄虚线，白边线，微裂、油渍、碎石；**路缘与人行道的方砖要有缝**。
- 树：圆形分层树冠，两到三层 + 顶冠，每个团块**两色点染**（暗在下、亮在上），团块要圆润柔和而不是多边形硬面；有树干、根部外扩、2–4 根枝杈。树冠约 4.5–5m 高。
- 灌木：低矮团块，同色系；偶尔带小花。

### 7.3 人物

- **比例：约 3.8 头身**（略微 Q 版，但不要大头娃娃）。身高 1.52–1.72（房东最矮，酒保最高）。
- 脸：**小圆点眼 + 一点高光**，小眉，小鼻，淡淡腮红，小嘴微笑。不要大眼睛、不要二次元反光眼。
- 头发：近黑，成束的发片，有体积；每个角色发型明确（见 §7.4）。
- 手：有手掌+手指（至少拇指+一组手指），**不要球状手**。
- 脚：鞋有鞋头/鞋带/鞋底厚度。
- 衣服：有袖子/裤腿的粗细变化、肘膝褶皱、领口袖口罗纹、口袋盖、纽扣；**布有厚度**，不是贴皮。
- 动作骨骼：髋、膝、肩、肘 4 对关节够用；站立 / 走路 / 双手交叠（房东）。

## 8. UI 风格（早期方案；按钮与色彩以 §13.6 为准）

- 面板：奶油纸色 `#EFE8D8`，次级带 `#E3DAC4`；细深棕边 `#6B5E50`；**硬边的浅棕投影**（偏移 2px，无模糊）。
- 顶栏/页脚：深暖褐 `#4A4238`，凹槽 `#352F28`，边 `#2A241E`，文字 `#F1EADA`，强调金 `#D9BC7C`。
- 按钮：主按钮芥金 `#D9BC7C` + 深棕字；次按钮奶油 `#F3ECDC`；危险按钮砖红 `#A5604A`；禁用灰。
- 强调色：锈红 `#9C5A44`；正向 `#5C7A5E`；警告 `#A5604A`；次要文字 `#6E675C`；正文 `#3A322B`。
- 图标：扁平手绘、边缘略粗糙、2 色以内；无渐变、无高光、无发光。
- 圆角小（3–6px），纸质感颗粒可选；标签页、进度条（锈红/赭黄/鼠尾草绿）、气泡对话框见 `ui-04-component-kit.jpg`。
- 字：使用现有字体，保持可读性；游戏内文字以本地化为准。

### 12.1 总原则

- **只有城郊是旧、黄、做旧的**。社区开始干净中性，公园、花园逐级更现代、更科技、更高级，但不用霓虹、不闪、不花。

|---|---|---|
| 强调 琥珀 | `#B8812A`（边 `#8A6120`，白字） | 每个界面最多一个主操作：确认、开始、前往、购买、租赁、保存 |
| 次要 中性暖灰 | `#7A7268`（白字） | 返回、取消、关闭、离开、筛选、改价、涨价/降价等其余按钮 |
| 警告 红 | `#B23A32`（白字） | 不可逆或有损失的操作：删除存档、放弃、退出游戏、强制结束 |
| 禁用 | `#9B948A` | 条件不满足：形状不变，降低对比，不再换颜色 |

- 取消的样式：陶土红主按钮、鼠尾草绿次按钮、靛青/松石等第三种彩色、涨价红/降价绿按钮（价格涨跌用文字颜色表达）、作弊按钮的红色（改中性灰）。
- 一屏最多一个琥珀按钮；两个同级操作时，一个琥珀一个中性灰，不用两种彩色。
- 不算按钮、保持原样的颜色：状态绿 `#6F8B72`（营业中、可用等标签文字与进度条“好”档）；信息蓝灰 `#5F7886`（通知/提示标题）；地图上的地点标记与路线；数据图标（涨跌箭头、医疗十字等）。
- 页签选中用暖炭，列表选中用琥珀描边；顶栏、底栏仍为暖炭 `#3A3733`，纸面 `#EFECE6`。
- 概念图已同步重做：`concept/ui-redesign/target/`、`compare/` 右半、`unified-ui-kit.jpg` 和 `concept/ui-windows-v2/`。这是在原概念图上按按钮区域换色，图里残留的红色（图标、选中框、提示条）以本节规则为准，不是设计稿。

## 14. 家具、车辆与货物建模标准

本节使用 2026-11-26 确认的八张概念原图。单门和双门冰箱均按干净版执行。现行实装范围和取景方式见 §14.7。

### 14.1 总原则

- 画风：等距手绘水粉，哑光，粗暖棕描边，表面只有轻微笔触纹理。**不要**塑料光泽、像素风、写实 PBR 反光。
- 轮廓要一眼认出是什么：保留现在的比例和占地，只补细节（把手、门缝、踏板、灯、屏幕、图案、包装印刷）。
- 颜色沿用现在的主色（床品、车身、商品包装），不要改色相，只加明暗和少量笔触。
- 概念图是方向，不是三视图。尺寸、占地、朝向以代码为准（`FurnitureCatalog`、`RoomSpec`、`MotorCatalog`）。图里的中文有乱码，名称以本地化文本为准。

### 14.2 旧与新（磨损规则）

- 磨损用来表现档次，不是所有东西都画旧：
  - 可以旧：城郊低档家具（硬板床、塑料矮凳、折叠桌、布衣柜）、低价二手车和三轮车、老旧货架。表现为轻微掉漆、锈点、补丁，不要脏污堆叠。
  - **冰箱（单门、双门）必须干净**：表面平整的米白或浅灰，**不要**锈迹、划痕、污渍、掉漆、磨损的边角，把手整齐。其他家电（电饭锅、空调、落地扇）同样保持干净；“坏电风扇”是剧情物件，可以旧。
  - 新、贵的东西一律干净：实木床、实木衣柜、沙发、书桌、跑车、商品包装。
- 同一个家具在不同价位只换材质和旧程度，不换造型。

## 15. 事件 CG（Resources/EventCg，共 43 张）

- 构成：场景底图（JPG 质感 PNG，16:9 约 1024）+ 道具抠图 prop_*（最长边 768）+ 人物抠图 person_*（最长边 1024），由 GameUi.EventCg 运行时叠加，人物无专属图时回退到立绘。
- 场景 10 张：开场到达/饥饿、商铺/住宅租金、公园划船、旧货集市（钟表/唱片）、社区介绍，以及食物特写 prop_hotpot / prop_tastingrice。
- 道具 28 张：统一水粉描边，无地面投影，透明底；人物 3 张（res_coder、res_coder_seated、zhang）。
- 画面规则：不出现文字与标签；脸必须画完整；家电与厨具保持干净；环境光由代码染色（停电/应急/烛光/傍晚/雨）而不是烘进图里。
- 抠图流程：灰底生成 → 边缘泛洪去背景 → 扩 3px 去光晕 → MinFilter+高斯 0.8 柔化 alpha → 按包围盒加 3% 留白缩放。替换 PNG 时保留原 .meta。
- 样图：concept/cg/（10 张标准样图）。
- NPC 无专属抠图时的运行时去背景（ScenePortraits.RemoveBackdrop，对全部 179 个立绘离线验证过）：
  1. 取立绘上方两角的底色，从上边与左右边按严格容差（18）泛洪；底边不作起点，否则白大褂会被吃掉。
  2. 清除被头发/轮廓围住的封闭底色小块（≥6 像素）：平整、接近底色、四周深色占比 ≥ 60% 才删，白衣服的阴影不会误删。
  3. 沿轮廓再吃掉 3 像素浅色光晕。
  4. 解混：轮廓 12 像素内、接近底色且 7x7 邻域里 ≥40% 是强色（头发/轮廓）的像素，颜色换成邻近前景色，alpha 取与底色的混合比例——专门处理发丝间的细缝和发梢。
  5. 透明像素的颜色向外扩散为前景色（防止双线性/mipmap 采样把灰底混回来形成白边），alpha 做 σ0.5 柔化；最后 5% 行渐隐。
  - 立绘导入上限为 1024（NpcPortraitImportRules）；512 会把发丝糊进灰底，抠出来必有白边。
  - 立绘新底色为 #E6E6E8 附近的中性灰；换底色、加渐变背景或出现黑边（曾有 life_leisure_staff_ktv_tier3_day 左右黑边）时要重新检查。
- 已知小问题：person_res_coder_seated 比旧图多了挂绳和手表细节。
