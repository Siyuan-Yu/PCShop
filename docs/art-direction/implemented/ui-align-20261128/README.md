# UI 设计稿与 Unity 实机对照

[逐页对照](index.html)覆盖 §19 的 39 张设计稿、证券交易所和全屏居家工作台六页，以及 §20 的开始界面与子窗口。街道 HUD、「我的」保留 1920×1080 原图。开始界面用有存档和无存档两种状态分别复拍了 1920×1080 与 1280×720。

复拍采用 Unity 的实际界面代码、场景与存档结构。截图使用隔离存档，后期证券页面通过花园已开放的取样状态生成真实现货和做空持仓。时间、物品、门店和持仓数据随取样状态变化。

- 正式界面改用 67 张独立透明 PNG。移除运行时资源目录中的 6 张旧整页图集及导入元数据。编辑器从美术设计目录读取切图源稿。[图标接触表](../../../previews/ui-icons/index.html)
- 当前仓库包含定稿的湖城封面。开始界面按 §20 使用 PETSHOP 标题文字，等待独立的正式 Logo 贴图。
- 柜台统计字段与经营系统一致。冰箱、居家工作台以现在的实际入口为准，§19 的两张旧住处示意仍可在对照中查阅。
- 本次记录 Unity 编译和截图结果。95% 目标仍待整体验收，EditMode 用例本轮未运行。
