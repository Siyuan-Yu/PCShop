# 品牌代言人与KOL统一

2026年11月6日。品牌代言人就是品牌签约的KOL：一份合约同时提供品牌直播排班和展会邀请资格，不再分别签代言和直播合同。本篇替代第64、65、71、72篇中两套长期合作并存的说明。

## 入口与规则

- 品牌顶部为品牌总览、短期推广、展会、企业竞标、代言人（KOL）。代言人页包含代言人与排班、代言人市场、专场记录。展会缺人时直接跳到同一个代言人管理入口。
- 招募流程已由[第76篇](76-mcn-agency-recruitment.md)修正：代言人市场先选MCN公司，再实际前往对应公司人事接待，办理介绍、认识主播并查看合约，不能从品牌面板直接签约。人事洽谈页保留头像、属性及费用对比。初/中/高级名额仍为3/7/12，90天独家代言；新签约不能重复签同一人。
- 一次签约费加动态日薪，取消这份合约额外的营业额2%分成；暂停直播仍计薪，解除时结清未付工资，已付签约费不退。参展另按原规则计算每日站台溢价，展示的总日酬包含基础日薪。
- 原每人独立排班、跨午夜、每天/隔天/每周、直播间、打赏、公共直播与专场结算规则保留。品牌直播通过现有直播效果和专场结算发挥作用，不再额外叠加旧代言的常驻客流奖励。
- 展会只邀请本品牌已签约且合约覆盖全部四天的代言人。签约不等于自动参展，报名时必须选入名单；未邀请的人不自动赶来。人数、工资、实际到场、舞台显示共用所选名单，避免出现两批人物。正在站台不能解约。
- 短期推广仍是独立7天广告服务，不提供直播排班和展会资格，界面不再提供第二种90天代言方案。

## 已有存档

读取旧档时，有效旧代言免费接入统一合约，保留原到期日、已付费记录和故事关联ID；不再收一次签约费，不追收过去未产生的日薪。新的日薪从本次载入起计算，旧暂停状态保留。

同品牌同一人若以前同时签过代言和直播，只保留一份实际管理/日薪合约：保留直播排班和处理进度，到期日取两份中更晚的日期。过去两笔已付费用不自动退款，旧财务记录不改写。重复读档不增加合约、不重复收钱；到期/已解除的旧代言不复活。

旧代言超过新名额的已付权益保留，新增签约仍检查容量。旧非独家、跨品牌合约保留原权益，不自动退款或删约；它们属于兼容存档情形，新签约使用统一独家限制。

内部旧BrandDeal仅作为故事/历史引用关联同一份合约，不再单独收取分成或加常驻客流。解约同步结束旧引用，避免故事仍把已解约人物当成在约。
