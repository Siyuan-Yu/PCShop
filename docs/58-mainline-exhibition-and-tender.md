# 后两章主线接入品牌经营（2026-11-04）

> 历史交付记录。当前唯一主线路线、季度展会规则及验收入口以[当前主线规则](story-and-district-progression.md)为准；本页早期费用、样品数与旧流程不再适用。

## 第二章：社区 → 公园

前置沿用社区6家实际开业门店、净资产3000万元、已创立行业品牌。达标后3游戏日主动联系；若邀请到期时睡着，按实际醒来后两小时发出。

1. **品牌第一次正式亮相**：任帆联系玩家，与唐蔚实际会面；选择本次引荐的品牌，接受后固定。
2. **把门店带到展台**：进入该品牌季度展会页，支付2000元、交3件真实样品并报名。
3. **让买家记住你**：展会当日进入会展中心，完成三轮接待。员工和嘉宾沿原参展机制实际到场。
4. **展会散场以后**：用真实库存发出20件展会线索订单，等客户收到并结算；同一品牌影响力达到100。
5. **展会之后的交付**：再与任帆、沈远实际约见，核验本品牌的参展和交付记录后开放公园。

## 第三章：公园 → 花园

前置沿用已开放公园，某个品牌所属行业的所有自营门店上一个完整月实际营业额达到1亿元。资格在等待邀请时记住所属品牌，不因邀请跨月改成别的行业。上市、股价系统仍不作为尚未实现的硬门槛。

1. **席位只有一个**：沈远联系玩家，与袁岚实际会面，了解原供应商占据席位的局面。
2. **摸清采购方与对手**：报名年度竞标，分别联系沈远核实需求、袁岚调查原供应商；已经赢得席位的既有真实记录可以承接。
3. **让试单替你说话**：提交报价与保障方案，实际发出并交付10件试单。
4. **挤进供应商名单**：试单到货后评审，超过原供应商评分才算取得席位。
5. **把席位坐稳**：同一份合同连续三期，每期30件；沿原规则按周期推进，发货不算到货，不能用不同合同拼三次。
6. **用交付赢得席位**：与沈远、袁岚再次会面，实际完成推荐后开放花园及机构资源合作。

## 交互与判定

- 手机聊天顶部「主线消息」展示当前品牌、阶段清单和实时业务数据。中间经营阶段不用反复约见。
- 按钮直达选定品牌的季度展会／企业竞标页，经营页也能返回主线。
- 报名、现场接待、到货、评审和分期履约均读取原经营记录；不通过看说明、刷新界面或聊天凭空生成收入与影响力。
- 中间目标达成后自动进入下一步，最后道路解锁仍要求实际会面。
- 展会失约、订单逾期、竞标失败或履约丢席位会提示下一季度／年度重试；不清空品牌、不越级开路。
