# 品牌、推广、展会、企业竞标与机构资源：首版可玩流程

> 本篇保留当时的交付记录。当前玩法和入口见[第72篇完整归档](72-current-game-content-2026-11-05.md)。

日期：2026-11-03。对应用户确认的五项玩法。本篇记录首版，后续正式姓名、人物故事页及KOL日常动态调整见[第55篇](55-npc-formal-names-and-brand-stories.md)，两部分源码一并归档。未生成 Windows 包。

入口：**经营 → 品牌**。沿用现有横向经营工作区，分为品牌、推广与代言、季度展会、企业竞标、机构资源五页。家中工作台打开同一经营工作区，可使用这些远程管理操作；到场参展仍要求玩家实际进入场馆。

## 1. 创立品牌

- 首版支持电脑、服装、模型三个行业，一个行业一个品牌。
- 进入社区；同业至少5家已布置门店，其中城郊至少3家、社区至少2家。
- 城郊近30天实际门店营收连续14天超过同行营收基准；社区两家门店持续经营30天，期间每次日结核对最近7天有营业收入。
- **同行指标目前是明确标注的市场估计基准，不是全城NPC门店逐单结算排行榜。** 基准按行业与月份变化，界面同时列玩家实际营收，避免将估算冒充NPC真实账本。
- 达标后唐蔚发出消息；输入2—16字品牌名，选择实惠或品质定位。品牌页可增加或退出同业门店，至少保留一家。
- 品牌影响力、口碑、推广和机构合约实际影响加盟本品牌门店的客流，仍需要商品、货架、价格和工作人员才能成交，不直接生成营业收入。

## 2. 推广与代言

- 复用莫莫、阿可、乔乔、陆栀、温岚等真实人物。不同人物与电脑、服装、模型行业的受众适配不同。
- 七天推广；90天代言；独家90天代言。固定费用签约时扣款，代言另按品牌门店实际营业额每日收2%分成；交情可降低固定报价。
- 独家合作会阻止同人物冲突签约。签约记录业务关系和联系方式。
- 人物事业消息独立于签约推进；首版使用轮换事件：获奖、稳定发布、尚待核实的作品争议、已核实的重大商业争议。获奖提升曝光，争议影响客流与口碑。
- 可以继续、暂停、核实协商或解约。暂停不退固定费、分成义务保留；每条新风波只能核实协商一次，费用¥200；普通提前解约支付剩余固定费30%，重大已核实争议可免解约费。提前解约、协商和风波后的继续合作会影响关系。
- **当前是明确的合作套餐与交情报价，不是自由输入合同条款的谈判编辑器。** 事业事件是首版规则化内容，尚不是完整娱乐产业模拟。

## 3. 季度展会

- 云帆会展中心保留原ID，移到社区—公园连接路的社区一侧，未开放公园也能到达。更新地图生成器，并通过道路连通、建筑重叠及湖面检查。
- 每90天一届，展示主题轮换，展前7天截止报名，展日09:00—17:00接待。
- 选择品牌、实际供货门店、同业现货商品、主接待方向。¥2,000支付展位/运输/基础展务，3件商品从真实库存中扣除作为展示试用耗材。
- 可安排来源店一名员工，另付¥200出勤交通补贴；可邀请一名交情至少20、未受雇的行业嘉宾，接待预算¥500。
- 当天06:00起人物沿真实路线赴展，已有采购或活动先完成；员工离店参展期间不同时承担门店工作。到场人员提供接待加分，迟到者不能隔空加分。
- 玩家必须实际在会展中心处理三轮接待，每轮间隔30游戏分钟。采购、媒体、设计三个方向与准备方向、品牌定位、到场人员及展务赞助共同影响评分。
- 完成展会取得影响力和一笔20件采购线索订单。14天内安排真实库存发货，货车按道路运输；到货结算后再获得70点影响力。重复点击不重复扣款、扣货、付款或加影响力。
- 错过展会不清空品牌，但本届费用及耗材不退，下季度可以重报。展会订单逾期损害口碑。

## 4. 企业采购竞标

- 公园开放且品牌影响力达到100后，一个品牌每个360天年度可报名一轮，报名/检验¥1,000。
- 来源店和商品来自真实现货；相应行业有具名原供应商。
- 通过统一NPC聊天界面向沈远核实需求、向袁岚调查对手，各花费¥200，每项只记一次情报。没有联系方式时先找本人。
- 报价套餐：低价（商品市场参考价75%）、均衡（90%）、服务（100%）；可另付¥1,000联合履约。试单报价锁定。
- 原供应商会回应首次报价，并在玩家追加合作保障后再次回应。玩家可追加联合保障，不能反复领取分数。
- 先实际交付10件试单，再提交评审。分数包含需求了解、同行情报、方案、合作保障和试单履约，界面展示自己与对手的评分及结果。
- 中标后连续三期，每期30件、30天交付窗口；需要真实进货、库存与货车运输。不能一次点三次立即完成三期。逾期失去席位，连续完成后获得企业推荐。
- 货车运输按现有路线规划计算时间，运费¥30；库存发货时扣除，款项到货时进入来源门店账本。无法按期到货时拒绝发货，避免扣货后制造无解状态。
- 当前运输复用路线及时间计算，不额外新增地图货车模型。报价和评审为首版公开规则，尚无开放式合同条款编辑、诉讼或无限轮竞价。

## 5. 花园机构资源

- 到达花园后显示“人物 → 机构 → 渠道”的关系说明：澄光传媒与三位创作者、云帆展务与任帆、联合采购与沈远。
- 支持制作¥5,000、季度展务赞助¥10,000、独家渠道¥20,000；均为90天有限期合约，不能重复叠加同一资源。
- 制作支持每周补充创作者资源，并带来曝光；展务赞助增加展会接待效果；独家渠道增加触达并占用该渠道合作位，其他品牌不能同时签它。
- 这些机构目前作为合约关系存在，不新增实体建筑或人物。不会凭空产生投资回报，也不能付钱直接操纵所有人物、制造丑闻或保证销量。

## 主线衔接与兼容

2026-11-04：中间阶段已扩充为连续主线，具体以[第58篇](58-mainline-exhibition-and-tender.md)为准，包含报名、现场接待、交付、调查、评审及三期履约的实时追踪。

新品牌路线：

1. 社区至少6家实际开业门店、净资产3,000万元并创立品牌，进入邀请计时。任帆与唐蔚在会展中心发出邀请。
2. 同一个品牌达到100影响力，并真实完成至少一笔展会线索订单，实际约见验收后开放公园。
3. 某个品牌所属行业的所有自营店，在上一完整月实际营业额达到1亿元，下一月触发企业合作邀请。统计按门店归属行业，包含真实交付的品牌订单。
4. 赢得年度席位并完成三期履约，实际会见推荐人后开放花园机构合作。

已开始的旧社区合作、模型寻物和公园试点主线保留，不强制改写存档或取消既得道路权限。新节点记录在原主线消息中，可导航、约见，单纯打开品牌页不会推进主线。

**上市与自有股价系统本轮未扩做。** 为使首版新玩法在正式运行中可达，上市/股价不作为新品牌路线的硬门槛；旧编辑器验收入口及其独立测试事实保留。此前第48、52、53篇中的旧第二、三段说明属于兼容路径，不能误认为本轮新路线仍强制模型委托。
