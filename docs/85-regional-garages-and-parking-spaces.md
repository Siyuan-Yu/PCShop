# 四区车库、车位与车辆用途（2026-11-07）

## 公共车库与车位

城郊、社区、公园、花园各有一座公共车库，紧挨对应赛场的接待建筑。地图只增加6×5米的小型附属门面和步行连接，不扩建大型停车岛、不更改已有赛道和道路节点。到建筑门口按 F 打开车库管理。

公共车库建筑不可租赁、不可购买、不可转为玩家物业。玩家租用或全款购买的是其中的车位，可以重复增加，供应没有游戏上限。每辆入库车占1个已持有车位；员工借用、赛车期间仍为其保留原车位。

| 片区 | 每个车位租金／30天 | 每个车位全款购买价 |
| --- | ---: | ---: |
| 城郊 | ¥50 | ¥5,000 |
| 社区 | ¥150 | ¥15,000 |
| 公园 | ¥400 | ¥40,000 |
| 花园 | ¥1,000 | ¥100,000 |

车位数量支持直接填写，另有1、5、10个的快捷选择。自有车位不收租，租用车位每30天自动续费。同一车库追加租用车位时，本期按距下一次续租的剩余天数计费，之后统一续租日。可以退租空闲租用车位，已付租金不退；已停车辆不可因退租失去车位。购买车位与租用车位可以同时持有。

## 通勤与入库

车辆各自保存编号、型号、车况、改装、停放车库、通勤身份和扣押状态。小电驴、三轮车、轿车各可以指定1辆通勤车；首次购入这三种出行类型默认用于通勤，免车位。通勤车不能参加竞速或免费练习。货车仅供员工进货，不可通勤或参赛，也不占车位，见[赛程与进货货车](87-race-meetings-and-logistics-trucks.md)。

想用当前通勤车参赛，需要先到车库将它改为入库车辆，占用本区车位；可以同时换另一辆同类型车辆通勤，也可以暂时取消该类型通勤。将入库车设为通勤车时，原通勤车停入该车刚腾出的本区车位。正在出行时不能换用途；当前载货超过步行上限时不能取消正在使用的通勤车。

车行的购买确认只增加“车辆用途”：用于通勤，或停入所选片区车库。替换原通勤车时，要为原车选择空余车位。未持有车位或空位不足时不会扣购车款。二手车行展位转为自用也使用这套用途与车位校验；商用展位库存独立于个人车位。

## 页面和分类

车库、比赛、免费练习的分类顺序固定为“小电驴 → 三轮车 → 轿车”；车行购车与整备单独使用“小电驴 → 三轮车 → 货车 → 轿车”四类。资产车产页的进货货车为全城独立车队，不归入地区停车库存。

- 车库管理：车位租购、空闲位退租、通勤切换、本区车辆、从其他车库调入。不提供报名、开始练习、开始比赛、前往赛场按钮。
- 赛场接待：在原页面按分类选择本区入库车辆，直接点击开始免费练习或竞速比赛，不另开选车窗口或额外报名流程。
- 资产：先选择“经营中的店铺／我的物业／车产”；只有“车产”内才显示四区与车辆分类。查看通勤车辆、地区库存、车况、参考残值、自有与租用车位数量、车位价值、租金及续租日。资产页不直接管理车库；可在位置图定位公共车库。
- 车行整备：保留改装、维修、回收和赎回，移除旧的全城“我的车库”快捷入口。

## 付费调运与占用

调车入口在车库管理、赛场比赛和免费练习的原页面里。先选来源车库，再选当前分类的车辆，确认费用后调入当前片区；不另开报名流程。调运按委托服务即时交车，不推进城市时间。

调运费为 `¥100 ×（1＋两片区等级差）`：相邻片区¥200，跨两级¥300，城郊与花园之间¥400。调运前检查目标片区权限、实际已持有空位、现金以及车辆占用状态；未成功不扣款。调入后会在当前页面自动选中该车。

通勤车须先入库，不能直接跨区调运。员工正在使用、参赛中或被扣押的车不能调运、出售或切换用途。员工采购记录实际车辆编号，归还或扣押均对应具体车辆，避免一辆车同时被员工与赛车使用。

城郊练习场继续24小时开放，其余三个赛场9:00—18:00；车友仍在9:00—18:00出现。公共车库全天可交互。

## 收支与存档

车位购买按资产购置记录，其参考价值进入玩家净资产；车位租金、调运费记录为个人支出，不冒充门店经营利润。未来现金预留包含所选日期范围内的车位续租。

车位数量、自有与租用性质、续租日期、车辆用途、停车区域及扣押状态一起存档。赛车验收档配9辆车（2辆通勤、1辆员工进货货车、6辆分布四区）、四区各6个已购车位、6胜场及真实二手车行；资产验收档配城郊租用6位、社区自有6位、2辆通勤车、1辆员工进货货车及3辆入库车。验收档里的6位只是初始数量，不是车位上限。未给正式新游戏赠送车位或车辆，不为上线前旧档额外制作迁移流程。
