## 已确认修复及实测结论

前几轮修复了读档时 NPC 错误离岗、数量控件初始化空引用、等待中的主线邀请丢失、旧货市场虚假待领取物品、音响调试主持人值班判定等问题。业务修复与测试夹具更新分开记载，具体原始用例见 158、159、162。

性能侧已接入休息分帧推进及中途写档保护，优化寻路、静态客流地理计算、服务节点查询、静止路线预览、HUD 分散刷新和人物池；人物共享资源在加载阶段预备。睡眠、昏倒、住院三个完整存档结果与优化前逐字一致。

最新 RTX 3070／1080p 编辑器巡检覆盖城郊、社区、公园、花园、赛场、店内、家中、读档后城郊、花园 4× 及睡眠，共十个样本，运行错误和采样到的材质／着色器异常为 0。核心数据：

- 读档解析与核心恢复约 28.62 毫秒，总转换约 80.62 毫秒；仍是同步恢复。
- 花园 4× 最长帧约 32.50 毫秒，其中模拟最长约 25.43 毫秒；人物显示更新最长约 2.54 毫秒。
- 睡眠约 4.64 秒，持续渲染 730 帧，最长帧约 14.39 毫秒，正常结束于次日 08:00。
- 人物预备使首次进城加载约从 3.79 秒增加到 6.35 秒，城郊 Unity 总分配读数约从 1,663 MiB 增至 1,804 MiB；这是加载时间与常驻资源换取游玩时较少卡顿的取舍。

**整个游戏稳定 120 FPS 尚未达标。** 最新正常室外 P99 约 8.36–9.39 毫秒，花园 4× 约 9.98 毫秒；120 FPS 每帧预算约 8.33 毫秒。平均 FPS 超过 120 不等于完成验收。数据、截图、脚本版本、源码指纹均见 [162 证据目录](validation/2026-11-27-performance-followup/README.md)。

## 测试结果应怎样理解

最新专项续修覆盖 199 个不同用例，各用例最新结果均通过；其中最后一轮只重跑了变化的 15 项活动用例，不是一次全项目 199 项同时通过，更不是全项目所有测试通过。

此前 158 的广覆盖与定向分层记录仍有 143 个未通过项。后续专项修复了其中一部分，但本次没有重新计算全项目最终未通过数量，也没有重新跑最终全量。因此不能用 199 项专项通过覆盖历史待复核清单，不能声称全游戏无 Bug。游戏性报告中的预算和路线检查也不能替代完整通关实玩。

历史资料保留失败和中止记录，不删除失败轮次来美化结果。主要证据目录为 `docs/validation/2026-11-27-multiround/`、`2026-11-27-repair/`、`2026-11-27-performance/`、`2026-11-27-120fps-acceptance/` 和 `2026-11-27-performance-followup/`。

## 换设备接续

1. 拉取 `art/experiment`，核对最新提交及本篇，不要误用回退过的 `main` 作为此次性能和功能交付。已有本地改动先保留，不执行硬重置。
2. 用 Unity 2022.3.6f1 打开工程并等待资源导入。项目资源、脚本、元数据、文档及证据都随 Git 交付。
3. `Assets/Generated/CityBake/` 是 `.gitignore` 中的派生地图缓存，不随 Git 上传；当前缓存格式为版本 16。换机或缓存失效时可在独立工程执行 `CityMapBaker.RunBakeOnly` 重新生成，再检查加载阶段日志。这是资产预生成，不是发布打包；不生成缓存时会退回现场建图，不能直接拿加载时间与本机缓存结果比较。
4. `Library`、`Temp`、完整编辑器日志、用户设置、玩家存档和临时镜像不上传。完整存档对照所需的是证据目录内专门生成的合成夹具，不是个人存档。
5. 后续运行测试仍需遵循 `AGENTS.md` 的当次授权规则。复现入口与隔离参数见 [性能证据 README](validation/2026-11-27-performance-followup/README.md)，本机临时路径可替换为新设备路径。图形巡检与 CPU 回归串行执行。
