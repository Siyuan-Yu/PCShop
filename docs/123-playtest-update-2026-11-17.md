# 《街角起家》试玩更新与工程交接

记录于 2026 年 11 月 17 日。本文汇总本轮源码、资源和玩法规则。完整游戏内容见[上一版玩法总览](122-current-game-content-2026-11-16.md)，同一系统有更新时以本文为准。原有主线、地图、门店类型、赛道、事件编号和操作入口可从该总览查阅。

## 门店经营、库存与采购

| 功能 | 当前行为 |
| --- | --- |
| 餐馆订单 | 餐馆的相应页签显示「订单」，包含鱼餐预订和堂食桌单，可以从柜台直接进入。堂食操作仍可在柜台办理。 |
| 鱼餐优先 | 厨师先做能备齐的鱼餐预订，按交期排序，再处理普通桌单。可做的预订优先预留米、配料和指定鱼。缺货的预订让出灶台，手动备料也遵循预留规则。出锅后由玩家交付收款。 |
| 鱼餐报价 | 按菜单当前菜价加指定鱼种加价，再乘 2。存档中尚未结算的旧报价于载入时翻倍一次。名望和交期按原订单规则计算。 |
| 饮料供应 | 农贸市场可批发可作堂食加购的饮料。现场采购、采购目录和员工进货共用供货规则。买回后可上架，餐馆定价显示饮料库存、售价与加购效果。 |
| 冰箱 | 四档容量翻倍为 **120／240／480／720 千克**。价格依次为 ¥1,299／2,799／5,299／7,999。家里和各门店各自计算已摆放冰箱的容量，旧存档也使用新容量。 |
| 采购数量 | 线下商店及批发、网购、定期采购、补货上下限和直供等选量界面加入滑块，同时可输入精确数字。拖动时可预览数量，松手后应用。选量沿用起订量、单品上限和分档规则。固定采购仍可单独设为「最大」，每次采购时按当时可买量计算。 |
| 员工详情 | 展开员工卡可看到智力、魅力、动手能力和体力，以及当前岗位的工作效率、班次和工资。招聘入口按钮使用「贴招聘告示」。 |
| 店员动作 | 同时工作时，厨师各自使用可用灶台与操作位置，并显示烹饪或出锅动作。服务员按任务显示上菜和清桌动作。实际接手装机的员工在装机台做装机动作，其他员工有独立的待命位置。 |
| 二手店销售员 | 在岗且在店的销售员会通过魅力提高二手转售品的购买意愿。魅力每点贡献 0.25 个百分点，全店销售员增益最多 25 个百分点。 |
| 营业额归属 | 销售流水绑定到该次开店的营业账户，同一地点重新开店也使用自己的流水。「今日营业额明细」、门店报表和经营统计按账户展示。旧存档先用收款凭据和开店记录核对归属，无法可靠归属的旧款项保留在总账。 |

## 手机、人物、邀约与活动

- **外卖**是手机自带应用，已拥有智能手机的旧存档也能打开。从应用里可按需点一餐，或设置缺饭时是否自动下单及所用档位。自动订餐沿用先吃现有可食用食物的规则，到实际下单时才支付选定档位的价格。四档为 ¥25、¥100、¥300、¥800。手动点餐和自动订餐共用价格、饱腹及各档附加效果。
- **手机设置 → 邀约**可选「更多邀约」「标准」或「免打扰」。更多模式把随机邀约的出现机会调至标准的两倍，普通事件的出现概率沿用原值。免打扰暂停新的主动邀约，已安排的日程可以继续。选项随存档保存。
- 开局通讯录内有 **陈志衡、林远航、唐俊杰、李秀兰、罗志勇、周国良**。其他人物在第一次当面交谈后自动加入通讯录，随后可主动邀请玩家。旧档里此前已打过招呼的人会补入通讯录。玩家主动邀请仍需与该人物达到 **10 熟悉度**。
- 「聊一聊」会在多次对话中聊到人物经历。「交流物价」会给出近期听到的风声，以及未来几天商品批发价、房价或个股可能的走向。风声取自当局的供应变化、档期和待发生企业事件。越贴近对应行业、档口或业务的人，越可能说对方向。同一天反复询问同一个人不会重抽消息。
- 一键赴约从开场前 **6 个游戏小时**开放，清晨的安排可以在前一晚出发。打开店铺或住处面板时，「接下来的安排」和「还款提醒」一起移到面板左侧，收起面板后回到右侧。进行中的赴约提示使用独立显示层，赴约导航时由它显示路线状态。
- 赛道观赛由沈知夏在玩家完成赛车登记且双方已经认识后发出。登记仍在城郊赛场车库办理，要求 **¥100,000 自有现金且无贷款**。旧档中登记前收到、尚未开始的观赛预约会自动取消，费用及关系维持原值。后续城郊引荐仍要求 **5 家开业门店、¥1,000,000 自有现金且无贷款**。
- 垂钓、球类、品尝及其他已接入的现场手操活动共用暂停流程。操作时外部世界时钟停住，短动作和现场走位照常显示，完成或主动结束后才结算约定或已用的游戏时间。夏澄的三杯试饮全部完成后结算 **90 分钟**。普通垂钓和球类仍按购买与使用次数结算。
- 提前结束时，按实做比例结算同行者的基础好感。一般按抛竿次数、球类和试饮回合、已完成的任务或活动用时计算。比如乔松同行垂钓完成 4／5 次，满额好感 +8，提前结束实际结算 **+6.4**。结算页显示所做比例和关系变化，全程完成奖励依然以完成条件为准。
- 垂钓时稳定把绿区跟住鱼，收线进度增加速度提高 **30%**。篮球松手后会看到出手动作、飞行弧线、球落下，以及「命中」「投失」或「被封盖」提示。运球和急停练习有各自的完成反馈，「董宇的新地板体验」默认选中跳投。

## 借贷、证券与物价

- 银行柜台和手机「周转借款」共用两步动作验证。选择金额与期限后，在角色画面按提示点头、摇头或招手。可拖动角色画面，也可直接点对应动作按钮。两步通过并确认后才放款，每次申请只放款一次。互动使用游戏内角色。额度与月单利、提前还款沿用总览中的规则。
- 证券交易所把「成本价」放在「我的持股」旁边，做空页显示「开仓均价」。现货成本按每股平均持仓成本显示，包含交易费用。可用现金和订单的现金净变动使用更大的数字和独立区域。
- 展开个股可在折线和 K 线图中查看自己的成交点。现货显示买入、卖出，做空显示开仓、平仓和强平。图上的标记使用实际成交时间、价格和数量，指向标记可看明细。符合条件的旧交易可从已有流水恢复。
- 个股每个交易日的价格，以上一交易日收盘为基准，日内涨跌上限为 **20%**。前 30 个游戏日，情绪与公司消息的影响系数分别为基础值的 2.4 倍和 1.5 倍。第 31 天起升至 4 倍和 2.25 倍。涨跌上限仍为 20%。除息按分红规则处理。
- 商品物价的小幅加强与股市分开计算。普通批发按行业加入最高约 ±3% 的基准波动，模型仍走上新周期，服装仍叠加季节。电脑配件常规变动的随机幅度从 0.05 提至 0.065，计划性供货冲击幅度为 7%–13%。地产两类周波动上限分别从 3.5% 和 2.5% 提至 4.2% 和 3%。物价看板和采购按实际报价展示。

## 显示、声音、出行和存档

- 主菜单标题使用 **《街角起家》**，英文为 **From Corner to City**。封面是无人出镜的风格化街区，表现从街角小店向城区扩展。标题和副标题使用菜单的中日英文资源。
- 保存和读取使用 **3×3 的 9 个存档位**。存档卡可快速查看游戏日期、所在地点、门店和余额。手动和自动存档可在同一局的格子内共存，覆盖时有确认。原手动档、自动档分别从第 1、2 格读取，继续支持备份回退。
- 新增 10 张物品图集，按商品 ID 映射 **247 个图集条目**，覆盖衣服、配件、手办、宠物用品、鱼、食材、餐食、家具、旧物及补充物件。车款复用对应车辆图。采购、购物车、员工清单、货架、仓库、背包、家居、礼品及相关活动的物品行使用同一套缩略图入口。
- 普通按钮的悬停颜色保持稳定，按下时提供一次状态反馈。按住鼠标、操作输入框、拖动滚动条或展开下拉时，等待该次交互结束再整窗刷新。打开弹窗清理原按钮焦点，空格不再触发 Unity 通用提交，避免重复叠开采购窗口。回车和手柄提交仍可用。
- 窗口首次出现时轻入场。营业额、证券成交、任务、邀约、赛车及展会结算使用数字过渡或分段出现。HUD 现金更新使用短数值过渡。动画使用实际时间，在暂停游戏时仍可播放。
- 下雨时室外出现跟随视野的雨丝，并配合光照变化。进入室内时隐藏雨效。简单音效覆盖界面操作、到账、提示、抵达，以及当前门店的顾客进门、未消费离开、结账、厨师烹饪和顾客用餐。音量和静音使用游戏设置。
- 小电驴、三轮车、货车和轿车的实际通勤型号影响手动行驶速度和沿路导航预计用时。通勤采用同车型内部分性能差距，入门车型保留原速度基准，竞赛仍按赛道性能计算。
