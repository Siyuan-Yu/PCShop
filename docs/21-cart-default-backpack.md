# 购物默认放背包（2026-11-01）

- 商品加入购物车时，按当前载具剩余承重与已预留的购物车背包重量，默认优先装入背包；只把放不下的部分分到叫车栏。
- 购物车顺序改为左侧“装进背包”、右侧“叫车送”。轻便家具与一般商品采用同一规则，步行装不下的冰箱等大件自然留给货车。
- 可继续手动“改叫车”、拖动两栏或全部叫车。再次加同种商品只默认分配新增数量，不把用户已选叫车的旧数量擅自搬回背包。
- 背包预留共用同一剩余承重，分配大米保留 0.25 千克精度；不会因为重复加购而超额分配。加购物车不扣款、不入库，仍在结账时统一支付货款和必要运费。
- 电话货车搬货清单不使用购物默认分配，原有装货规则保留。

本轮 **540/540 EditMode 通过**，无新增截图。新增回归覆盖小件默认背包及免运费结账、剩余 0.25 千克与重复加购、保留手动叫车选择，以及轻家具/冰箱的默认分配。原有手动分配和拖动测试改为先明确选择全部叫车，再验证手动搬回背包。
