# 住宅与商铺的每周价格行情

## 每周涨跌

新增四项独立行情：住宅售价、住宅月租、商铺售价、商铺月租。每7个游戏日更新一次，售价单周随机变化范围±3.5%，月租±2.5%；累计系数限制为初始基价的0.5—2倍。使用独立、可存档的随机数状态，不消耗顾客、硬件等系统的随机序列。

住宅仍按档次设基价。商铺仍由实际预计客流决定基价，售价以基准月租120倍计算，再乘售价系数；租金另乘月租系数，两种涨跌不会叠乘。

## 实际交易与租约

- 中介住宅、商铺的购买报价、新租报价与未签商铺挂牌随周行情更新；全款规则保留。
- 已签商铺租约、提前签约待交房租约、玩家住宅租约，以及持有物业的既有租金不随周行情重定价。重新租住或新登记出租时采用当周租金。
- 自有物业估值、出售到手和身家使用当前行情；出售保留估值九折规则。维护费继续按实际购入价计算。
- 住宅中介同时显示新租报价和当前租约月租，避免把市场报价误认为当期扣款。

## 物价简报

四项房产行情置于简报品类列表前部，可分别查看涨跌幅和折线，并参与综合走势。日记录使用同一组实际报价系数，周内保持不变，换周后体现涨跌。

按开发阶段要求，不专门迁移旧版物价记录；只读取当前完整品类格式。新建游戏与重新生成的作弊预置使用当前数据结构。

新增价格系数、周次、随机状态和住宅签约月租随存档保存，正常读档不会重新抽取本周报价。

## 作弊测试预置

城市生活作弊入口的“具体物业与投资”改为“自有物业与每周房产行情”：准备4处商铺、1套自住房及1套有实际NPC租户的住宅，覆盖自营、出租、空置与自住。全部通过全款购买接口生成，无房贷。预置8日报价样本，只抽取同一套房产行情并记录，不推进生活、工资或营业；入档即可查看四项周涨跌。样本之外的后续行情仍按正常周更新。

员工多店档与赛车档撤掉硬编码租金，改用当前商铺报价。品牌创建、展会和KOL预置原本使用正常租房/租铺报价，无需改造其玩法。已有测试槽可重新点击相应预置生成，无需维护旧版本兼容。
