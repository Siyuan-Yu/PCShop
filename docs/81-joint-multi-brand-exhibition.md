# 同一届展会的多品牌联合参展

2026年11月6日。修正多个品牌可以报名、但现场只处理第一个品牌的问题。

同届已报名且未结束、未错过的品牌统一核对门店、海报、合约及站台人员到场条件，全部齐备后联合报到。任一品牌未准备好会显示该品牌名称及原因，不提前扣其站台费或开始其他品牌。

现场顶部增加当前品牌选择，可切换电脑、服装、模型等品牌的实际展台内容、库存和受邀主播。每个品牌仍各有24段事件，每段选择只作用于本品牌；自动切换到尚未处理的品牌。全部参展品牌处理完同一段后，游戏时间才统一前进80分钟。日末统一休息一次，每个品牌按各自已锁定报价支付当天站台费，不把两场四天串成八天。

不能在其他品牌尚未处理时重复推进已处理品牌。已完成本段的品牌显示等待提示和切换入口。所有品牌完成最后一段后统一闭展，各自退货、结算销售、费用、品牌提升及采购订单；结算窗口可切换查看同届其他品牌。

存档保留当前选中品牌及每个品牌独立进度。旧档中一品牌已经开始、同届其他品牌仍未报到且未错过时，可在现场选择另一个品牌办理加入，先核对其准备条件，从当前环节参与，不补造此前销量/得分，也不追收未参与天数的站台费。已标记错过、已退回库存的历史报名不自动复活。

健康中断会同时结束正在参与的本届品牌并各自退回剩余库存，避免留下不可操作的参展锁定。任一正在参展品牌的KOL都不能中途解约。普通出行在全体品牌结束前继续按原规则锁定。

现场顶栏新增“自动选择”开关，默认关闭。开启后约每1.2秒优先选择现场评分较高的合理应对，同分时比较热度效果；复用实际选择接口，照常销售、付费、统一推进时间，不预发奖励。多品牌依次处理当前环节。点击“暂停自动”或手动选择可接管，打开其他弹窗时暂缓执行。结束、中断、离开现场或切换存档自动关闭，不将自动开关存档，载入后不会自行推进。

Unity 2022.3.6f1编译通过，Core、Game及Editor程序集生成并正常退出。按用户要求不运行游戏、不截图、不执行测试集，未提交GitHub。
