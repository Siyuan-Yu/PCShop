# 湖区赛车、车型改装与二手车行

更新：2026-11-05。本篇补充第59篇完整游戏归档；历史文档中“顺丰车行出售所有载具”“二手车行自动产生销售额”的规则，以本篇为准。

## 玩家入口与验收

正常游戏：去顺丰车行购买第一辆小电驴，即可参加赛车；已拥有旧版三轮、轿车或货车的存档也能使用相应车型参赛。车行内有“我的车库 / 改装”“四大赛车场”。员工的“车辆与占用”页也能打开具体车型车库和赛场导航，住处大屏资产页在有车后出现湖区赛车入口。

编辑器：**作弊 → 赛车与二手车行验收（独立测试档）**。提供六辆车、500万元追加资金、四片区通行、六次测试胜场、四位已认识车友、一家实际签约且付费的小型二手车行，玩家位于城郊赛场。该预置保存到独立测试槽，原进度仍可从城市生活验收页返回。正常存档不会自动获赠车辆、资金或胜场。

实机验收建议：先用轻行跑免费练习，再用逐风R对比；换三轮、宏途或苏七跑三车竞速；到顺丰改车升级电机和轮胎；去社区车行收车、检测、挂牌，等待买家。按用户要求，本轮没有截取或查看游戏画面。

## 驾驶与比赛

- W / 上：加速；S / 下：先刹车、停稳后倒车；A/D或左右：转向。
- 空格手刹；R复位至上一个检查点并罚5秒；Tab切换跟车/全景；Esc暂停或继续。失去窗口焦点会暂停。
- 三秒发车倒计时，按绿色检查点顺序完成全部圈数。记录分赛场、车辆组别和模式保存，退赛不记完成成绩。
- 高速转弯会推头，抓地和操控分别影响滑移与转向；离开柏油减速，撞护栏或碰撞对手减速并造成损伤。道路、检查点、对手和画面共用同一条赛道曲线。
- 对手跑圈进度独立，按实际过线时间判断最终名次。复位罚时也会让对手前进，不能靠复位抢名次。对手基于基础车型设置速度，玩家改装能产生优势，高级车对手速度另设可完成的上限。
- 正赛奖金为报名费的2.5 / 1.2 / 0.4倍；退赛不退报名费，也没有奖金。完成正赛会结识当地车友，冠军增加胜场和更多交情。
- 健康至少40、精力至少30、车况至少40%才能参赛。每次比赛/练习消耗8精力，基础磨损2点；额外磨损来自碰撞。碰撞损伤超过5后才进行受伤判断，概率随损伤增加、最高80%，单次最多损失30健康；安全完成不会无故受伤。
- 驾驶使用固定60Hz的简易街机模型，不受经营时间1/3/4/8倍速影响。小游戏期间暂停城市计算，结束后推进30游戏分钟并正常结算经营、生活和工资。最长10分钟后退赛。
- 比赛中不允许普通出行、离场或存档；完成/退赛结算后恢复，控制器安排自动存档。中途关闭程序只能回到上一份存档。

这是封闭赛道的3D驾驶小游戏，不是文本选项结算；当前采用街机动力与碰撞模型，没有拟真轮胎温度、手动挡、联网联机或开放世界竞速。

名称与外观为游戏自制。加速、抓地、操控是本游戏的驾驶参数，用于车型对比，并非实车测量结果。画面距离和速度按街机尺度折算。

每台车有独立编号、车型、车况和改装等级；同型号可以多台持有。四类改装每项最多3级，每级30分钟：电机/动力总成每级提高13%加速；电池电控/传动每级提高7%极速；轮毂轮胎每级抓地+8；转向悬挂每级操控+8，两项上限125。价格为基础车价×12%×新等级+100元。维修费按缺失车况×基础车价×0.2%计算，每次30分钟。

旧版载具自动按数量迁移为轻行、载星、家悦、小货王，保留数量、运输占用和扣车状态。日常城市交通仍按原载具类别的速度/载货/养护规则执行，具体性能用于赛道。员工占用车辆会限制可赛车数量；同类存在被扣押车辆时，需先赎回再参赛或改装，避免拿扣押车辆参赛。车行回收按基础车价×60%×车况计算，改装费用不另回收。

## 车友与二手车行

新增4位常驻赛场工作的NPC，各有三段独立经历、社交关系和复古漫画头像。正式NPC总数从120变为124；原20位重点人物及其故事不变。

| 姓名 | 角色 | 场地 | 已有关系 |
|---|---|---|---|
| 许星澜 | 电驱教练 | 城郊 | 与郑禾组织入门运动 |
| 沈知夏 | 车友俱乐部主理人 | 社区 | 与乔禾运输整备配件 |
| 陆景行 | 赛道整备师 | 公园 | 与程弈交流机械结构 |
| 顾若宁 | 收藏车经纪人 | 花园 | 与梁敬筹备车友聚会 |

到赛场聊天或完成正赛即可结识车友，每日聊天增加交情一次。每位已认识车友每周有一条车源；不同层级介绍不同价位上限，交情越高收购报价越优惠。没有认识对应车友就没有该渠道，已买线索不能重复购买，读档和重开窗口不会刷新。

解锁社区后，可在所属中介的委托经营业态中开二手车行：主店已开业、知名度12、装修投入8万元，加首月租金、押金、中介费和5,000周转金。小/中/大店分别2/4/6展位，店员日薪180元，租金和固定费照常结算。

操作必须实际到自己的车行，9:00–19:00营业时进行：

1. 收购车友介绍的车辆，或把自己的四轮车从车库移入展位；两处库存不会重复。
2. 花300元、30分钟检测，查看车况；可另付整备费、花60分钟恢复车况。投入计入单车成本。
3. 按建议价挂牌，或每次上下调整10%；最高挂牌基础车价3倍。价格越高越难成交，过高可完全没有买家。
4. 每3天至多出现一位买家，且只是概率到访，报价保留2天。实际到店接受报价、收款交付，显示单车毛利。不是每天自动生成营业额。
5. 可撤回自用车库。关闭车行前必须售出或撤回所有库存车，避免清算时吞车；库存残值计入总资产。

比赛赢取人脉，经营取得资金，升级车型再进入更高阶赛场，构成本轮完整循环。旧二手车行存档保留合同和周转金，改用真实库存成交，需要重新收车或调入自有车辆。
