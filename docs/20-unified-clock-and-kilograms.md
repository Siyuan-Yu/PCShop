# 统一实时计时与千克（2026-11-01）

## 走路、停下与室内使用同一个时钟

原来 `GameSession.Tick` 有两条计时分支：静止时由真实秒数与倍速推进，街上手动移动/自动前往则用走过的路程除以载具业务速度推进。地图连接路还有不同的压缩比例，因此移动、停下、跨路段时出现不同流速，且两条分支的不足一分钟余量各自累计。

现在每个实时 Tick 只调用一次 `TimeController.Tick`，随后统一推进世界时钟。手动走路和自动前往只更新位置；家中、店内、街上静止、街上移动、碰到路边停止都按相同真实时间与倍速计时。保留现有走路画面速度、碰撞和手动接管。

自动前往的剩余分钟按剩余实际画面路径、当前移动速度与统一时钟比例重新估算，途中递减。到达后先完成当前帧应流逝的时间，再触发进店弹窗，避免弹窗暂停吞掉到达帧。出租车计费仍使用原路线费用规则。

暂停、普通弹窗、主菜单和摆放仍按各自规则暂停；吃饭、睡眠、地铁等有明确耗时的动作继续使用原动作时间。后台员工采购和货运的业务路程/速度参数仍用于其独立行程报价，不再作为玩家逐帧时钟的来源。

## 重量统一为千克

游戏内不再混用其他中文质量单位。冰箱、家具、纸箱、背包、载具、货车、购物车、食材、米、员工采购和所有承重提示统一标“千克”。件、份、袋、碗继续表示物品数量或包装数，不表示另一种质量单位。

- 活跃库存和配送使用 `RiceKg`、`CourierItem.Kg`、`ByWeight`，重量直接以千克相加、比较和计算费用。
- 米价为 ¥6/千克，开局为 2.5 千克米，网购一袋 5 千克、原袋价 ¥25；换单位不凭空增加开局物资或改变同重量米的价格。
- 0.25 千克生米做 2 碗、0.5 千克做 4 碗、1 千克做 8 碗；配菜消耗保留原等量配方，并用千克说明。
- 食材按原物品的实际重量换算每千克单价，购买按钮显示实际增加重量。保质批次仍保留份数，称重时使用每份的千克数。
- 员工采购的米按每袋 0.5 千克、¥3 计，保持原采购单与在途订单的等量内容；食材注明每份千克数，运费与承重始终按千克。
- 四档冰箱仍为 60/120/240/360 千克，删除重复的另一套单位显示；原生模型、售价和容量不因本次文字统一改变。
- 大米分配背包和货车保留 0.25 千克精度，不把剩余 0.25 千克空间错误当成装不下，也不丢弃分车余量。

## 旧存档转换

新存档标记 `weightUnitsVersion = 1`。旧档只在读入边界转换一次：厨房、背包、纸箱、临时存放、家店冰箱、分店储物以及未到货配送中的旧米量换成等量千克。旧 `riceJin`、`jins` 仅作为读取兼容字段保留，不参与游戏内计算。

旧包裹按原包装的等量千克送达；员工采购米的旧件数对应相同 0.5 千克袋数。现金、熟饭、食材份数、家具、过期日和冷藏标记保留。新档保存/再读不会二次缩小米量；旧配送送达也不会重复转换。
