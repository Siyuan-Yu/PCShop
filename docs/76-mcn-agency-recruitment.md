# MCN公司人事招募与统一代言合约

2026年11月6日。修正第73篇合并代言人与KOL时的招募入口：统一的是合约、直播与参展用途，招募继续经过公司介绍、实际认识主播及现场人事签约。品牌面板不再提供直接签约按钮。

## 玩家操作

1. 在“品牌 → 代言人（KOL）→ 代言人市场”选择公司，查看定位、旗下主播头像及名单，点击前往公司人事接待。
2. 三家公司当前共用社区MCN联合接待处，营业时间09:00—18:00。远程可以了解名单，办理手续需要实际到达现场，并满足社区开放及现有会面条件。
3. 在接待处选择公司与要签约的品牌，点击“与公司人事洽谈代言 / KOL签约”。
4. 尚未认识的主播先办理介绍，保留实际赴约、交换名片的流程；已经认识的主播可请人事出示合约。
5. 核对签约费、动态日薪、90天期限、名额与参展费用后确认签约。随后回到品牌的“代言人与排班”管理直播，展会邀请使用同一份合约。

## 合约与存档

新签约必须在营业时间内到达MCN接待处，并于当日与该主播所属公司人事洽谈。仅认识主播、远程打开名单或找另一家公司的接待都不能直接签约；跨日后需要重新洽谈。底层签约接口同步检查这些条件，旧代言入口也不能绕过。

新合约记录经办公司。人事洽谈状态不写入存档，重新读档后新签约需重新接待。已有有效合约继续生效，无需再次认识、重新签约或支付签约费；直播排班、日薪、展会资格及第73篇旧档兼容规则保留。

短期推广仍是独立服务，本次扩大公司旗下名单没有扩大原短期推广可合作人物范围。
