## 1. 定位

一款 3D 低多边形（固定斜俯视相机）的**电脑城创业故事**，由三层构成：**世界层**（在街上走动，看到店铺和地产）+ **店内层**（固定镜头室内，装机等手操）+ **UI 面板**（经营决策，不算 3C）。详见 `docs/04-3c-and-world.md`。

> 从商业街最偏的一间小电脑店起家，手装机赚第一桶金，靠行情、人脉和签约主播做大，最后建成自己的电脑乐园。

- 开局固定：商业街上最小、离地铁站最远的一间电脑店，资金很少，客流不多，只能自己动手装机赚钱；靠打出知名度提升客流。
- 贯穿全程：**行情判断**、**人脉与关系网**（含签约主播、朋友、恋人）、**手操到雇人到管理**的成长曲线。
- 终局：**园区**（电脑乐园：电脑、电竞、吃、住、车）。
- 宣传时**不要**用"创业模拟器"作为核心卖点（该标签竞品密集），用"电脑城创业故事"这类具体说法。

### 不是什么
- 不是"货架摆放"式零售模拟。
- 不是纯 MCN/主播经营游戏。玩家不扮演主播，主播是签约对象。
- 不是通用的"开局任选行业"开店模拟。
- 不是纯 UI 的东京股神式模拟：玩家能在城市里走动，看到自己的店和地产。
- 视角为 3D 低多边形 + 固定斜俯视相机；不做店内自由走动（进店后切到固定镜头室内场景）。

## 2. 竞品与差异化（截至 2026-10，来自 Steam 商店页与媒体介绍，未试玩）

### 2.1 已有竞品
| 类别 | 代表 | 说明 |
|---|---|---|
| 装机/零售 | PC Building Simulator 系列、PC Creator、Computer Repair Shop、PC Store Simulator、ElectroFix Simulator、Tech Shop Simulator 等 | 装机、维修、货架零售为主，近年跟风作品评价偏低 |
| 挖矿/行情 | Crypto Miner Tycoon Simulator、Garaged Crypto Miner（未发售）等 | 视角是挖矿者，不是渠道 |
| 创业/人生 | Big Ambitions（3D，体量大）、Street Vendor's Journey（摆摊起步，计划多行业）、长安首富模拟器、九州：立志、Great Town Business（未发售）、創業王 CEO | 摆摊起步、多行业、人脉、生活模拟已被占据 |
| 二手车 | Real Life Simulator（2D，未发售） | 验车、砍价为核心 |
| 主播/MCN | 榜一模拟器（2026 Q4）、直播时代、Idol Manager: Virtual Venture（2027）、VtuberCompanySimulator（2027）等 | 主角是主播或公司，不是"有硬件生意的创业者" |

### 2.2 我们的区分点（按重要性）
1. **以电脑硬件为根**：行情（币圈热度、AI 需求等虚构宏观因子）+ 手动装机 + 渠道视角。
2. **主播人气与忠诚的反噬机制**：人气越高，身价、野心、挖角风险越高，好感衰减越快；与硬件带货联动。
3. **园区终局**：把电脑、电竞、餐饮、住宿、车整合成"电脑乐园"。
4. **每个阶段都有"手操 → 雇人 → 管理"的转变**，核心在装机。
5. 现代中国语境（电脑城、主播、行货/水货、人情关系）。

### 2.3 要避免的撞车
- 摆摊起步、通用开店：已被占据，不作为开局或卖点。
- 二手车：只作为园区车辆区的业态，不做独立核心玩法。
- 3D 生活模拟：不比拼。

## 3. 核心体验曲线（成长阶梯）

| 阶段 | 身份 | 玩法重心 | 关键设计 |
|---|---|---|---|
| L1 手操期 | 小电脑店店主 | 自己装机、跑货、接单 | **时间是最稀缺资源**；手装省钱且效率高；熟练度提升后更快更好 |
| L2 雇人期 | 小老板 | 雇第一位装机工，花钱买时间 | 员工有性格和成长；玩家腾出时间做采购/行情/社交 |
| L3 管理期 | 店长/渠道商 | 多员工、仓储、账期、多品类 | 现金流压力；行情博弈成为主角 |
| L4 帝国期 | 集团老板 | 签约主播、MCN、投资、人脉运作 | 关系网和资本成为主要玩法 |
| L5 园区期 | 园区主 | 建设并运营电脑乐园 | 终局，整合所有业态 |

**手操永远保留：** 即使后期雇了人，玩家仍可亲自上手（品质更高或应对特殊订单），但不强制。

## 4. 业态规划

### 4.1 根业态：电脑硬件
- 核心张力：行情判断、囤货时机、账期。
- 手操：拖拽配件到主板、检查兼容性、计时（轻量 2D）。
- 雇人后：装机员；玩家专注行情、采购、社交。
- 联动：主播带货影响价格和销量；供货给电竞馆。

#### 配件与兼容（已确认）
- 5~6 个品类（如 CPU、主板、内存、显卡、硬盘、电源/机箱），每类 3 档（入门/主流/高端），全部虚构品牌和型号。
- 兼容规则只保留几条关键的：CPU 与主板接口匹配、电源功率够用、显卡尺寸与机箱匹配等。

#### 库存与包装（已确认）
- 店铺就是仓库，大中小都有库存容量，配件占空间（`[建议]` 小 40 格、中 120 格、大 300 格）。
- 散件：占空间少（`[建议]` 0.4 格），能放更多，卖价低一些。
- 盒装：卖价高一些（`[建议]` 约 +12%），顾客更信任，但占空间多（1 格）。拆包装不可逆。
- 载具载货量也按"格"算，进货要考虑店里放不放得下、车拉不拉得动。

#### 行情可读（已确认）
- 按"新闻（原因）→ 宏观指标（币圈热度、AI 需求等）→ 品类价格"展示因果链，玩家能顺着链条看懂为什么涨跌。

#### 装机小游戏（已确认）
- 2D 覆盖层：把配件拖进主板对应位置，有限时；装错要返工，耗时增加。
- 完成后按"标准耗时 × 熟练系数"一次性推进世界时间。

### 4.1.1 L1 核心循环：守店（已确认，详见 `04-3c-and-world.md` 2.6）
- 守店时切到小店室内固定镜头。顾客进来挑货，挑好后到柜台找玩家结账，玩家点击收款；装机订单进队列，由玩家手动装。
- **支付升级线：** 前期只收现金（玩家只有按键手机）→ 买智能手机解锁收款码 → 再解锁自助结账平台。每一级让不带现金的顾客也能成交、结账更快、排队流失更少。
- **在场营业：** 一个人时离开小店就关门；雇人后可以持续营业；自助结账不能代替人值守。
- 一周 7 天：周末客流更大、批发商休息。

### 4.2 园区业态（L4~L5 逐步解锁）`[默认]`
| 业态 | 核心张力 | 联动 |
|---|---|---|
| 网吧/电竞馆 | 上座率、赛事、设备折旧 | **直接采购你的硬件**，园区核心 |
| 餐饮（小吃街/面馆） | 人流、口碑、损耗 | 导流给电竞馆；主播探店 |
| 民宿/酒店 | 季节性、评价、房态 | 住客导流 |
| 车辆区（二手车展销/停车） | 估价、砍价、翻新 | 和"车/地位"系统联动 |
| 花店等商铺 | 节日需求、易腐 | 送花影响恋爱好感 |

- 1.0 目标业态总数不超过 6 个；其余作为后续更新。
- 园区业态的手操玩法做成"简化版"，不追求每个都像装机那样深。

### 4.3 园区（终局）
- 玩家在后期购入一块地，建设"电脑乐园"。
- 园区由已解锁业态"落地"为园区内的店铺和设施，行业之间互相导流，玩家做布局、招商、运营决策。
- `[默认]` 1.0 做成"布局 + 招商 + 运营指标"的轻量版，不做自由建造。

## 5. 横向系统（跨业态共用）

### 5.1 关系网
- 所有 NPC（供应商、客户、员工、主播、朋友、恋人、同行、官员/银行等）共用一套关系数据：好感/信任、立场、记忆。
- 关系可兑换：情报、优惠价、订单、融资、危机援助。
- 恋爱是关系的一种，需要好感和"地位匹配"等条件，有经营后果。`[默认]` 离开/变心可挽回但代价高；恋爱对象可以是签约主播或非签约人物，前者带"公私混淆"代价。

### 5.2 主播/MCN
- 玩家不扮演主播；签约后可以"资源投入"（推广预算、流量、礼物等）。
- 核心属性：**人气、好感/忠诚、野心**（后续再加压力、合同等）。
- 人气上升带来：带货和代言价值增加，同时身价、野心、挖角风险上升，好感衰减加快。
- 代言费随人气上涨；存在性价比最优区间。
- 可发展为 MCN 公司（L4 以后）。
- 角色首批 3~5 位原创角色。

### 5.3 地位与车
- 玩家有"地位/形象"属性（资产、公司规模、车、人脉）。
- 车影响通勤效率（省时间）和谈判效率（豪车加成），也影响与高人气主播的关系匹配。

### 5.4 行情与投资
- 价格由虚构宏观因子驱动：币圈热度、AI 需求、新品周期、库存缺货、政策/汇率、股市情绪。
- 玩家通过新闻、研报、人脉情报做不完整判断。要有"可读的因果"，避免纯随机。
- 股票等投资作为 L3 以后的辅助玩法。`[默认]`

## 6. 底座架构（技术）

所有玩法模块建立在同一套底座上，通过注册数据和规则接入，**互相之间不直接调用**。

| 底座 | 职责 |
|---|---|
| 时间系统 | 连续世界时钟（分钟级）、日历、暂停/倍速；所有行动推进同一条时间线 |
| 账本 | 统一收支、资产负债、现金流 |
| 人物与关系 | NPC 数据、关系值、记忆标记 |
| 事件系统 | 数据驱动：条件、选项、后果 |
| 属性与修正 | 玩家/员工/店铺属性，加成和减益的统一计算 |
| 世界与地产 | 路径图、寻路、移动耗时、地块与产权、地价（见 `04-3c-and-world.md`） |
| 业态模板 | 商品、成本、客流、员工岗位、升级项的数据配置 + 专属模块钩子 |
| 价格与行情 | 宏观因子 → 品类价格 |
| 存档 | 全状态序列化（通过存档接口，平台可替换）；每天自动存一次，另可随时手动存档 |
| 平台抽象 | 成就、存档、支付、广告、分享做成接口 |

- 代码分层：`Core`（纯 C#，不引用 UnityEngine，可测试）、`Game`（Unity UI 与场景）。
- UI 与世界层以代码生成为主，不依赖可视化拖拽；地图路径、建筑插槽用数据文件（JSON）描述。
- UI 用 uGUI + TextMeshPro，中文字体思源黑体；保留旧 Input Manager；Core 随机用带种子的随机数，读档可复现。

## 7. 平台与资源规范

- 主目标：Steam（Windows），横屏。
- 微信小游戏不做；iOS/Android 以后再评估，只预留接口。
- 为移植预留的约束：
  - UI 不依赖鼠标悬停/右键/复杂快捷键，布局不写死分辨率。
  - 美术用图集和压缩纹理，控制分辨率；角色立绘按需加载。
  - 音频：BGM 短循环、单声道，同时音频数量受控。
  - 资源按 AssetBundle/Addressables 分批加载，避免首包过大。
  - 存档、成就、支付通过接口隔离。

## 8. 合规与美术

- 所有品牌、型号、平台、人物原创或虚构；不影射真人；不照搬竞品 UI/角色/文案。
- AI 美术：登记到 `docs/asset-log.md`；统一风格并人工修整；Steam 内容调查如实披露预生成 AI 内容；不使用实时生成 AI 内容。
- 恋爱和主播内容尺度克制；国内发行相关合规要求另行核实。

## 9. 垂直切片

### VS1（第一个可玩版本：一个月流程，已确认）
- 底座：时间（含星期）、账本、角色状态（饥饿/精神/健康、睡眠）、事件、存档（最小版）。
- 世界层灰盒：一条商业街（约 20 家店）+ 地铁站 + 城中村住所 + 电子配件批发市场，角色沿路径行走并推进世界时钟；进入小店切室内。
- 守店：顾客挑货、柜台现金结账、装机订单队列；离开小店关门。
- 业态：**电脑硬件**（手装机 + 进货 + 简版行情）。
- 进货：线下档口（在约 2 公里外的电子配件批发市场，找老板、可砍价）+ "1788"批发平台（找对店铺最便宜、找错吃亏、到货要等；靠评价、试单和人脉推荐找对店）。
- 载具：步行/打车 → 小电驴（快、拉货少）/ 三轮车（拉货多、会被交警查）。交警有可见视线，被看到会追，追上罚款。
- 成长：L1 手操 → L2 雇第一位员工。
- 一次行情波动（新闻 → 宏观指标 → 品类价格）。
- 目的：验证 (a) 手操到雇人是否有手感；(b) 行情判断是否好玩且"可读"；(c) 守店结账是否有满足感而不烦；(d) 移动耗时是否让"自己干 vs 雇人"的取舍有感；(e) 一天 3~5 分钟的节奏是否舒服。

### VS2
- 1 位签约主播（人气/好感/野心三属性、一次代言、带货联动）、汽车（效率/形象影响）、支付升级线（智能手机、收款码）。
- 大老板直供：社交活动（打球、踢球、KTV、酒吧）刷好感后直接拿货，最便宜还能赊账。
- 第二业态：网吧/电竞馆（采购你的硬件）；关系与事件内容深化；恋爱线。

### VS3 及以后
- 园区（布局/招商/运营）、餐饮/民宿/车辆区、MCN 公司、投资。
- 地产系统（租/买/出租、地价与政策事件）、家业总览图层。
