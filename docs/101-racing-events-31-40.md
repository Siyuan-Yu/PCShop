# 随机事件 31–40：赛车预约、车辆状态与护具

本批接续 01–30。用户确认 31 的夜宵金额为 ¥2,000；37 的报名费为 ¥2,000、单独捐款为 ¥500。其余事件按真实预约、实际车辆和装备改造。属性门槛只影响成功率，不因属性不足禁用选项。本批实际驾驶结果取代原来的智力掷骰。

## 31 · 骑手的小挑战

配置 ID `race_rider_bet`。吴磊与玩家约一场双方能赴约的比赛日，到指定赛场使用专属入口实际进行一对一单圈挑战，不收普通比赛报名费。开始前需保留 ¥2,000 夜宵预算。按实际名次确定谁请客，完赛增加交情 4；无现金赌注收入，不增加正式比赛胜场或发普通赛事奖金。退赛不结算夜宵输赢。

赛后有单独邀约，可立即安排或三游戏小时后再提醒。饭局使用真实餐厅、日程和同行者，固定合计 ¥2,000，由输家到场开始时支付；吴磊请客时玩家支出为零。预约时不扣款。拒绝比赛或改天再约不扣交情。

## 32 · 电池掉电

配置 ID `race_battery_old`。只对一辆实际空闲电动车触发，不影响燃油车或其他车辆。事件出现即记录该车电池老化，拒绝维修也保留。该车动力降低 25%，每次实际驾驶有 40% 概率在 20–60 秒后断电，按退赛处理并在结算时支付救援 ¥1,500。

可选择导航到顺丰改车，或继续承担风险。到对应车间营业时间内更换，费用为车型原价的 18%，最低 ¥800，经过 30 游戏分钟。普通车况维修不清除电池问题，换电池不重置车况或改装等级。状态随车辆保存。

## 33 · 再来一场？

配置 ID `race_rematch`。候选人来自最近一次实际正式完赛的具名对手，不再固定为某位人物和赛场。列出实际可赴约日期、地点及原有正式报名费，确认后写入赛车邀请日程。费用到场支付，关系按实际同场完赛结算。没有实际对手记录时不出现；旧档需先完成一场正式比赛。

## 34 · 车身贴纸赞助

配置 ID `race_sponsor_sticker`。累计至少两场正式胜利后可为一辆实际赛车签约，五场合同，每场 ¥3,000，总额 ¥15,000。车辆显示手机店贴纸与剩余场数。只在该车完成普通正式比赛时入账并消耗一次；练习、单圈挑战、慈善赛、退赛及其他车辆均不计，签约时无预付款。合同跟随具体车辆保存。

## 35 · 弯道边的意外

配置 ID `race_crash_help`。正式比赛发生碰撞且存在实际具名对手后，赛后触发一位同场车友的救助事件，当天有效。可以陪同到最近可达医院，或联系工作人员、确认工作人员处理后离开。

陪诊使用真实医院、同行者和 90 分钟预约，到院开始时支付照护 ¥1,500，完成后交情增加 6。没有无缘由的玩家健康扣除。预约失败不扣款；工作人员接手不产生额外扣款。该事件不声称模拟了每位 NPC 的独立伤势数值。

## 36 · 来赛道看看

配置 ID `race_spectator`。尚未解锁赛车、尚未认识沈知夏时可出现，例外绕过赛车事件组的首跑要求。预约城郊实际正式比赛日 09:00–17:00 的观赛时段，观赛 60 分钟。预约即刻不增加属性；实际赴约完成后认识沈知夏、见识 +1，关系走活动结算。观赛不直接解锁赛车，正式入门仍沿许星澜原有流程。

## 37 · 慈善赛

配置 ID `race_charity`。预约实际可赴的赛场和比赛日，从接待处专属入口开始实际驾驶。到场报名 ¥2,000，完赛获得纪念奖牌、名望 +1、魅力 +1，不发现金奖金，不增加普通正式胜场。退赛不获完赛奖励。

另可只捐 ¥500，立即记入实际慈善支出并增加名望 0.3，不产生比赛预约或奖牌。保留改约和拒绝选项。奖牌在赛车接待的装备区显示。

## 38 · 旧护具

配置 ID `race_maker_gear`。程弈赠送实际身体护具，成色 60%，收下后入赛车装备并穿戴。该部位全新防伤 20%，当前成色防伤 12%，收下增加交情但不直接治疗玩家。可在赛车接待处卸下／装备，或花 ¥1,000、30 分钟整修到 100%。每个部位只使用一件装备，碰撞会降低成色。

## 39 · 夜骑小队

配置 ID `race_night_ride`。有实际可用电动车时，沈知夏邀请到城郊赛场集合，在安全路线休闲骑行。集合时段 19:00–21:30，全程活动 90 分钟，使用真实赴约、同行者和活动分阶段结算，不是竞速比赛，也不立即发放属性。

气温低于 0℃、高于 35℃或车辆不可用时取消，可再次预约，不扣交情。玩家需有通勤用途或城郊车库内的健康电动车，车况至少 40%、无电池老化。活动开始后，玩家和同行者沿当前地图内的实际赛场路线骑行并返回集合处，路径随存档恢复。场景显示双方电动车，镜头跟随玩家。当前天气系统有气温、没有独立雨量或暴雨状态，因此取消条件基于真实气温，不编造雨天判定。本次沿用城市活动时钟，不新增夜骑手操赛道模式。

## 40 · 头盔清仓

配置 ID `race_helmet_deal`。支付 ¥2,500 获得一顶实际头盔，成色 100%，自动装备头部位，防伤 20%。与身体护具合计最多降低 40% 的实际事故伤害。购买不直接治疗或增加健康；拥有后不重复触发同一清仓商品。装备、成色及整修与 38 共用系统。
