# 网购入口简化（2026-11-03）

## 玩家可见的变化

- 手机和应用商店只有「网购」，删除独立的1788进货应用。
- 网购分类为家具、店里摆设、衣服、礼品、大米、电脑配件。配件无需另开平台，选择数量和收货地点即可下单。
- 删除线上商家列表、店铺评分、买家评价、试单选商家、新商家推荐和默认线上商家设置。所有新配件网购使用同一个明确报价，不再承担选择劣质商家的随机损耗。
- 配件价格按市场价85折及既有周维成关系优惠计算，每单运费¥15、次日10:00到货；生活用品继续使用原有报价和两天配送。各分类下单页明确显示时间。
- 电脑装机订单缺件清单直接放入网购购物车；自动补货和采购目标统一使用网购，无需指定线上商家。账单预留、每日预算、在途去重仍有效。
- 线下批发店、进货员和已签订的协议直供保留，它们仍是实际城市经营的一部分。

## 旧存档兼容

- 原来安装1788的存档自动视为安装网购；保存时不再保留第二个应用入口。
- 已付款的旧线上订单保留原商家、数量、付款、到货时间与交付规则，也仍可按原流程取消退款。
- 旧补货计划里的指定线上商家不再控制新采购；未执行的线上采购按统一网购报价重新检查预算。
- 内部历史类名、枚举和旧商家数据仅为读取旧档保留，不作为玩家可见平台或新订单的选店系统。
