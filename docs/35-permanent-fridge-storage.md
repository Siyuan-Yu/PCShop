# 冰箱内食物永久保存（2026-11-02）

## 当前规则

- 家和所有自营门店的冰箱内，食物永久保存，不会因天数流逝而过期。
- 放入冰箱暂停消耗保质期；取出后按存入前剩余的保质期继续保存。反复存取不会重新获得完整保质期。
- 背包、锅中、普通后仓、临时存放、经营库存和运输中的食物仍按原有到期规则处理；曾经冷藏不代表离开冰箱后也永久保存。
- 取消首次冷藏额外延长7天及旧档冷藏补天逻辑。旧档已有批次保留已记录的到期日，不回扣历史已获得的天数，读档不再额外补天。
- 所有冰箱档次均适用；容量、承重、家店分开存放及自动进餐沿用原规则。
- 冰箱内容显示“永久保存”；背包内容继续显示保质期倒计时。冰箱商品说明和做饭完成提示同步更新。

## 实现与兼容

现有食品到期日按天记录。每日跨午夜时，对仍在家及各店冰箱内的批次顺延到期日一天，并移除冰箱过期清理。取出、再存入以及存读档沿用原批次信息，无需新增存档字段。旧档中已被清理的食物不会凭空恢复。

本篇替代第17、19、30篇中的冷藏额外延长7天规则；其他历史功能和验证结果按各篇当时版本理解。
