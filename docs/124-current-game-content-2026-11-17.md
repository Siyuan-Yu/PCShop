# PETSHOP 当前完整玩法与工程交接

更新于 2026 年 11 月 17 日。本文记录当前 `main` 的玩法、操作、工程入口和第一章 WebGL 试玩边界。目录中的专题文档保留各系统的细则与历史验证。此前的九格存档、外卖、采购体验、邀约和财务改动见[前一次试玩更新](123-playtest-update-2026-11-17.md)。本轮新增的 3D 人物、暖色场景、界面样式及试玩启动修复见[本轮交接](125-art-ui-and-webgl-startup-2026-11-17.md)。

## 版本与运行

- 当前游戏暂用 **PETSHOP**，工程名为 **PCShopSell**。Unity **2022.3.6f1** 打开 `Assets/Scenes/Main.unity` 进入 Play 后，可在主菜单开始游戏或读取存档。主菜单遮盖整个游戏画面，封面按原比例等比铺满，多出的边缘裁到视口之外。标题、副标题及菜单使用中、日、英文字资源。Windows 客户端默认窗口化，设置可调分辨率、音量和菜单语言。
- Windows x64 完整版与第一章 WebGL 试玩版使用同一份源码，各由自己的构建入口生成。此前版本的测试结果见[Windows 构建归档](121-current-game-content-windows-2026-11-16.md)。

## 游戏与操作

玩家在架空城市「湖城」生活，从小出租屋做饭、找铺、装修、采购和销售做起，扩到多店经营，再通过人物关系、品牌、展会和履约推进区域主线。银行、证券、物业、活动与赛车使用同一个城市时间和账本。

| 入口 | 操作 |
| --- | --- |
| 移动和交互 | WASD 移动，F 与人物、门口、设施、货架和场所交互。空格暂停或继续，1–4 对应 0.5×／1×／2×／4×。暂停和倍速在同一组，四档单行等宽。手动、窗口、教学或活动暂停各有状态，选定的倍速仍显示高亮。 |
| 顶栏第一排 | 我的 M、背包 B、手机 P、任务 T、日程 C、通知 N。 |
| 顶栏第二排 | 员工 U、资产 J、采购 G、物价 H、品牌 L、赛车 R。菜单 Esc 在最右侧，跨两排。部分功能随解锁开放。 |
| 底栏 | 选择步行、打车、通勤载具或快捷目的地，也可打开叫货车。金黄色的「我的店」主按钮直接导航，下拉箭头只切换目标门店。地铁站可办理对应出行和站内事件。 |
| 右侧面板 | 在店内打开门店柜台、库存、定价、订单、记录、装修和员工。在家用可折叠住处面板查看待摆放的家具和进入装修。 |
| 我的和手机 | 「我的」有个人资料、饮食、住处、通讯录和人际关系图。通讯录和手机共用联系人功能，物价从独立入口查看。 |

操作中的输入框有焦点时，字母优先用于输入。普通按钮采用深蓝底和细描边，选中项用浅蓝底、金字金边，主要确认用实心金色。购物车、叫货车和网购中的「送到」按钮也用实心金色。手机应用沿用深蓝底板并通过图标颜色区分。通讯录和证券在各入口共用对应控件。

## 湖城、出行与主线

- 城郊、社区、公园和花园由主线逐步开放。住宅、商铺、市场、交通站点、银行、医院、会展和各运动场所使用实际路网、入口及营业时间。城市扩建记录包含 49 间可租购商铺和 132 处住宅的配置。[区域与实景](91-city-expansion-v15.md)
- 自定义目的地支持多关键字、类型和街区组合筛选。详情显示可达性、营业状态、实际路线和打车报价。「立即前往」发起导航，「保存到底栏」更新可随存档恢复的快捷位。[自定义目的地](120-custom-destination-picker.md)
- 室内发起快捷出行时，角色先走到门口的交互范围，再继续街道行程。站在电饭煲桌、柜子或货架边时，寻路会从身旁能走的位置起步。家具彻底堵住通道时，界面会提示清理后重试。店内摆设改变后会重新计算出门路线，家里的床边和门口使用同一套避障逻辑。
- 开局现金 ¥15,000、20 千克米，先在小出租屋完成第一顿饭。经营引导包含找中介、布置开店设施、采购、定价、首单、招聘、手机收款码与通勤车。任务条按实际状态显示下一步和可用入口。设施采购只列待买的品项和参考价，装修只列待摆放的设施。已备和已摆数量以总进度显示。无可用主操作时，「详情」占满底部按钮区。
- 二手店开业引导中，摆好货架后还要走到货架旁按 F，或在门店库存页打开货架，在「零售商品」里选「二手转售品」。旧档如果已经跳过这步、尚未完成首单且货架仍未配置，读档后会重新提示设置。
- 城郊引荐要求开业五家城郊门店、自有现金 ¥1,000,000、结清全部贷款，达标后开始三天邀请流程。引荐、三人三处寻物、现实到场合作、展会或竞标履约衔接后续片区。商圈以实际街道与店铺位置计算。[主线与片区开放](story-and-district-progression.md)
- 中介显示商铺、住宅、预计进店、租购金额和交房时间。商业租金按周扣，预计客流受地段、面积、地铁、住宅及同类店分流影响。同类店在约 40 米商圈内分流。房产可全款持有、出租或自用，已签租约按签约规则结算。首套小出租屋周租 ¥500。[物业买卖与租赁](82-cash-only-properties.md) · [物业周行情](83-weekly-property-prices.md) · [资产地图](84-assets-stores-and-property-map.md)
- 路口和桥头的铺装在交汇区共用平面，从路口外再过渡到坡道。桥面相邻段共用弯处断面，重叠的路面、外露侧壁和穿进车道的交叉标线按交界裁切。同步调整压近道路的部分住宅位置，保留实际导航路网。[道路与人行道专题](74-continuous-roads-and-pavements.md)

## 第一章 WebGL 试玩范围

- 网页版从新游戏进入城郊，开店教学、租房、采购、经营和可到达的城郊场所按实际规则运行。任务界面可查看「城郊经营目标」的开业门店数、自有现金及贷款状态。
- 开业 **5 家城郊门店**、结清贷款、达到 **¥1,000,000 自有现金**后，由李秀兰发出城郊主线邀请。首次达到条件后等待 **3 个游戏日**，到期正在睡觉时改为醒来两小时后联络。玩家保留回复、约见、寻找三页商铺图、当面交给唐蔚的流程。交付后任务页显示试玩完成，原有城郊经营可以继续。
- 地图只展示城郊可达的道路和地点。步行、快捷路线与场所入口共用地区限制。社区、公园和花园在整局中保持锁定。品牌管理、赛车登记及其玩法在试玩内停用，园区和代言的成长任务也跳过。完整版交图后按原主线开放社区。
- 本地构建由 `WebGlTrialBuild.Run` 为 WebGL 单独传入 `PCSHOP_FIRST_CHAPTER_TRIAL`。试玩限制由构建确定，正式构建沿用完整规则。存档写入浏览器持久化存储中的 `first-chapter-trial` 子目录，与完整版分开。

- 试玩先显示主菜单，选择新游戏或读档后显示加载状态并开始生成城郊场景。渲染生成范围在道路检查点收束，城郊外仅保留必要远景。 [启动内存问题与修复](125-art-ui-and-webgl-startup-2026-11-17.md#第一章-webgl-试玩与启动内存)

## 门店与源头采购

| 经营类型 | 当前玩法 |
| --- | --- |
| 电脑店 | 六类三档共 18 款配件，盒装和散件、兼容装机、整机陈列、顾客委托、企业合同与库存预留。可以亲手装机，也可由在岗装机员履约。 |
| 宠物用品店 | 初始默认店型。基础／中档／高档用品零售与猫狗代养。代养容量随店铺大小为 4／8／12 只。可聚焦互动、补粮换水、清理猫砂和管理玩具，饲养员覆盖每人两只。 |
| 服装店 | 春秋、夏、冬款分价格档采购，气温和季节影响偏好，销售员与试衣镜影响购买意愿。 |
| 模型手办店 | 现货、限定和原创系列，商品热度、转售、陈列及品牌展品实际使用库存。独立展会可买对应模型。 |
| 二手旧物店 | 卖家进店，在收购鉴定台前排队。玩家或收购师出价，买后鉴定并决定定价上架或丢弃。代管可设预算、单件上限和风险倾向。独立旧物市场提供另一路购买、检测和维修。 |
| 餐馆 | 收银台、灶台、餐桌和冰箱支撑堂食。备料、下锅、出锅、上菜、收款、清桌和饮料加购都走实际流程。鱼餐走专单。 |
| 二手车行与场馆 | 区域开放后可经营二手车，支持车源、整备、挂牌和顾客出价。场馆经营使用各自的设施、接客、预约、容量和托管规则。 |

- 第一次租店可以选择表中的前六类。花店、生鲜店和食品店的类别用于保留旧档兼容。通用柜台能查看营业额、实际与预计客流、流失原因、知名度、口碑和排队。口碑影响购买意愿，知名度影响客流，个人名望在各店之间共用。商品调价和整体倍率可预览，确认后应用，普通零售参考价最高可调到 3 倍。货架有件数和重量双约束，余货可放后仓。[经营核心](36-shop-core-gameplay-and-supplier-stock.md) · [货架容量](44-shelf-item-capacity.md)
- 新店默认 08:00–22:00，可自行调整。到设定打烊时间后停止进新客，已有顾客在具备继续服务条件时可卖完、做完和收款。人员离岗、缺设施、停电等造成无法经营时按对应规则处理。餐馆可从营业记录查看客人流失原因与评价变化。
- 二手旧物店每店最多有 **5 位**卖家等候，卖家从到店起最多等 **8 个游戏小时**。有人等待时，柜台的金色「打开收购鉴定台」显示红点。打烊后可继续接待已到店的卖家，普通买家仍沿用原有的挑货和收银队列。早期存档中已经排队的卖家保留原定离店时间。
- 收购鉴定台把「出价收购」「检查状态」「确认售价并上架」放在详情面板底部的同一位置。每一步完成后自动打开当前物品的下一步，上架后优先切到下一位卖家。报价和售价可分别修改，玩家也可以从左侧列表选择要处理的物品。
- 员工管理支持招聘、排班、换岗、调店。收银、销售、装机、采购、厨师、服务员、收购、饲养各有适用店型和属性。玩家也能在允许的店铺签到工作，实际时段及表现计入工资。采购员可按固定清单或库存下限补货，使用真实货源、运力和目的地。供货按供应商、具体商品和日期共享，支持按选定星期安排。[员工与采购](13-employees-and-procurement.md) · [供货分配](38-supplier-model-allocation-and-weekdays.md)
- 招聘后可展开员工卡查看四维、出勤、岗位效率和工资。厨师分配各自灶台，服务员按上菜、清桌任务移动，在岗装机员使用实际装机台。二手销售员的魅力每点提高转售购买意愿 0.25 个百分点，全店上限 25 个百分点。销售流水按本次开店的营业账户归属，同址重新开店独立记账，无法归属的旧流水保留在总账。
- 采购支持线下批发、手机网购、直供和在途配送。数量支持直接输入、加减和长按。购物车按可用负重装背包，超出部分可叫车。默认收货点按商品和门店类型匹配，点金色目的地按钮可改选。店里收货检查路线、冰箱空间和待送容量。企业物流、玩家叫车及员工运货走各自入口。[运输与货车](87-race-meetings-and-logistics-trucks.md)
- 农贸市场每天 **02:00–18:00**，采购按批发价、起订量和每日供货。大米按 **0.5 千克／袋**报价和选量。「鱼类」集中显示鲫鱼、白条、鲤鱼、鳊鱼和麦穗鱼，「全部」也包含鱼，「米与生鲜」显示其余该类食材。切换页签保留购物车。其他鱼种从垂钓取得。
- **宜居家具城**每天 **09:00–24:00** 营业。可按适用店型及电器、设施、装饰筛选。普通、加固、重型货架连续显示，冰箱、代养小屋、同类玩具、床、衣柜、储物家具和空调的规格也各自成组。每组按目录价从低到高排序，家具城、统一采购目录和手机网购共用分组。家具城柜台的数量滑块、输入和结账均使用每款每单 **50 件**的上限。餐馆筛选下提供货架，可送到餐馆并摆放供饮料上架。米家采购列表按售价从低到高排列，按商品类型切换时保留此排序。
- 家具回收从家具城接待页进入，选自家一间门店后仓里的家具和数量，按目录原价 **40%** 报价。叫车按路线、重量和车数先收运费，再取走家具，送达家具城后回收款到账。待送进度随存档保留。

## 名望、委托和餐饮

| 来源 | 规则 |
| --- | --- |
| 电脑店个人装机委托 | 每店发出一单后，随机隔 **1–2 个游戏日**开放下一次到店委托，由合适的顾客触发。按时交付每单 **+0.2** 名望，交期 **4 天**，每店个人委托最多 **5 单**，与企业及其他装机来源合计最多 **12 台待交付**。 |
| 电脑店正式企业合同 | 整份全额履约 **+0.4** 名望，台数逐台收款。企业合同交期按台数加 4 天计算。个人介绍与社区单按各自履约规则处理。 |
| 宠物店代养 | 每周结算时状态**高于 95%**的宠物，每只 **+0.2**。 |
| 二手店真品文物 | 上门卖家约 **2%** 带疑似文物，其中约 **10%** 为真品。最低接受价随机在 ¥2,100–2,800。高智力收购师更容易预判真假。鉴定真品参考价 **¥10,000**，实际卖出 **+1** 名望。 |
| 餐馆鱼餐专单 | 每店每天营业时可发 **1–2 单**，当天第二单最早在第一单发出 **4 小时后**，同时最多待交付 **2 单**。交期 **7 天**，鱼种的稀有度对应 **+0.2／0.3／0.45／0.65／1** 名望。按指定鱼种和菜品备料，由玩家交付并收款。 |

普通零售成交影响店铺知名度和口碑。上表记录各店经营获得个人名望的方式，装机、代养和鱼餐等入口显示可得名望或达标条件。派单时间按门店分别保存，取消或拒单不会重置派单间隔，达到待交付上限后等空位再发单。
