# 交互简化与重复入口清理（2026-10-31）

本轮按两次交互清单修改正式工程。2026-11-01 已按新采购流程复验；最新结果见 [第 16 篇](16-daily-multisource-purchasing.md)。以下规则替代旧文档中相冲突的描述。

## 减少重复操作

| 原问题 | 当前行为 |
|---|---|
| 员工值守时离店仍要确认 | 员工在班直接离店；无人值守、关店等后果仍确认 |
| 完成任务与新任务连续弹窗 | 结果、奖励和下一步合成一个窗口，一次关闭 |
| 班次循环切换 | 员工页直接选择 09–21、09–17、13–21 |
| 补货保留资金与预算循环切换 | 保留天数、现金底线、日预算直接输入；商家直接选 |
| 采购数量、预算反复加减 | 数量直接输入，保留单件加减；新采购费用自动计算，不再输入预算 |
| 选采购型号要翻完整列表 | 支持品类、搜索、只看已选；选定货源后只筛选可加购目录，完整已选清单保留；可跨档口和商店混选 |
| 查库存与采购单来回切页 | 每行显示目的店库存及该店所有渠道在途数量 |
| 拖整行却只移一件 | 购物车、搬货拖整行；背包装不下时只放能放的，其余保留叫车 |
| 多件搬运依赖隐藏长按 | 单件/长按仍可用，旁边明确提供数量选择，支持指定数量或全部 |
| 换岗遇到占位需退回腾岗位 | 同窗口提供替换安排，确认后原员工设为待安排且保留薪资；在途/预留岗位仍保护 |
| 采购时老板占车需退出切出行 | 采购页可直接把老板改为步行，释放其车辆；仍服从背包负重规则 |
| 重开店铺侧栏总回柜台 | 保留上次选择的页签 |
| 手机应用关闭没有返回路径 | 从手机启动的应用保留手机作为上一层，关闭应用回手机 |
| 通知只能从菜单查 | 顶栏通知入口、未读计数、会话内历史 |
| 采购草稿误关丢失 | 关闭后本局暂存草稿，重新打开恢复；新局/读档清理草稿，不自动提交生效 |
| 招聘未安排就先聘用 | 先预览选择岗位、门店，最后一次确认聘用；取消不增加员工或工资 |
| 不同入口辞退保护不一致 | 删除招聘页直接辞退，统一使用员工页带后果说明的确认流程 |
| 挪动一个家具也歇业全天 | 新增快速整理，只在编辑期间暂停；整体装修保留歇业一天 |
| 临时存放到期强制锁窗 | 三天倒计时保留；不足一天/到期显示可点击提示条，窗口可关闭，批量入箱和搬货仍可用 |

替换安排会立即将原岗位员工转为待安排；跨店调入者仍是明天到岗，确认框明确说明今天的空岗与日薪。不会悄悄辞退员工或改变跨店生效规则。

## 重复入口收敛

- 自动装机改为员工管理中的每店一个开关；培训迁移到员工卡片，避免删入口后丢功能。
- 招聘页仅招聘，不重复提供员工管理、调班、辞退、采购入口。顶栏员工是统一入口。
- 经营总览保留顶栏，移除柜台和菜单中的通用重复跳转。
- 店面装修归店铺装修页，“我的”仅保留住所摆放入口。
- 任务卡仅“查看步骤”可打开说明，移除整卡点击；顶栏任务保留，便于收起任务条后找回。
- 背包、报表、叫货车、屋内小窗口移除正文中重复关闭，保留标题栏关闭和 Esc/右键。
- 普通地点面板只保留标题栏关闭，并说明关闭返回街上。
- 长期目标统一名为“三年目标”，入口归经营页；移除菜单重复入口和目标页重复人物列表。
- 人脉图、人物详情仍在顶栏人脉；账本归经营页，菜单移除重复账本入口。
- 叫货车保留底栏及临时存放中的情境入口；通讯录弱化为联系司机。
- 纸箱保留场景/库存访问，背包内改称“转存物品”；日程与手机日历共享同一功能。

另补退租安全检查：本店纸箱或临时存放非空时禁止退租，防止清理入口后仍发生物品丢失。
