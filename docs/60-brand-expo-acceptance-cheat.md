# 社区资格与品牌展会验收窗口（2026-11-04）

入口：Unity编辑器运行游戏，左上角**作弊 → 社区资格与品牌展会验收**。城市生活验收列表也提供同一入口。仅编辑器显示，未修改正式发行版的解锁门槛。

## 使用方法

1. 点击“创建展会测试档（直接获得社区资格）”。使用独立测试进度，保留进入前的正式进度快照，不需要先做第一章寻图或经营五家店。
2. 社区直接开放，公园/花园仍未开放；准备15万元起始资金、一个实际电脑店、“晨湾科技”品牌、CPU和显卡各60件、可安排参展的员工许明，以及已认识的创作者/嘉宾。起点位于云帆会展中心门口，仍要正常进入场馆。
3. 点“打开季度展会”，选择来源门店、商品和接待方向，正常支付2000元并交出3件样品。可安排许明和陆栀/温岚，补贴和人物行程沿用正式规则。
4. 从作弊窗口点“报名后推进到展会当天09:00”。预置日期为第68个总日索引，展会为第75个总日索引；保留展前7天报名截止，不把过期报名改成允许。
5. 实际进入会展中心，完成三轮接待。每轮间隔30游戏分钟，可正常放时间，也可使用窗口内“接待等待：推进30分钟”。工具不会替玩家选接待方向或加分。
6. 接待结束后，在季度展会页发出20件采购线索订单，扣真实库存和运费，等真实运输到货再收款/加影响力。不会直接标记已交付。
7. 可保存独立测试槽；点“返回进入测试前的正式进度”恢复本次会话的原进度。重启后若没有原会话快照，可从主菜单加载正式存档。

## 快进与边界

- 开幕快进只对带专用标记的独立展会测试档生效，未报名、已到开幕、正在工作/出行/活动时不会跳时间。
- 每次最多推进60游戏分钟，继续运行正常经营、工资、NPC和运输结算；仅此按钮执行期间补足饥饿、健康、精力和缺觉状态，避免跨七天被晕倒打断。平时测试仍使用正常身体规则。
- 仅此专用快进期间略过普通过程弹窗显示，防止一周门店通知堆叠遮住展会界面；实际账务、库存及经营结果仍执行。快进结束后恢复正常弹窗。
- 新预置不自动报名，不自动完成三轮接待、订单、主线或社区之后的道路资格。
- 老的“展会、人物与故事路线”参观预置保留，和新的品牌参展验收分别使用。
- 本轮未打Windows包，未自动提交或上传GitHub。
