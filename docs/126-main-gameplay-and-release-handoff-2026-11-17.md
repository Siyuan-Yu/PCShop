# PETSHOP 主分支玩法与构建交接

更新于 2026 年 11 月 17 日。[当前完整玩法](124-current-game-content-2026-11-17.md)记录项目全貌，[美术、界面与 WebGL 启动交接](125-art-ui-and-webgl-startup-2026-11-17.md)记录新版人物、场景和启动方式。

## 主菜单、操作与主线

- 主菜单使用 PETSHOP 标题和等比铺满的城市封面。标题、副标题和主操作在左侧。加载存档可用时高亮；「帮助」「关于」「退出游戏」使用同一排同样式按钮。加载界面沿用九格存档位。
- 顶栏快捷键为我的 M、背包 B、手机 P、任务 R、日程 C、通知 N、员工 H、资产 O、采购 G、物价 I、品牌 L、赛车 T。菜单用 Esc，任务条的收起提示同步使用任务快捷键。
- 开局引导突出可操作的设施、键位、金额和等待时间。开店设备任务列全所缺品项。NPC 对话采用深色正文，背包和送礼选择使用可辨认的格子、数量和状态。
- 买完小电驴后，主线依次提示「开第二家店」和赛车登记。第二家店从设施摆齐后的次日起计入，任务使用任务栏和轻提示。已开两家店或办完赛车登记的存档可跳过该步。
- 已进入出行路线时，可以从邀约提示或日程直接转去赴约。同一目的地复用路线，改道条件不满足时保留原路线。最早仍可提前六个游戏小时出发。活动进行时的世界时钟及提前结束结算沿用活动规则。
- 街景在低俯角和大缩放范围下会自动调整相机距离，避免近裁剪切掉街景底部。雨滴覆盖随新取景位置更新。坐下与站起动作随人物姿态过渡。

## 门店、餐饮和物业

- 中介地图按该中介负责的区域展示房源，突出小型、中型和大型店铺。选择经营类型采用带物品图标的卡片。商铺和住宅的租赁、购买使用合同版式，突出房源、款项和约定。确认时播放签名，并在实际成交前复核价格与办理条件。
- 货架使用暖色界面与更紧凑的格子布局。采购与陈列用现有图标、名称、数量及货架容量信息。订单交期按当前游戏时间显示剩余天、小时和分钟，覆盖鱼餐、装机、企业采购、转介绍和展会交付。
- 餐馆「订单」页只显示鱼餐预订。普通堂食在柜台处理，团购及转介绍可从「人脉经营故事」处理。厨师优先制作备齐的鱼餐。缺鱼时可打开冰箱或从订单前往钓场，交付由玩家确认收款。
- 冰箱合为单门 **500 千克**和双门**不限容量**两种，旧设备按兼容映射读取。餐馆可在后仓存放从农贸市场采购的食材，冰箱管理可操作后仓、背包和冰箱中的库存。厨师烹饪只从冰箱取材。柜台会提示缺冰箱、缺食材以及后仓可补的数量。
- 垂钓绿区跟住鱼时，收线进度上涨速度比上一版提高 **50%**。鱼离开绿区时，进度下降速度提高 **100%**，降到零会脱钩。

## 银行、物价和事件反馈

- 现金低于零时，每个游戏日最多弹一次银行借款提醒。当天的提示状态随存档保存。银行由张淑琴值白班 **08:00–20:00**，林晓宁值夜班 **20:00–次日 08:00**。柜员实际到岗后才开放柜台，旧存档读取时补入夜班柜员。
- 手机「周转借款」与其他手机应用共用窗口尺寸和缩放。顶部展示可借额度和当前现金，申请页左栏是金额与期限，右栏是还款预览。申请使用既有动作验证，成功后转到「我的贷款」。日历与工作台的还款入口可以直接打开贷款记录。
- 商品单日涨跌绝对值超过 **10%**时，按同一天合并成弹窗。证券独立使用当前交易规则，单日涨跌上限为 **20%**。NPC 聊物价时的消息与预测沿用人物行业和当前市场状况。
- 刮刮乐开奖会弹出奖金到账或未中奖结果。顾客事件的处理反馈也使用弹窗。自动订餐入口提示避免把「手机 → 外卖」拆成两行。

## 试玩、源码与桌面构建

- 日常开发和正式构建以 `main` 为准。WebGL 试玩从同一源码用 `WebGlTrialBuild.Run` 注入 `PCSHOP_FIRST_CHAPTER_TRIAL`。城郊开业至少 **5 家店**、自有现金达到 **¥1,000,000**且无未偿贷款后，直接完成试玩目标，可以留在城郊继续经营。完整版仍有街区引荐和后续片区。
- 旧 Windows 包曾从较早的 WebGL 工作树构建，缺少主分支后来加入的全屏封面、新角色和界面。另一次启动失败来自固定 NPC 人数检查，夜班柜员加入后触发异常。现已取消生产启动对固定人数的依赖，身份唯一性由编辑模式用例覆盖。
- 2026 年 11 月 17 日，Unity **2022.3.6f1** 从基于 `main`、包含当时本地改动的副本成功构建 Windows x64，归档约 **120 MB**。已核对全屏封面资源、借款新版、夜班柜员和 ZIP 完整性。实机启动尚未验证。
- 当日另有一个使用 Mono 构建的 macOS 通用包，包含 Intel 和 Apple 芯片架构，归档约 **120 MB**。它早于本次 `main` 整合，构建与归档已核对，macOS 实机启动尚未验证。
- 本次 GitHub 同步包含源码、资源引用和文档。既有 Windows、Mac 和 WebGL 发布包保留在各自的构建输出中。
