# 所有商品的重量说明

> 快餐最新规则：购买后按实际重量放背包，之后在饭点/饿时自动进餐，或在背包手动吃喝；支持冷藏和存档。此前强制堂食、不占重量的规则废止。见 [第26篇](26-fast-food-takeaway.md)。

更新日期：2026-11-01。

## 界面规则

所有可携带商品在名称下面单独显示小字“每件/每份/每袋 X 千克”，重量不再混在长描述中。通过统一的 `ProductLabel` 格式保持位置、字号和单位一致，较长说明放在重量下一行，并相应增加商品行高度。

覆盖实体档口配件、家具城、烟酒礼品与水果、农贸米菜、1788批发与自动补货、个人网购家具/礼品/袋装米、员工采购目录及已选清单、店内库存和货架、购物车与搬货卡片、背包商品格。盒装和散件按各自的实际承重分别显示。

- 配件：`Stock.SpaceOf(part, boxed, 1) × Backpack.KgPerSpace`，与背包/车辆负重算法一致。
- 家具、礼品：各自定义的 `WeightKg`。
- 食材：每份实际 `WeightKg`，大米散装显示每次加购0.25千克，网购按 `RiceBagKg` 整袋显示，员工按采购包装的 `UnitKg` 显示。
- 购物车：同时显示单件重量和当前批次总重量；背包格显示单件重量及件数，大米格保留其实际总千克数。
- 手机、服装、已安装设备和载具当前没有背包承重数据，分别明确标注随身使用、穿戴、直接安装或不装入背包，不编造重量。快餐明确标注堂食、不占背包重量。

此次只补足显示，不改商品重量、背包上限、运输规则、售价或存档格式。
