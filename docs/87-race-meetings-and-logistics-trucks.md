# 赛车赛程、11人比赛与进货货车（2026-11-07）

## 赛程和奖金

正式比赛不再每天开放。每周一举行大赛；小赛从第1年1月3日起每3天举行一次，按全局日序计算，不随换月重置。同一天同时符合两种赛程时只举行大赛。免费练习仍在赛场营业时随时可玩，城郊练习场继续24小时开放，其他赛场9:00—18:00。

| 类型 | 参赛费 | 冠军奖金 | 亚军奖金 | 季军奖金 |
| --- | ---: | ---: | ---: | ---: |
| 每周大赛 | ¥200 | ¥2,000 | ¥1,200 | ¥600 |
| 三日小赛 | ¥100 | ¥1,000 | ¥600 | ¥300 |

其余名次和退赛不发奖金，免费练习不收参赛费、不发比赛奖金。各级赛场采用同一奖金表，原片区与胜场条件保留。赛场接待和赛场列表显示今天的赛事、费用、冠军奖金及下一场日期；无赛事时仅正式比赛按钮不可用。

实际开赛时锁定本场类型，完赛奖金按该类型和真实名次结算，结束后日期变化不会改写本场奖金。比赛、练习仍固定1倍速，保留右键调整镜头和A/D仅控制车辆转向；不恢复健康、精力准入门槛。

## 10名对手

正式比赛为玩家加10名对手，共11人。对手分两列、间隔排列在起点后方，沿同一条实际赛道行驶；表现位置与碰撞检测使用同一条车道偏移。排名、完赛时间、R复位罚时推进对手和HUD人数全部按10名对手计算。

对手速度高于此前两名对手，按赛场等级及个体顺序变化；大赛再提高强度。免费练习不生成对手。

## 车行四类与货车用途

购车和整备页按“小电驴 → 三轮车 → 货车 → 轿车”显示分类。顺丰仍卖小电驴和三轮车，湖岸汽车城仍卖货车和轿车，不出售的分类会说明应去哪家车行。

小电驴、三轮车、轿车三类可指定通勤车或作为入库赛车，车库管理和赛场选车继续按这个三类顺序。

货车购买或从二手车行展位转为自用后，直接进入全城员工进货车队：

- 只能给员工采购计划使用，仍保留实际车辆编号与往返占用。
- 不可切换为玩家出行方式，底部通勤按钮移除小货车。
- 不可设为通勤车，不可参加比赛或免费练习。
- 无需租购车位，不占车库容量，不在地区车库之间调运。
- 在“资产 → 车产”里单独显示进货货车车队、占用状态与参考残值，在车行办理整备和回收。
- 仍作为自有车辆计入资产与日常养护，二手车行商用展位继续与个人车辆库存分离。
