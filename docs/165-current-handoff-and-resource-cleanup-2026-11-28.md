## 换设备

1. 切到本交付分支并拉取 `origin/art/experiment`，用 Unity 2022.3.6f1 打开。
2. 派生地图 `Assets/Generated/CityBake/` 按需重建。当前格式版本为 17，烘焙入口是 `CityMapBaker.RunBakeOnly`。若沿用了旧花园缓存，先重烘，再检查树冠和地图加载。[地图预生成与加载](地图预生成与加载.md)
3. 回归从隔离镜像及独立存档执行。日后复测使用 `tools/run-tests.ps1`，感情线和写字楼图形验收分别用 `tools/qa/run-visual.ps1 -Capture RelationshipExperienceCapture` 与 `-Capture QaRuntimeCapture`。验收目录保存测试摘要、用例 XML、源码指纹及实机记录。
4. 上次交付的 Windows 包基于 `7c51368a`。本篇覆盖其后的项目源码、资源、文档与验证证据，发布包版本及大小另见[上次构建记录](164-native-performance-continuation-2026-11-27.md#构建与继续方法)。
