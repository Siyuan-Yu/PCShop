## 系统核对

- `old_market` 是已有的通用旧物闲逛活动，地点仍为电子批发市场 `stall_cpu`。没有独立旧物市场场景和一套场内旧物商品买卖。
- 已有玩家二手店的收购、鉴定、上架与真实库存系统。旧物维修尚未实现；二手车辆维修属于另一个系统，不能当作钟表或电子旧物维修使用。
- 宁汐有模型摄影的人物设定、剧情及相关合作描述，但没有玩家取景、构图、按快门、保存照片的实际拍摄玩法。76未伪装成已能拍摄。

## 已实现的七项

| 73 任帆的电子展邀请 | 每月10–12日实际预约和到场，普通入场由邀请人提供；逐个走到新品、供应商、企业需求展位，现场体验交流要经过五分钟。普通参观不要求电脑店，商务采购要求保有已开办电脑店，并打开现有真实采购渠道自行确认。预约不直接加见识。 |
| 74 韩征的内部场 | 每月9日布展现场，参观与协助调试分开预约。调试有三个真实展台及不同故障线索：过载支路、未接通电源、松脱信号线；玩家选处理方式，操作五分钟后检查结果。错选消耗精力并可再试，未解决不能去下一台。三台都正确且完整完成90分钟后支付¥1,500，提前离开不付全额。指示灯随完成情况改变。 |

| 77 沈晓的城市模型之行 | 使用现有人物关系：`life_enterprise`是其父亲。孩子与父亲都要实际到场；约在展期内周末休息日，照顾上学与工作安排，预约最多向后查三个月以找到展期周末交集。现场有城市微缩景样件，可听小凳子的细节或观察搭建。赠送扣真实背包模型，有冷却；无需买礼物才能陪逛。现货不会冒充孩子记忆里的旧款。 |
| 78 顾客的好评 | 必须有真实结账或餐饮／团购成交记录，绑定对应门店及商品。可感谢、问具体意见、征求同意后转发；转发安排次日起营业时的潜在到访，是否成交仍取决于库存、服务和价格，不直接发钱。 |
| 79 找错零钱 | 统一为真实现金成交后发现“少找”。差额为该笔价款的10%，最低¥1、最高¥50，绑定收银记录。盘点确认的待退现金单独入账，并等额计入负债，净资产不因此增加。可立即补还、约一小时后来取或暂缓；退还时只扣一次并清负债，原正常商品收入不重复扣除。待退清单在财务及现金流水中可处理；拖延两天有一次口碑损失。 |
