# 员工管理、进货员与车辆（2026-10-31）

## 入口与岗位

- 顶栏新增“员工”，可在任意地点查看所有自营店员工；店内“招人”页也有“员工管理”入口。
- 每家自营店有收银员、装机员、进货员各一个岗位。招聘仍在自己的店内贴启事，次日 9:00 来面试，候选人行选择“收银 / 装机 / 进货”。
- 收银员负责值守和收款，可按原规则花 ¥1,200 培训兼做装机，日薪增加 ¥60。
- 装机员入职培训 ¥1,200、日薪增加 ¥60，原有自动装机与排班保留。
- 进货员按玩家采购单外出买配件；不代替收银值守，不会仅因雇了进货员就让无人看管的店开门。
- 员工列表展示姓名、岗位、日薪、今天所在店、在岗/休息/外出状态、班次、明天的调店安排及最近一次进货结果；可调整班次和辞退。

## 跨店调动

1. 在员工卡片点“安排明天调店”。
2. 选择目标自营店。岗位不变，目标店相同岗位已有人或被其他调入安排预留时，不允许覆盖。
3. 今天仍在原店工作；跨到次日后换到新店，工资、班次、装机完成数和收银培训保留。
4. 生效前可在员工列表取消。存档会保存安排和生效日期，读档不提前调人。

昨日工资在调店前结算，员工不会在两家店重复领工资。原店的未完成订单保留；缺少可装机员工时清除员工工作倒计时，后续可继续处理。目标店临时有了人、退租或员工仍在出差时，调动取消并提示重新安排。

## 进货操作：三步设置

在员工列表或店内进货员卡片点“安排进货”：

1. **去哪里买**：电子市场按品类自动找档口，或指定一家档口；指定档口不卖的配件会明确提示，不能自动替换型号。
2. **买什么**：每个型号设置本趟件数，支持减一、加一、加五、清空清单。该单是固定件数，不是库存目标；现有 1788 自动补货仍是另一套按库存目标补货的规则。
3. **怎么运回来**：选择步行+货车、打车+货车、小电驴、三轮车或自有小货车；设置含交通费的预算上限。

界面直接列出货款、往返车费、货车运费、合计、总件数、总重量、预计送到店的分钟数。即使未到上班时间或市场已关门，也能查看清单费用；派出按钮写明本趟支付金额。

- **保存安排**：保存清单、档口、运输方式、预算和每日开关，不立即扣钱。
- **按清单派出**：检查通过后统一预付本趟货款、车费和运费，锁定报价与当日档口额度；员工和货物进入在途状态。派出后关闭员工列表与采购单，不留下界面暂停锁。
- **每天进货**：默认关闭。开启后，工作日上班期间每天尝试一次，按清单固定件数采购；失败记录原因，当天不反复刷屏，调整后可以手动派出。周末市场不营业。
- 不超预算、不擅自减少数量或换型号；预算不足、现金保留不足、仓位不足、档口额度不足、没有空闲车、超载、市场未营业或来不及下班前回来都会阻止出发。
- 付款后继续保留全店工资、房租、车辆养护和近期债务所需现金，沿用补货现金保留设置。

## 运输与车辆占用

| 方式 | 车辆要求 | 装载与费用 |
|---|---|---|
| 步行 + 货车 | 不占自有车 | 员工步行往返，货物叫面包车送店，每车 200 公斤 |
| 打车 + 货车 | 不占自有车 | 往返打车费 + 按车数计算的货车运费，每车 200 公斤 |
| 小电驴 | 一台空闲小电驴 | 整趟最多 20 公斤，员工自己运回 |
| 三轮车 | 一台空闲三轮车 | 整趟最多 80 公斤，有违规罚款和扣车风险 |
| 自有小货车 | 一台空闲小货车 | 整趟最多 160 公斤，按每台每天 ¥60 养护 |

- 车行可购买多台同类车，按钮显示“购买一台 / 再买一台”，每买一台扣一份车价。
- “员工”→“查看车辆与占用”显示各类车总数、空闲数、老板占用、哪位员工使用及扣押数；老板底栏切换车辆也遵守同一份数量限制。
- 员工出发时占一台自有车，返店后释放。老板当前选中的自有车占一台；想交给员工可先把自己的出行方式切回步行。
- 只有一台小电驴时，进货员使用期间其他人不能用；两台则可同时供进货员和老板使用。
- 在途采购保存员工、目的店、运输方式、到货/返店时间和清单。存读档保留占用；返店释放一次，到货入库一次，不重复付钱。
- 步行/打车模式中员工与货车可不同时间抵达，列表按员工返店状态显示，货物送达独立提示。前一趟人或货未结束时不能派下一趟。
- 在途员工/货物未完成时不能辞退进货员或退租目的店；正在被员工使用或被扣押的车不能出售。
- 配件送到出发时所在的那家店；计入该店在途库存和仓位，避免另一家店错误算作已经补货。在途配件也计入库存估值。
- 三轮车员工出差返程有 15% 的违规检查概率，罚款沿用现有 ¥200；被检查后按原扣车概率决定是否扣押，须去车行每台 ¥500 赎回。该首版参数仍需平衡。

## 叫货车快捷入口

底栏新增“叫货车”，直接打开原有货车装货单，选择货物与送达地址，不需要先打开手机。手机通讯录里的“货车司机老蔡”入口和原有搬货流程保留，两处使用同一套逻辑。

## 存档与代码

- `GameSession.Workforce.cs`：统一员工列表、次日调店、进货单报价与派出、员工/货物在途推进、车辆总数及占用。
- `GameUi.Employees.cs`：员工列表、调店选择、车辆占用和三步采购界面。
- `Employee` 增加稳定身份、待调店/日期、采购计划和最近结果；旧员工读档生成身份，原有姓名、工资、班次、培训与熟练度保留。
- `OwnedShop.Buyer` 保存本店进货员；主店和分店均有独立 `hasBuyer` 标记，防止 Unity JSON 把空字段变成未雇佣的零薪员工。
- `ownedVehicles` 数组允许同类多项，兼容旧档的一类一辆；新增扣押台数和在途采购字段。小轿车/小货车养护按总台数结算。
- 本次未改变已有店铺侧栏的暂停/继续规则，员工管理和采购弹窗按普通窗口自动暂停。
