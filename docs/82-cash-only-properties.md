# 住宅、商铺全款购买及旧档按揭清理

用户确认：旧存档中这部分全部去掉。

## 当前规则

- 中介住宅与商业物业购买只保留全款入口；购入确认仍列房价、交易费、搬家费或押金及预付租金抵扣。
- 取消按揭首付、贷款本金、月供本金与利息、提前还贷入口及相关提示。出售收入不再扣贷款余额。
- 物业租金和月维护费继续正常结算。资金保护额只预留适用货款、APP贷款和物业维护费，不再预留房贷月供。
- APP贷款与工厂直供货款账期维持原规则，本次清理对象为住宅及商业物业按揭。

## 旧存档迁移

加载时将自住房及所有持有物业的贷款本金、月供本金字段归零，保留产权、房价、租户、租约、家具与库存；不补扣或返还现金，不修改已经发生的历史流水。

旧字段及旧接口为兼容存档和既有调用保留。字段不再恢复欠款，按揭购买与提前还贷接口不再扣款或生成贷款；再次保存写入清理后的数据。
