## 城市、主线与人物

- 湖城由城郊、社区、公园、花园片区组成。住宅、商铺、批发市场、公园、餐馆和交通站点共用城市路网、营业时间和游戏时钟。完整版从城郊出租屋开始，通过开店和经营成果、人物引荐、实际到场、展会及商业订单逐步开放片区。[城市与片区配置](91-city-expansion-v15.md) · [主线与开放条件](story-and-district-progression.md)
- WASD 移动，F 交互，空格暂停或继续，1–4 选时速，Tab 折叠功能栏。底栏可以步行、打车、骑通勤车、搜索目的地或叫货车。顶栏有我的、背包、手机、任务、日程、经营、物价、股市、品牌和赛车，部分入口随进度开放。[操作、商店与生活系统总览](124-current-game-content-2026-11-17.md) · [自定义目的地](120-custom-destination-picker.md)
- 开局教学依次覆盖做饭、中介、开店装修、货架和货源、首单、招聘、智能手机与自动订餐、收款码、通勤车、证券以及扩开新店。第二、第三家店根据实际店型续接装修、上架和首单。餐馆还有食材、烹饪与堂食步骤。[教学与开店流程](146-current-gameplay-and-playtest-2026-11-20.md#教学店铺经营和配送)
- 第一章引荐门槛为城郊开业五家店、现金达到 ¥1,000,000 并结清贷款。进入引荐流程后，回复李秀兰，联系陈启明，按约和唐蔚见面；分别与李秀兰、林远航和周维成完成指定散步、餐叙、逛旧物市场，按线索取三张图页后当面交付。找人读取 NPC 的实际地点，邀请与交付走通讯录或人物对话。社区开放镜头约 13 秒，可跳过，演出期间暂停时间和事件。第一章 WebGL 试玩在经营门槛后显示试玩完成，可继续留在城郊经营，使用独立存档。[主线导航、会面与开区演出](146-current-gameplay-and-playtest-2026-11-20.md#主线找人和街区开放)
- NPC 有住处、职业、路线、在家与在岗状态、喜好、日程及关系。可当面聊天、赠礼、约活动、交往、招聘或谈直播代言。赴约要考虑路程、到场时间和营业时段。普通饭局点餐后按游戏时间等上菜，可以边吃边聊天；已有固定菜单的约饭，碰面后直接入席。城郊平地散步公园、河岸公园全天可用。住宅上门通常需好感达到 30 或有入户邀请。[NPC 日程、拜访与到场活动](146-current-gameplay-and-playtest-2026-11-20.md#人物日程与到场活动)
- 约见对话用角色口吻表达还要等多久、是否到场及接下来怎么做。一起活动后，同场参与并完成或中途结束的 NPC 会留一句告别；文本考虑活动类型、熟悉度、家人或情侣关系。结算窗口保留游戏数据，NPC 发言以自然对话呈现。约见的任务页负责展示地点、时间与等待进度，人物窗口按实际是否到场及当前阶段给出一句可读的答复。

## 多店经营、商品与资金

- 「经营 → 店」默认整窗显示所有门店。选中后才在右侧展开本店概况和采购，左侧可继续切店。列表单独显示进货员与最近实际到货，此外有营业状态、今日经营收入、近 7 日收支差额和待处理事项。岗位会影响要不要安排进货员，补货、缺货、到货和人员状态使用实际数据。全店补货预算、直供协议及账款仍有跨店入口，采购归入各店详情。玩家界面从采购等入口撤掉「在途订单」用词和入口，订单、运输与到货逻辑继续按实际状态推进。[门店和采购设计与实现](145-current-game-and-store-management-2026-11-19.md#经营--店与采购)
- 「经营 → 员工」汇总所有店的真实雇员、岗位、名额、排班和工资。智力、魅力、动手能力和体能影响岗位，界面可预览效果；同店换岗当天生效，跨店调动次日生效。员工或玩家可用实体市场、手机网购、直供或按库存阈值和清单补货。车辆、容量、路线、营业时间和交付目的地影响配送，可叫货车。店内柜台继续处理排队、定价、货架、库存和到店服务。[员工、采购与排班](13-employees-and-procurement.md)
- 店型包括电脑配件及装机、服装、饮品、代养、模型手办、二手旧物、餐馆、场馆及二手车。各店使用自己的货品、设施和经营流程。电脑店手动或员工装机、按时交单并反馈口碑，服装与手办定价考虑顾客预算，代养接送及照料实际宠物，餐馆备料、做饭、上菜、收款与收桌，并支持鱼餐预订。餐馆饮料使用货架现货，二手车有车源、整备、挂牌和出价。二手店从收购鉴定、修复到上架出售使用实际库存容量。[各店型与货源](145-current-game-and-store-management-2026-11-19.md#店型员工与货源)
- 模型店有晨湾航行、雨巷守望、苔园来客、星灯工坊四个原创系列，常规款和限定款可陈列销售，上下游行情影响零售。客带模型委托与库存分开，当前已有喷漆、改胶加喷漆和对应的质量、耗时、交付、口碑结算，手工或在岗喷漆师均可处理。二手修复台单独操作，修复师能力影响耗时和成功率。家具城售价为**模型喷漆台 ¥900、二手修复台 ¥600**。后续维持现有委托深度。[模型委托、修复台和费用](144-model-commissions-and-event-cg-handoff-2026-11-19.md) · [二手店修复和销售](132-used-repairs-and-sales-2026-11-18.md)
- 物价、经济简报和门店账本展示实际交易、趋势及明细。可看硬件与模型行情，以及现金变化、分店收入和支出；近 7 日经营收支差额包括实际进货等经营支出。银行支持存取款、贷款、还款及手机借款。证券支持自选、持仓、现货、做空、保证金及强平，银行和手机共用报价。品牌可升级并绑定门店，MCN 可认识主播、谈代言、排直播，展会和竞标使用实际展品、库存和订单履约。[经济报表](134-economic-and-price-dashboards-2026-11-18.md) · [股市](90-stock-market-and-short-selling.md) · [品牌、展会与竞标](54-brand-expo-tender-playable.md)
- 通勤与赛车分别管理。通勤车辆各自保留扣押状态，可提前领回或三天后免费归还。参赛车辆可登记、改装、维修、跨区调车和管理车位。自由练习 ¥100、两圈，正式比赛也为两圈；成绩、罚时和奖金走比赛结算。[赛车和车辆状态](146-current-gameplay-and-playtest-2026-11-20.md#中介租约和赛车) · [区域车库](85-regional-garages-and-parking-spaces.md)

## 商铺、住宅与快捷出行

中介和资产入口使用同一套类型名称和状态颜色。经营入口接入商铺经营收支，页面按门店、街区或店型查看经营实账。

| 玩家要做的事 | 入口和交互 |
| --- | --- |
| 看名下资产 | 「我的 → 我的资产 → 商铺／住宅／车产」。商铺和住宅用实际城市建筑、道路、地形和水面做全城或片区总览，可缩放、拖动、选建筑或从右侧列表定位。商铺保留「全部商铺经营收支」入口。 |
| 看一个片区的房源 | 对应片区的中介。地图保留正常街景和相邻区域可见的边缘，拖动和缩放视野受中介负责片区约束。名单、选址和办理范围均随中介切换。 |
| 辨认已购、已租 | 中介和资产页统一使用**金色表示已购、浅蓝色表示已租**。描边、标签或选中效果帮助定位同一栋建筑。 |
| 找到同片区的另一间房或店 | 点快捷回家或快捷前往自营店旁的小三角，每处住宅、每家店按具体地址单列，选定后可保存到快捷位。当前主住宅和实际可前往的店可直接选。锁区、路线不可达、已有租户、现金不足以打车或当前操作阻止前往时，按入口规则置灰并说明原因。场所营业时间会在服务入口提示，允许到门口的地点会在抵达后重新检查入场条件。 |
| 自用、开店或出租 | 商铺空置时可办理自营开店或出租，住宅可留作自住。登记自营时撤下该店的招租，出售产权时保留原租户。详情首屏同时放主要状态、地址和常用操作。仍有租户、主住所未迁出、玩家尚在物业内或仍自营时，会给出具体阻挡原因。 |
| 给中介出租或改价 | 资产与中介详情内有同一周租滑块，范围为参考周租的 50%–200%。滑块实时显示周租、租客意愿与成交中介费。首次操作是「确认出租」，已招租时可「确认改价」或撤下。 |
| 收回房源 | 招租中可撤下。已签约可预约到期收回，之后也可取消预约；满足到期条件的房源可直接收回。收回后按空置处理，可重新出租或自用。 |

- 中介按天撮合，低价租客意愿高，高价可能长时间租不出。参考价的日基础成交概率为 32%，最高报价时约 2.9%，较低报价的上限为 88%。固定 30 天空置期已经取消。成交后入首周租金，并按现有中介费规则扣费，基准为半周租金，应用中介关系折扣；之后按周结算。住宅成交会记录实际租户。
- 新签的玩家业主租约每 28 天滚动续期；玩家可以预约到期收回，NPC 默认继续租住。玩家向房东租商铺或住宅时，租期按既有约定持续，仍保留玩家退租、欠租与主住所等游戏规则。旧版托管商铺迁移为保留原租户、到期收回的既有租约，原折扣仅在这份旧合同内有效。
- 商铺与住宅的租购、签约、交房、账单和地产成交都使用实际地址及账本。玩家支付的商铺和住宅周租各自汇总、分别提醒；签约预付首周，后续周日结算。[旧版地产与合同基础](82-cash-only-properties.md) · [现有基础包的租金规则](146-current-gameplay-and-playtest-2026-11-20.md#中介租约和赛车)

## 生活、休闲与小游戏

### 日常活动与目前的交互

- 日常可打工、做饭、打包食物、买食材、点外卖、自动订餐、穿搭、睡觉、安排工作台和经营计划。饥饿、精力、健康、营养、情绪和气候共同影响人物状态。衣柜可按季节查看和试穿已拥有衣物。居家工作台的经营、投资、联系人和生活自动化可按各系统设置。[生活、住宅和工作台](145-current-game-and-store-management-2026-11-19.md#市场资金物业与生活)
- 已有餐叙、夜宵、郊游、普通散步、垂钓、篮球、高尔夫、场馆、现场调饮和摄影。钓鱼用鱼饵、浮漂、提竿和控张力，钓获可做饭、赠送或处理；篮球用瞄准与蓄力；高尔夫用选杆、力度和落点；摄影现场有自己的照片记录。社区花灯会按节日安排在服务站前，可与 NPC 一起逛。旧物市场仍可照常买卖、查看、修理和处理闲置。[垂钓](105-fishing-system.md) · [场所消费](104-premium-venue-services.md) · [现场活动及摄影](115-onsite-events-51-58-and-76.md)
- 酒吧用独立吧台画面，可以挑饮品、点单，部分饮品支持加蜂蜜，同行者可以接话。KTV 在独立包间界面选曲，可听伴奏或按空格接唱。钓鱼增加实际水面画面和浮漂提示，咬钩后有 3 秒提竿时间；篮球增加明确的偏左、偏右、过头或不足提示。酒吧保留喝酒场所身份，德扑和台球各有自己的店。
- 宜居社区公园可散步、坐湖岸，也可单人或和 NPC 一起划船。划船 ¥180 一条船，45 游戏分钟。用 A／左方向和 D／右方向交替划，跟上节奏会滑得更顺，慢一点也能继续，可以随时返航。靠岸再结算，情侣、熟人和初识的同行者使用不同告别话。划船定位为放松或约会，没有名次。
- 社区运动场可练足球点球，每场 5 球、¥300、40 游戏分钟。移动瞄准，按住空格或射门按钮蓄力，松手射门。可一个人练，亦可约 NPC 一起来，同行者可以守门。继续采用社区球场和游戏现有人物；进球、扑救、出界有直接反馈。篮球保留在现有运动场。

### 抓娃娃奖品与配送

- 投币前，机台显示从小铺送到家的单辆运费。新叫车沿用现有按路程计费的规则。
- 抓中奖品时，随身负重还有空间就直接放进背包。装不下时自动叫车，扣运费后按游戏时间运往家中后仓。已有从这里送回家的车且还有空间时，奖品装上同一辆车，免付额外运费。机台会显示已入背包、已付运费或已并车。
- 现金不足以支付运费时，放弃本次奖品，投币费照常结算。机台即时提示，获得件数只统计进背包或已安排送达的奖品。
- 已付费的配送随现有货运记录一起存档。旧档里已留在机台的奖品，在读档时免费转入家中后仓。

## 后续路线

开了几家店、员工接手日常经营以后，玩家现在很容易回家睡觉、跳过当天、等下一笔钱。接下来的目标是让这段时间有值得主动去的地方、想见的人和能继续的事情。门店自动经营继续存在，生活安排由玩家自己选择。

| 顺序 | 接下来做什么 | 边界与验收 |
| --- | --- | --- |
| 1 · 先做一轮中盘体验验收 | 用五店验收档模拟连续几个游戏日，走一次店铺经营、空闲邀约、白天与夜间休闲、收尾对话和第二天日程。分头验证划船、社区点球、淘货、柏青哥、地下牌庄、抓娃娃、台球和两处影院。 | 看当天能否自然安排一两个想参与的活动，能否从平时入口找到玩法，以及预约、营业时间、结算和返回世界是否衔接。抓娃娃加验背包可装、扣费配送、并车、运费不足和旧档迁移。先修实测发现的操作与提示。 |
| 2 · 让常驻场所和人物形成回访 | 更多 NPC 根据喜好、日程和关系主动提议去既有场所；结束后接住实际活动、成绩、淘到的东西或同行者关系。旧物市场可用现成物件和熟人对话做回访，优先用已有内容。 | 普通日也能去玩。事件适合做邀请、同行和后续话题。酒吧保留点酒和聊天氛围；对花灯、旧物市场等，以场景内可辨认的东西和直接反馈提高在场感。 |

### 界面与美术原则

- 从当前游戏截图、真实场景、人物和物件起稿，延续现有 UI 与暖色微缩美术。按地点、时间、天气选择明暗和色调。涉及精细操控的机台、牌桌和球台用独立视图，机台奖品复用现有物品。
- 首屏优先显示关键状态、主要数据和常用动作。可读字号、按钮尺寸、分栏与紧凑布局都用足以后，再用滚动或分页；一页里尽量避免两层滚动。减少重复说明，把条件与后果放到相关确认框或提示。可常用的自营、出租、改价和收回动作直接留在详情。
- 商铺、住宅、已购、已租等同一概念在资产页、经营页相关入口和中介使用统一术语与状态含义。世界地图保留真实建筑，受区域约束的入口用可拖范围表达责任区。不能前往的目标置灰并标明原因。人物对话用自然话，系统数据放状态或结算区。
