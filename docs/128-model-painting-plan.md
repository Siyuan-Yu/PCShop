# 模型手办店：改胶／喷漆玩法备忘

记录日期：2026-11-18。

**状态：2026-11-19 已接入首版。**

家具城的模型店设备分类出售喷漆台（¥900）。摆进自己的模型手办店后，正常进店的顾客偶尔会带自有模型来委托。靠近喷漆台按 F，或通过店铺柜台的「模型委托」查看。客带模型独立于门店商品库存。

| 环节 | 规则 |
| --- | --- |
| 接单 | 同一门店每隔一到两天可出现新委托，未接的报价两天后失效。每店同时最多保留四笔待接或在办委托。已接委托可继续处理或归还。 |
| 玩家加工 | 在喷漆台做三道工序。普通喷漆从打磨底漆开始，改胶订单从修件粘合开始，之后均为主色喷涂和细节收边。游标越接近目标中心，单步得分越高，三步平均为最终品质。可以退出并继续。 |
| 员工加工 | 模型店可聘用或安排喷漆师。委托交给员工后，在营业时段有电且员工实际在岗时推进，每台同时处理一件。动手能力决定速度和品质。 |
| 耗材与交付 | 喷漆耗材 ¥30、基础工费 ¥180。改胶加喷漆耗材 ¥60、基础工费 ¥360。开工扣一次耗材，交付时按 0–10 分品质结账并调整店铺口碑，高品质交付增加个人名望。归还模型结束委托，已用耗材不会退回。 |
| 存档 | 按店保存订单和加工进度。搬店保留订单；已接委托须先交付或归还才可转型或退租。旧存档摆上喷漆台即可开始接单。 |

下方保留首版开发前的设计备忘。

## 已确认方向

| 项目 | 设计方向 |
| --- | --- |
| 服务 | 模型手办店增加“改胶／喷漆”服务，名称暂定。 |
| 委托来源 | 偶尔有 NPC 带自己的模型到店，委托玩家门店喷漆。 |
| 专属岗位 | 增加“喷漆师”职业／岗位，由员工承接喷漆工作。 |
| 主要能力 | 喷漆师的动手能力影响喷漆质量。 |
| 质量评分 | 喷漆结果以 **0–10 分**表示，体现喷涂准确度和最终质量。 |
| 必要设施 | 店内需要摆放“喷漆台”。 |
| 玩家参与 | 玩家也能亲自进行喷漆交互，形成可手操的服务玩法。 |

NPC 带来的是委托加工的自有模型，后续设计应与门店普通商品的进货、上架及零售区分。

## 后续需要设计的内容

- 委托出现频率、同时待处理的上限、交付期限和服务价格；目前只确定“偶尔来”，未确定具体数值。
- 动手能力如何映射到 0–10 分，是否允许随机波动，以及玩家手操结果如何评分。
- 喷漆操作的具体交互方式、难度、完成时间，以及员工自动制作与玩家手操如何衔接。
- “改胶”是否包含独立于喷漆的改造操作，还是先以喷漆为首期范围。
- 喷漆台价格、占地、并行处理能力，以及是否需要颜料等耗材。
- 评分如何影响报酬、满意度；是否奖励名望及奖励多少，尚未确定。

后续实施前再细化交互和经济数值。本备忘不代表上述待定机制已经批准实施，也不调整当前模型手办店的收益。
