# 开发路线（草案）

原则：每个阶段结束都是"可玩的东西"，先验证核心好不好玩，再加内容。

## M0 工程与基础（当前）
- [x] Unity 工程、目录、asmdef 分层、.gitignore
- [ ] 主界面框架（顶栏：日期/资金；侧栏：页面切换）
- [ ] 游戏时钟（暂停/1x/2x/4x）
- [ ] 存档/读档框架

## M1 行情 + 进出货（核心验证）
- [ ] 商品池：4~6 个品类（显卡、CPU、内存、硬盘、主板、电源），每类若干虚构型号
- [ ] 价格模型：基础价 + 隐藏因子（币圈热度、AI 需求、新品周期、库存/缺货、政策/汇率）+ 噪声
- [ ] 走势图页面、新闻/研报（含不完整信息）
- [ ] 进货、库存、仓储成本、出货、资金曲线
- [ ] 事件系统（数据驱动）
- [ ] 验证标准：玩家能"读懂行情"而不是纯靠运气；用测试跑模拟检验价格走势合理性

## M2 装机与客户订单
- [ ] 装机配方（兼容性规则简化，UI 选配件）
- [ ] 组装时间、利润、客户订单、网吧/企业/电商等客户类型
- [ ] 账期与坏账、现金流压力

## M3 扩张
- [ ] 分店框架（统一"店铺 + 商品池"，数据配置）
- [ ] 其他业态：饭店、手办模型店
- [ ] 员工/雇佣

## M4 主播与关系
- [ ] 主播 NPC（粉丝量、风格、好感度）
- [ ] 推广合作合同、对销量/客流的影响
- [ ] 好感度/恋爱线（注意内容尺度与各地区审核）

## M5 上架准备
- [ ] Steamworks 集成（成就、云存档）
- [ ] 商店页素材、内容调查（含 AI 披露）
- [ ] 平衡与测试、Demo/愿望单

## 待决策
- 正式游戏名与美术风格基调
- 时代设定（现代 / 近未来架空）
- 本地化范围（先简中）
