# 开发路线（草案 v5，对应 02-design.md v0.3）

原则：每个阶段结束都是"可玩的东西"，先验证差异点，再加内容。开工顺序（已确认）：世界层灰盒 → Core 业务 → 店内手操与 UI → 核心循环验证 → 美术升级。

任务引导约束（2026-10-30）：现有及后续所有任务只说明地点、操作方式和当前进度，不提供一键前往、自动寻路、传送或代开目标页面；玩家自行移动和操作。只派发当前经营阶段的任务，不展示远期目录，已完成教学不回看。教学按钮仅用于查看/关闭说明，知识类教学在对应实际页面确认阅读。
