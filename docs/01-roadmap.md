# 开发路线（草案 v5，对应 02-design.md v0.3）

原则：每个阶段结束都是"可玩的东西"，先验证差异点，再加内容。开工顺序（已确认）：世界层灰盒 → Core 业务 → 店内手操与 UI → 核心循环验证 → 美术升级。

## M0 工程与基础
- [x] Unity 2022.3.6f1 工程、目录、asmdef 分层、.gitignore、Git
- [x] 设计文档（含竞品与差异化）
- [ ] AI 2D 美术风格试验（1 个角色半身像 3 表情、5 个硬件图标、UI 配色/字体、招牌/海报样张）并登记 asset-log
- [ ] 确认美术工具及商用条款
- [ ] 中文字体（思源黑体）导入 TextMeshPro（VS1 暂用系统微软雅黑 + uGUI Text）
- [x] 程序生成城市（街道、建筑、店面、街道设施、占位人物与车辆）与 URP 打光，三套光照预览（`docs/previews/`）
- [x] 赛博朋克光影升级（霓虹点光、雾、SSAO、反射探针、后期），详见 `06-art-and-rendering.md`
- [ ] 美术可替换约定落地：人物外观组件、车辆预制体、店铺模块挂点
- [ ] 美术升级（核心循环验证后）：买单品包 / 外包 / 保持极简，三选一或组合

## M1 底座（纯 C#，带单元测试）
- [x] 时间系统：日历 GameDate、时刻 GameTimestamp、连续世界时钟 GameClock（分钟级，跨午夜自动分段，TimeAdvanced/DayAdvanced 事件）
- [x] 星期：GameDate.Weekday / IsWeekend（7 天一周，第 1 年 1 月 1 日为周一）
- [x] 账本（Money、Ledger：收入/支出/强制支出、按日期和类别统计）
- [x] 时间控制 TimeController：暂停、1×/2×/4×/8×、面板自动暂停（Hold/Release）、1× 每游戏分钟秒数可调（默认 0.25）
- [x] 营业模拟 ShopSimulation：按分钟生成顾客（时段、周末、位置、规格、知名度系数），挑货 → 排队 → 结账入账；等太久或没带现金离开；无人值守关门；支付方式（现金/收款码/自助结账）
- [x] 一局运行状态 GameSession：玩家位置、进出地点、进店开门/离店关门、结账推进耗时、在家睡到 8:00、23:00 睡觉提醒、批发商营业时间
- [x] 载具与载货量、打车计费、交警（视线、追逐、罚款、扣车）的 Core 规则
- [x] 角色状态 PlayerStats（饥饿、精力、健康、缺觉、智力/魅力/技术），接入世界时钟（通用 Stat/Modifier 框架后置）
- [x] 生活系统（VS1 部分）：自动三餐、睡眠与缺觉、小憩、凌晨 4 点晕倒、住院；衣着、居住环境、手机档次后置
- [x] VS1 目标与清算：第 30 天净资产 ≥ ¥8,000 且雇过人；现金连续 3 天为负破产（长线 3 年目标与多结局后置）
- [ ] 人物与关系（NPC 数据、关系值、标记）
- [ ] 事件系统（数据驱动：条件/选项/后果）
- [x] 带种子的随机数服务 GameRandom（营业、行情、交警、1788 共用，状态进存档）
- [x] 存档接口与序列化（每天自动存 + 手动存，单存档位）
- [ ] 业态模板框架（数据配置 + 专属模块钩子）

## M1.5 世界层灰盒（详见 04-3c-and-world.md）
- [x] 路径图（WorldMap）、A* 寻路（Pathfinder）、移动耗时（Transport/TravelCalculator/TravelPlanner，Core，带测试，含与 Floyd–Warshall 对照）
- [x] 沿路径位置插值（PathWalker）
- [x] 城市布局数据格式 CityLayout（JSON：节点、边、地点、店铺规格、业态、玩家的店、压缩路段长度、巡逻路线、档口品类），Core 解析与校验
- [x] 起始地图数据 `Assets/Resources/Data/city_layout.json` + `StreetWorldBuilder` 按数据生成，一张连续大地图
- [x] 玩家沿路径移动并推进世界时钟（画面匀速、耗时按游戏距离）、相机跟随/缩放、时间控制条
- [x] 点击建筑/名牌前往并进入；打开面板自动暂停
- [x] 小店室内灰盒：固定镜头，顾客挑货、排队、柜台结账（现金），离开小店关门
- [x] 街道行人（CrowdView，灰盒）
- [ ] 拍照模式、里程碑镜头（可后置）
- [x] 一条商业街（20 家店，玩家最小最偏）+ 地铁站 + 5 条街外的城中村住所 + 约 2 公里外的电子配件批发市场
- [ ] 验证：走路耗时是否让取舍有感；世界层是否不拖沓（等验收反馈）

## M2 VS1：一个月流程（验收说明见 07-vs1-acceptance.md）
- [x] 配件数据：6 个品类 × 3 档，接口兼容规则
- [x] 库存与容量：店铺按规格有容量（格），散件/盒装占用与卖价不同，拆包装不可逆
- [x] 价格与行情（新闻 → 宏观指标 → 品类价格），含模拟测试
- [x] 进货：线下档口（肉身跑过去、可砍价、工作日营业）与"1788"平台（推荐/试错发现店铺、次品率、次日到货）
- [x] 载具：步行、打车、小电驴、三轮车（耗时与载货量），地铁
- [x] 交警：骑三轮车时概率出现，可见视线扇形，被发现追逐，追上罚款，可躲进店里
- [x] 装机订单队列与手装机小游戏（2D 拖拽，装错算失误、更耗时）
- [x] 雇人：招聘、应聘者、工资、员工值守小店并自动结账
- [x] 房租、破产、月目标
- [x] 基础 UI 框架（代码生成）：HUD、行情、店铺面板（柜台/库存/定价/装机单/1788/招人）、地点面板、系统菜单、弹窗
- [x] 自动化：119 个单元测试 + 批处理冒烟测试（脚本化走完一个月并截图）
- [ ] 验证：手操到雇人是否有手感；行情是否可读；守店结账是否不烦；节奏是否舒服（等验收反馈）
