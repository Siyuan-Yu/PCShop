# 剧情总纲、人物支线与四区晋升流程

记录日期：2026-11-02。

> **本轮已确认的叙事设计方向；各项实现状态以当前工程核对结果为准。**
>
> 本文是后续剧情内容制作的统一设计入口，不是实现清单或游戏验收报告。本轮仅记录决定与必要的工程差异，不开发剧情、不修改运行时规则。具体数值、人物绑定和事件细节以文末“待定事项”为准。

## 1. 叙事定位与内容层次

游戏是一款在架空近当代城市中，通过**多业态经营、人物关系和生活探索**共同推进的商业人生游戏。电脑、服装、模型手办、二手旧物、餐馆等店型都可以成为进入故事的方式；实际可经营店型以当前工程为准，不因本文举例扩充店型。

不再以“旧电脑城发展成科技新城”为总主线，不把所有故事固定在电脑行业，也不要求其他店型玩家靠装机推进主线。

整体采用四层内容：

- 轻量的四区成长主线。
- 贯穿式人物支线。
- 普通居民日常。
- 可选的投资起落与再起故事。

主线不需要解释一整套复杂商业阴谋。优先通过已有的聊天、买卖、订单、采购、推广、饭局、展会、招聘、排班、开店、租赁、购置物业和投资呈现故事。功能大体沿用现有工程，后续以内容填充为主；必要的少量事件标记、具名顾客、对话条件和后续反馈可在未来补充，本轮不实施。

## 2. 核心主题：从被规则筛选，到参与规则

已确认的核心表达：

> 玩家曾经觉得一些规则不合理。后来逐渐进入其中、从中获益，也开始理解、遵守，甚至维护这些规则。与此同时，玩家仍然可以决定怎样对待后来的人。

主题不等于“有钱以后一定变坏”“普通人永远无力改变事情”“有资源的人都是坏人”“所有商业门槛都没有必要”，也不要求主角放弃财富才能获得好结局。

真正关注的是：

1. 前期玩家接受别人给出的条件，后期开始制定别人需要接受的条件。
2. 规则有合理用途，也可能不断巩固已有优势；玩家对同一规则的评价可能随自身位置改变。
3. 掌握较多选择的人，与没有多少退路的人，所说的“没办法”并不完全相同。不能为了显得复杂，把所有强势行为都解释成没有选择。
4. 玩家不能解决全城问题，但能对自己参与的具体交易和合作负责。

“成为资本”具体表现为拥有物业、订单、供货资源、岗位、合作机会与选择权，不只是现金达到某个数值或走进奢华区。

贯穿方式是：同一种条件，前期让玩家接受，后期让玩家制定；同一句理由，前期由别人说，后期出现在玩家的选项里。可反复呼应的情境包括：

| 规则情境 | 叙事关注 |
| --- | --- |
| 没有履历，就难以获得建立履历的机会 | 谁愿意给第一次机会 |
| 新人需要预付或承担更多保证，成熟客户反而条件宽松 | 风险与信用怎样分配 |
| 好机会优先在熟人之间流转 | 信任的便利与圈外人的处境 |
| 付出过进入成本的人反对后来者更容易进入 | 过去的不公平怎样成为自己的优势 |
| 提高自身收益的条件同时提高别人的起步或留下成本 | 交易双方承担的代价不同 |

这些是故事情境，不是增加五套复杂模拟系统的要求。

## 3. 四区成长主线

区域顺序为**城郊片 → 社区片 → 公园片 → 花园片**，对应低端、中端、高端、顶奢的地区与经营环境。NPC的人格、价值和故事深度不按地区分等级；城郊人物也能拥有关键经验与关系，后期仍值得回去见面。

| 阶段 | 已确认的成长内容 | 主题重点 |
| --- | --- | --- |
| 城郊片：有人愿意带你入行 | 从小店起步，认识商户、熟客、员工、供应商；面对履历、资金、引荐门槛，通过一次真实表现获得关键人物介绍 | 第一次有人愿意给新人机会 |
| 社区片：从认识人到被认可 | 积累客户与合作方，机会开始经熟人提前到来；实际合作记录得到两三位相关人物确认，再进入公园片经营圈 | 人脉带来信任，也可能挡住没有关系的新人 |
| 公园片：你也拥有需要维护的优势 | 参与更大订单、推广、品牌或渠道合作；付出进入成本后享受稳定资源，面对降低新人门槛的提议产生犹豫 | 曾经的不公平成为自身优势后的重新解释 |
| 花园片：现在轮到你解释规则 | 影响租约、采购、合作名单与机会分配；面对类似过去自己的新人，可沿用标准，也可给试单、介绍等有限机会 | 通过人物回应与经营变化呈现后果，不直接判善恶 |

主线不要求固定日期完成，不因错过某天强制失败。不要求每种店型都开一遍，也不要求炒股、买豪宅或发展恋爱才能完成成长。主线结束后继续自由经营，人物保留后续日常。

## 4. 三次晋升的渠道与流程

三次晋升分别是：**一个人愿意带你；一圈人能够确认你的经历；你已经能带着资源来谈合作。**

晋升主要开放新区域的经营接洽机会、相应铺位或商业合作名单，以及更重要的客户、渠道和私人商业活动。不把公共道路、普通消费和公共场所全部锁在好感后面：玩家可提前去高区域看看、消费，开展特定生意时再面对接洽条件。

晋升表达游戏中的商业圈准入与合作机会，不包装成现实法律上的经营许可；也不免费赠送店铺或资产，租金、采购、装修和合作投入仍按正常规则承担。

### 4.1 城郊 → 社区：一次可靠表现与一位引荐人

核心条件：**一位关键人物愿意引荐＋基本经营表现。**

推荐主渠道为李姐或小陈（设计讨论中的“陈中介”）的商户关系；替代渠道为老周或已有实际交往的熟客。这里确认的是渠道方向，最终绑定与条件仍待后续制作。

1. 正常开店营业，认识附近人物。
2. 通过中介或聊天得知社区片机会及接洽条件。
3. 熟人介绍一笔适合当前店型的小额业务。
4. 玩家通过现有经营玩法实际完成。
5. 引荐人安排见面或简短饭局，介绍社区经营联系人。
6. 相关经营机会开放，玩家自行决定是否投入。

电脑店处理相应需求；服装、模型店完成正常选购与交付；餐馆真实接待；二手店通过对应正常交易证明可靠。不强迫所有路线装电脑，不增加复杂团购或专用生产系统。第一次流程保持短，不做长串请客送礼任务。

重点反馈：同样的玩家，因为有人愿意介绍，事情突然更好谈了。

示意对白（不是最终逐句对白）：“就是我之前提过的那位老板，事情做得还算稳。”

### 4.2 社区 → 公园：客户与伙伴共同确认经历

核心条件：**两三位相关人物认可＋一段实际合作记录。**

推荐关系结构是一位实际客户与一位合作伙伴共同帮助接触公园商业联系人，不是随便认识三个NPC凑数量。客户确实使用过商品或服务；伙伴一起做过供货、推广或经营合作；区域联系人接受引荐并判断具体合作适配性。

1. 已进入社区经营圈，积累正常经营经历。
2. 日常业务中形成一位真实客户和一位合作伙伴。
3. 完成一次有结果的合作，例如推广后的真实成交、一次交付，或在既有展会履行职责。
4. 两方愿意介绍或确认玩家履历。
5. 在饭局、展会或商户会面中，与公园联系人正式接洽。
6. 相应铺位、客户或合作机会开放。

不固定所有玩家必须认识同一套人，按店型和已走人物线提供少量等价路径。方向示例：模型可关联陆栀与合作商户；服装可关联宋棉、温岚及相关客户；电脑可关联企业客户与供应商；餐馆、二手可经具名熟客与商户合作进入。**这些不是已实现路线，具体分配后续依据当前角色关系确定。**

重点反馈：玩家第一次发现，自己的名字会在不在场的时候被人提起。

示意对白：“上次那件事，合作的两边都提到过你。”

### 4.3 公园 → 花园：带着资源落实一项合作

核心条件：**足够经营实力＋一位圈内引荐人＋一位有实际合作经历、有一定分量的合作者＋落实一项适合自己的真实合作。**

实力不只看钱包余额，不能炒股赚一笔就自动晋升，也不强迫经营多个行业。保留两种等价证明：

- 多店路线：能够组织多家店的人手、采购、经营与合作。
- 专精路线：主要经营一家成熟门店，但有持续客户、可靠交付与稳定合作。

物业、资金和长期业务可作补充条件，具体数值未定。

1. 在公园片形成成熟业务与关键关系。
2. 圈内人物提出花园片某项实际商业合作机会。
3. 一位既有合作者愿意支持或共同参与。
4. 与相关方见面，选择承担部分，谈清条件。
5. **先开放本次合作需要的接洽、场地或签约入口。**
6. 通过现有经营方式实际落实承诺。
7. 进入更广的花园核心合作名单。

推荐承载事件是花园片一处既有商业场地的开业或商户合作，可提供商品、服务、经营一家店或参与已有推广。玩家只承担适合自身业务的一项，不要求新建巨型项目或购买整栋楼。

不能形成“先在花园开店才能获得花园开店资格”的循环。圈内引荐人掌握当地场地、渠道或客户；第二位合作者了解玩家，能共同承担业务。第二位可以是已经成长起来的创业员工，但只是可选路径；不能既让员工必须等玩家进入花园才能成长，又要求员工成长后才能引荐玩家。

重点反馈：对方不再只是审核，而是询问玩家能提供什么。

示意对白：“这件事，你准备负责哪一部分？”

晋升后可紧接一个小事件：另一位新人想加入，有人来问玩家是否了解、是否愿意考虑。它只表现玩家开始参与筛选，不做强制善恶考试。

### 4.4 共通规则

1. 好感帮助开始交流，不能代替真实履约；无限送礼或每天打卡不能直接刷出资格。
2. 条件与当前缺口在游戏内说清楚；达成后确定推进，不随机判定晋升失败。
3. 合作失败可补救、重试或换等价路线，不清空所有关系。
4. 不因未完成晋升强制涨租或清档。
5. 已有资格、人物记忆与当前资金实力分开。投资失利后可能暂时承担不起大项目，但人物不会忘记过去履约；履历与关系可以成为再起资源。
6. 后续接入旧档时，不因新增流程取消已有资产与合法经营状态，具体迁移届时另定。

### 5.1 老周：《我只能替认识的人担保》

早期介绍货源与客户，也说明自己为什么谨慎。玩家受益后逐渐采用相同筛选标准；后来新人请求合作，玩家也担心对方没有履历。讨论信任怎样降低风险、第一次机会为何难得。不把老周写成永远兜底的工具人。

### 5.2 阿杰：《我当年也是这么熬过来的》

既是同行也是朋友。共同经历进入圈子的困难后，阿杰珍惜已有优势，未必赞成降低门槛；他认为自己的成本与努力应受保护，并非突然变坏。双方可竞争、合作、有分歧，不安排必然背叛。

### 5.3 李姐与街区租户：《下一次续租》

前期希望房东给予周转空间，后期自己拥有物业，熟悉租户也提出相似请求。更高报价、稳定租户与长期经营各有价值。用谈判、续约、搬迁或招牌变化体现同一条件在交易两边的不同重量。不强制涨租，也不保证低租一定带来更大回报。

### 5.4 创业员工：《第二块招牌》

明确保留的正向长期人物线：

**可靠工作 → 日常透露创业愿望 → 认真提出具体计划 → 玩家选择支持方式 → 准备与交接 → 开自己的店 → 逐渐站稳发展 → 成为独立合作伙伴。**

支持可为建议、看铺、介绍货源、真实订单或条件明确的资金支持；不给钱不等于拒绝整条故事。员工开的不是玩家换名的分店。他有自己的判断，借款与承诺正常履行，帮助不产生终身服从义务。

后期可就品牌、选品和合作方式有分歧，最终谈成适合彼此的合作。不靠成功后背叛制造戏剧，也不让他成为自动感恩返利资产。

他可成为晋升花园的可选支持者，或在玩家失利时提供真实业务；没有投资失败，也能通过共同项目相互成就。**人选与最终店型未锁定，许明只是候选。**

### 5.5 莫莫：《这次先按合作方的要求》

从真实介绍商品与生活发展到更多商业合作。一次妥协确实带来收益，也让下一次更容易被接受。玩家既是朋友，也希望推广有效；双方处理宣传承诺、私人经历与商业效果的边界。不写成从一开始就欺骗玩家。朋友、合作与可选恋爱互不强制绑定。

### 5.6 上层经营者：《我们一直都这么办》

提供大项目与花园机会，确实帮助玩家，同时提出有利于自身的条件。可以友善、有能力，并非固定反派；玩家成长后可能开始采用相同解释。角色姓名及复用安排待定。

### 5.7 小林：《你现在说话像个老板了》

了解玩家过去，真心支持，也比较自己的人生。普通聊天中，玩家对别人的困境给出商业解释，小林提起他以前也抱怨过同一件事。小林不是道德裁判，也有求助、羡慕与自己的选择。通过老朋友视角表现玩家变化，不把友情变成纯业务资源。

## 6. 生活与人物探索支线

这些故事不必全部服务晋升。保留普通友情、兴趣、生活与快乐，不让全城每个人都代表一种社会问题。

| 人物或方向／工作标题 | 已确认内容与边界 |
| --- | --- |
| 陆栀：《我已经不喜欢那个角色了》 | 想离开早期热门作品尝试新创作，但普通顾客曾因旧角色得到快乐、朋友或生活支撑。创作者有权改变，顾客的珍惜也不浅薄。用选品、展会、聊天呈现，不预设商业热门肤浅、小众原创高尚。具体旧角色尚未制作。 |
| 宋棉与温岚：《看起来像那么回事》 | 选衣、设计、体面与商务场合；同样能力因外表受到不同对待，衣服既是表达也可能是证明身份的压力。普通得体服装满足正常场合，奢侈品不是万能通行证；具体分支与愿望后续再写。 |
| 杜师傅、老张与熟客：《这里还有我的位置》 | 便宜的一道菜、书店愿望、常坐的桌子连接日常。经营调整后有人更常来，也有人换地方。不要求保留一切，让客流、租户和价格背后有可认识的人；各情节最终归属待细化。 |
| 二手旧物：《价格能鉴定，经历不能》 | 鉴定能确认真假与状态，不能完整判断感情和经历。卖掉不一定不珍惜，仿品不一定承载虚假感情。利用已有收购、鉴定、转售与人物关系做少量具名故事，不模拟每件商品完整流转史。 |
| 其他居民日常 | 夜校、换工作、家庭、合租、爱好、友情与约会等短内容。可只有轻松与快乐，不一定给金钱或能力奖励，也不必升格为阶层或资本议题。 |

莫莫与陆栀等人物各自保留已有身份与内容，职责分工以后细化。

## 7. 可选投资起落与再起

### 《这次消息应该很可靠》

玩家经关系获得项目信息，自行决定不投、少投或重仓。消息可真实，结果仍不确定；项目有独立发展逻辑，不能检测玩家全仓后才临时安排失败。

损失对应实际投入和经营选择，不删除未投资现金、未承担相关风险的物业和全部门店。不设某天必然灾难、强制破产或必败投资关。引荐人也可能判断错，但只投少量资产：进入同一圈子不等于有同样的风险承受力。

### 《这次换你给我一个机会》

投资或经营失利后保留履历、人物关系与经历，可出售合格资产、缩减业务、打工、接订单继续生活。曾受帮助的员工或合作方可提供真实订单、引荐与共同业务，不无条件填坑，不凭空发“剧情救济收益”。

不破产也能体验平等合作。再起是可选人生分支，不是主线必经环节。上市、做空、融资发行及复杂证券模拟不列为本轮已定必要内容。

## 8. 叙事呈现与制作边界

1. 优先使用已有玩法，不为每段故事加新系统。
2. 统一复用“人物立绘＋对话正文＋选项”的原主对话界面，不再新建居民、员工或剧情专用主窗口。
3. 饭局、活动、看铺、展会仍需真实到场；接受邀请不等于完成，不恢复点击后立即结算整场活动的旧行为。
4. 业务真实发生：订单要交付，商品要买卖，推广需要实际成交，买物业需要支付和权属变化。不以剧情按钮凭空发利润代替经营。
5. 重要事件至少说明怎样发现、玩家做了什么、之后人物或世界有什么变化。变化可小到新对白、工作地点、店铺招牌、后续邀请或下一笔正常订单，不必大量过场动画。
6. 人物有自己的目标、判断与关系，可以感谢或不同意玩家，不只是等待玩家解决的问题。不把每条写成“有烦恼→玩家花钱→人物被修好→发奖励”。
7. 不把主题直接做成善恶按钮，不使用“是否压迫别人”“是否成为坏资本家”等选项；使用正常经营表达，说明条件与代价。
8. 玩家行为必须明确，不能偷偷替玩家涨租、拒绝合作或使用隐私，再通过剧情指责玩家。
9. 不保证善意总更赚钱，也不安排恶意行为必遭机械报应；收益与后续可以不同方向。
10. 不为表现“不合理规则”故意让操作困难、拖慢进度。门槛有说明、替代路径与适度负担，不把表达变成折腾玩家。
11. 重要人物先有相处趣味和具体愿望，再逐渐体现主题；不靠悲惨身世、长篇演讲或不断反转制造深度。
12. 少量关键内容前后呼应，例如早期别人说“不是你不行，我们一直都这么办”，后期类似理由出现在玩家制定条件的场景里，无需旁白宣布主角变了。
13. 主线结束后继续自由经营，人物仍有后续日常，不变成任务完成后的空壳。
