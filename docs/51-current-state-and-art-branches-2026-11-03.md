## 3. 三个相关分支

| 分支 | 内容与用途 |
| --- | --- |
| `main` | 持续开发主线。本次把原工作区的工业风美术、人物剧情内容与文档正式提交，保留已经提交的UI整理。 |
| `art/industrial-reference` | 工业风参考快照，固定在`97b0697`。它保存像素版开始前的工业美术与当时玩法基线，也包含当时人物配置；不包含后来main的完整UI整理。 |
| `art/pixel-town` | 独立像素风实验版，`9c50b61`基于工业快照制作。未合并main后来的UI整理；不应把它当作main全部最新内容的替代品。 |

两个美术方案使用相同基线地图和玩法。像素分支只调整表现；本次同步文档不会将像素美术合入main，也不移动两个美术分支的历史位置。

### main／工业版

- 蓝灰、砖棕、黄铜和暖纸色；建筑屋面、檐口、窗框、管线、通风设备等工业细节。
- 金属、木材、砖石等程序材质；住宅、别墅、店铺、家具、植被与湖水配色统一。
- 日间、黄昏、夜间的环境光、补光、阴影与水面表现；深色经营面板、图标与浅色人物对白区。
- 人物立绘保持比例；美术附加构件不增加碰撞或地点标记，不更改地图道路和玩法。

实际游戏截图：[街景](previews/art-variants/industrial-street.png)、[店内](previews/art-variants/industrial-shop.png)、[对话](previews/art-variants/industrial-dialogue.png)。这些由实际场景构建器与游戏UI渲染，不是生成的效果图。

### 像素版

- 橙红屋顶、蓝灰窗框、奶油色建筑、明亮绿植与粉色花树。
- 世界画面使用固定像素网格、色阶与边缘处理；树冠使用分段光照和叶片色块。
- 原人物立绘增加像素采样，保留人物身份；UI采用深蓝、金黄、暖白配色与阶梯边框，文字保持清晰。
- 使用3D场景与像素化渲染，尚不能等同于参考板中逐像素绘制的全部细节。没有为追求概念图密度增加道路、建筑地点或游戏功能。

实际游戏截图：[街景](previews/art-variants/pixel-street.png)、[店内](previews/art-variants/pixel-shop.png)、[对话](previews/art-variants/pixel-dialogue.png)。
