## 当前规则

| 81 快递丢件 | 仅在有真实已付款、送店的网购配件订单时触发，绑定订单号和实付金额。等待令原到货时间延后两天，申请查件延后三小时；不是从当前时间提前送货。取消投递索赔会移除该单在途货、释放关联补货预留，两天后按原实付款及运费赔付一次。已取消订单不能再通过普通退款入口领钱，也不会再到货。到货时间同步采购记录。当前覆盖网购配件订单，现有面包车配送、普通商品包裹和直供订单未纳入丢件池。 |
| 82 对面贴了降价单 | 复用现有真实同行促销，与旧价格战共用同一轮状态。仅对同行活动中的同款临时九折，结束后恢复；原价应对与加强服务也沿用原系统。跟价不另扣¥100或¥1,000，少赚反映在真实成交中；已处理的同一轮不能再通过旧事件重复处理。 |
| 83 店里来了只猫 | 到已开办门店的临时可见小猫。放水后显示水碗、最多留45分钟；轻引离开3分钟，不打扰20分钟。到时离开，保存剩余截止时间；不永久收养、不直接加魅力或口碑。本批未开启完整养宠系统。 |
| 84 供货商送样品 | 认识周维成且保有已开办电脑店，借一件真实型号样品，次日10点到店。样品单独记录并显示实体“试用样品·非卖品”，不混入可售库存。到店可试用10分钟、归还或按报价买断；只有买断扣实价并将一件实物入库，且检查含在途订单的剩余仓位。试用后归还或买下交情+2一次，不自动给店口碑。 |
| 85 邻居换招牌 | 现无梯子物品，改成实际帮许文杰换招牌。可约当前下一可用时段、明天或婉拒；不是虚构借梯子归还。根据真实工作地点与日程预约，双方实际到场相处30分钟后交情+4、精力-5。原建议的“打烊后”调整为“约明天”，避免闭店和对方已离岗时无法完成。 |
| 86 差评 | 必须有七天内对应门店、经营类型和租约的真实成交记录。了解问题、协商补偿、公开回复三选一；补偿是该笔实付10%，最高¥500，先显示确切金额。实际支付一次后次日反馈，不保证花钱删评价，不凭空制造退款或让钱变口碑。原有好评和找零处理不互相消耗。 |
| 87 学生党想要折扣 | 按店型与真实商品报价：一件九五折、三件九折、原价或不接。生成真实订单，不立刻发¥180；确认接单后备货／装机／做餐，交付扣实际商品才收款。沿用团购无企业保证金、无3%企业奖励的规则。 |
| 88 门面陈列建议 | 有实际绿植／海报陈列才触发。自己调整打开现有装修；记录陈列位置，实际改变且不减少装饰数量后才安排后续潜在顾客。设计师¥1,500，到店确认开始后扣费、操作30分钟，再按真实布局检查安全位置并挪动装饰；没有安全位置全额退设计费。均沿用当天歇业装修规则，不偷偷改全局营业设置。不是花钱只加一个属性。 |
| 89 库存变动待复核 | 旧版本没有可证明的账实差额，所以改为待复核提醒。现在盘点或约打烊后盘点，到店开始、暂停接待，实际30分钟，离场暂停。报告列后仓配件／零售商品／二手实物或大米、待结账、在途数量和今日真实成交笔数及金额，并保留起始快照供对照；未确认损耗不扣现金、不扣货。完成见识+1一次；恢复原营业状态，原本歇业或当日装修的店不强行开门。 |
| 90 热得没人逛 | 真实室外温度≥30℃才触发。已有空调按原气候规则改善舒适和耐心，不再收¥80；缺空调可从待办进入现有家具采购，¥1,200／¥3,600买入后还需实际安装。也可花¥1,000做晚间宣传，需该店有晚间营业时段；18点后营业时才安排四位潜在顾客，不保证卖出。照常营业不额外扣费。电费不另造。 |

## 简洁的后续入口

工具栏“日程”内新增“经营待办”，笔记本和手机日历均可进入。集中显示样品、盘点、陈列、赔付、顾客反馈和晚间宣传；有前往门店、开始、归还、买下等动作。进行中的现场操作收起窗口让时间继续；需要装修的操作明确显示“今日歇业”。空调入口使用现有采购与摆放流程。

借用样品不是玩家资产；物流索赔后取消投递，避免货款双拿；与具体门店绑定的任务记录店型和租约，门店停用／换类型后不能将旧事件奖励领到新店。设计师未完成但对应门店已停用时退已付费。
