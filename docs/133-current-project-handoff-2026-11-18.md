# 当前源码总览与本轮交接（2026-11-18）

本文记录第127篇之后至本次 GitHub 同步的累计变更。当前项目仍暂名 **PETSHOP**，Unity工程目录为 `F:/PCShopSell`，本轮分支为 `main`。历史完整系统清单见[第124篇](124-current-game-content-2026-11-17.md)，前一轮试玩修正见[第127篇](127-playtest-fixes-and-handoff-2026-11-18.md)；下述最终规则覆盖相应历史参数。

## 已有系统与本轮重点

项目已有六种自营店型、员工与采购、库存及叫车物流、生活与住所、人物关系与活动、股票与银行、品牌与展会、赛车及分区主线。WebGL试玩仍只提供第一阶段城郊内容；完成原有目标后可继续经营，不解锁后续片区。

本轮主要完成：启动与地图预生成、顶部功能栏整理、银行证券教学与1股交易、开局做饭体验、中介地图边界、门店价格平衡，以及二手高价货源、自动议价、修复与销售推介。

## 启动、地图与首次场景

- 启动先展示主菜单；进入或读档后再加载街区，显示阶段、百分比、已用时间。加载期间允许后台运行，结束后恢复原设置。
- 保留增量生成回退；优化树林空间查询、共用树形和小模型缓存、固定形状顶点与碰撞体创建，按时间预算分帧。
- 道路、建筑、树林和建筑细节保存为固定摆放与共用网格。构建前按源码、资源指纹自动刷新缓存，Windows使用完整地图，WebGL试玩单独生成第一阶段地图。生成缓存忽略入库，构建机可从来源重建。
- 加载遮罩在当前位置的室内外显隐、家具、角色和镜头同步后才关闭，避免先露出街道再回家的闪现。加载阶段不推进经营时间、不接受移动输入。
- 修正 `Quaternion To Matrix conversion failed`：Unity的四元数相等运算不能用来检测全零 `default`。生成端按模长判断、还原无旋转并规范化；运行时对旧缓存中的无效值同样处理，编辑器保存后检查旋转有效性。源码指纹变化后，下次构建会重新生成缓存。本次未重新生成缓存或实机验证该报错消失。

细节、资源体积记录和首次显示顺序见[地图预生成与加载](地图预生成与加载.md)。此前生成过Windows地图预生成版本，但它不包含本轮后续全部界面、平衡和修复改动，不能作为本次最新源码的验收包。

## 界面与中介地图

- 顶部保留状态栏，通知和菜单位于最右上角；功能入口单独一排，可用Tab或折叠按钮隐藏。
- 原资产内容合入“我的 → 我的资产”，保留门店、物业、车产及原有详情和筛选；员工和采购合为“经营”，继续进入实际工作页面。
- 功能栏折叠后，任务、安排、门店及住所面板随之调整；临时消息按任务卡实际下边缘避让，保留间距，避免遮住任务。
- 中介商铺与住宅地图共同采用本片区建筑投影外轮廓，按当前可见区域内缩限制拖动，减少旧大矩形包含的无关空地。拖动、缩放、定位均走约束，保留片区概览和房源选择。不是删除或缩小实际城市地图。

## 开局做饭

- 首次推荐煮1.5千克大米，约12碗，教学数量与实际下锅数量同步。
- 教学与普通电饭煲共用等待界面，不再提供一键跳过40分钟的按钮；显示剩余时间、煮好时刻和进度。
- 煮饭窗口释放自身自动暂停，世界正常运行，手动暂停或其他窗口持有的暂停仍有效。等待期间暂时隐藏强制高亮遮罩，煮好后继续吃饭、打包教学。
- 打包提示精简为饭点或饿时自动吃、冰箱暂停保质期倒计时，并突出关键词。

## 银行与证券

- 股票最少可买1股，加减数量循环为 **1、5、25、100、200、500股**。手机、银行和居家工作台使用同一证券交易页面。
- 银行增加证券交易入口，在银行可按银行条件访问，不要求先装手机证券应用；其他入口仍遵守手机应用条件。
- 开第二家店之前增加银行证券教学，讲报价、持仓、手续费和留足经营资金。看完教学即可继续，不强迫买股票；已有第二家店或后续进度的旧档不强行补做。

模型价格普通周期为40天、约0.65～1.9倍；报价和购买逻辑都参与测算。此前成本按售出当日渠道价估算，未完整模拟低价囤货、跨周期采购成本或压货损失。新增模型展示暂复用系列已有插画，不是四张新制作插画。

二手店高价普通货源占非文物卖家约15%；好货参考转售价为相机¥1,500、游戏机¥1,800、音响¥2,400，仍有瑕疵、仿造和损坏。收购师参考估值与公开要价预留毛利，仍可能估错，不读取隐藏底价制定报价。文物2%出现率、其中10%真品及原鉴定和出售名望规则保留。

## 二手修复与销售

- 新增可选二手修复台，¥1,200、35千克；家具城二手店筛选可购买，配送和摆放沿用现有规则。靠近按F进入修复页。
- 新增修复师岗位，仅限二手店；动手与智力共同决定速度和成功率。员工名额仍为小店4、中店6、大店10。
- 每台配一位在岗修复师并行修一件。已鉴定、未上架的瑕疵或损坏普通旧物可以尝试一次修复；成功恢复好货，失败保留原状态。文物、仿造品不修复。
- 耗材按好货参考价值的8%／15%支付，计入物品总成本；进度随物品保存，下班、关门、离岗或修复台收起时暂停。修复中禁止出售及丢弃。
- 在岗修复师可自动处理符合条件的未上架物品；完成后尝试上架，货架不够则保留待上架。
- 销售优先推介≥¥1,000及久置旧物，购买意愿加成仍共用原25个百分点上限。顾客正常挑货、排队、付款，不直接变现。

完整规则和界面入口见[二手修复与销售](132-used-repairs-and-sales-2026-11-18.md)。小店可改配收银＋收购师＋修复师＋销售，不能直接沿用两名销售配置的旧收益数字。

## 收益测算的适用范围

已有离线测算按基础商品、小店、能力50、营业12小时、理想供货和在岗计算，人工、房租、估算运费单列。毛利指收入减商品成本，不等于净现金流。

- 模型增加高价款后，不同行情起点的周毛利约¥7,500～11,000；这是阶段抽样，不是每周保证值。
- 宠物用品涨价后零售周毛利约¥7,524；按两猫两狗满住且状态90～100推算，整店周毛利约¥16,868～17,576，已扣涨价后的照料耗材。入住、状态和主人结算并非完整实机寄养模拟。
- 服装90%售价方案周毛利约¥12,295、扣固定费用后约¥4,989，**已被95%方案替代，95%尚未重算**。
- 二手新增货源与议价后、加入修复前，200组平均周毛利约¥19,737，扣四人人工、房租和运费后约¥12,431。**新修复与销售版尚未重算**。
