# 冰箱、具名饭菜与营养/心情（2026-11-01）

## 冰箱购买与使用

- 家具城“家里用”“店里装饰”现有四档冰箱：¥1,299 单门 60 公斤、¥2,799 家用双门 120 公斤、¥5,299 对开门 240 公斤、¥7,999 四门 360 公斤。均可送到家或指定自营店，也进入网购和员工采购目录。最新参数与存档兼容见 [第 19 篇](19-fridge-tiers.md)。
- 冰箱可在家及任意自营店正常摆放、旋转、挪动。容量按具体型号计算，同一房间多台按型号累加；不同店与家里的冷藏食物相互独立。
- 在冰箱边按 F 打开存取界面；背包和“我的”在当地有冰箱时也提供入口。可逐份或整叠存取熟饭、食材、大米、饮料及其他食品，家具、配件和香烟不能放入。
- 电饭锅做好饭后可“把做好的饭全部放入冰箱”，无需先塞进背包。冰箱界面同时列冷藏食物和背包食物，显示菜名、数量、重量、最早到期日和剩余容量。
- 熟饭、食材首次冷藏额外保鲜 2 天，取出保留到期日。同一批反复取出、放入不再延长，不会无限刷新。到期仍会正常腐坏并提示；大米和原有不易腐食品沿用原规则。
- 收起冰箱、摆放撤销/重做不能把容量减至低于现有食物重量；退租前须清空冰箱，防止物品丢失。取出遵守背包负重上限，失败不搬走食物。

## 背包按菜名分开

此前食物批次已保存菜名，但背包将所有熟食聚为“饭盒”。现在白米饭、青菜焖饭、肉末焖饭等分别占一叠，显示各自数量、饥饿恢复、营养变化及最早到期日。选择一叠后点“吃一份菜名”，只消耗选定食物，优先吃该种快过期的。

纸箱、临时存放与冰箱使用相同的菜名区分；搬运和存读档保留菜名、恢复值、数量、到期日和冷藏标记。原有不区分菜名的旧搬运键仍兼容。

背包的食物格使用不同底色及文字区分。本次没有另制独立食物插画。

## 营养值与心情

两个新数值范围 0–100，新游戏和旧存档首次加载均从 50 开始；后续随存档保存，已降至 0 的数值不会读档重置为 50。可在背包、冰箱和“我的”查看。

目前只记录饮食造成的变化，**不据此改变健康、精力、行动、员工、客流或经营收入，也没有被动衰减和奖惩**。原有饥饿、健康恢复机制继续沿用。

| 食物 | 饥饿恢复 | 营养变化 | 心情变化 |
|---|---:|---:|---:|
| 白米饭 | +22/碗 | −5/顿 | 0 |
| 青菜焖饭 | +28/碗 | 0 | 0 |
| 鸡蛋焖饭 | +31/碗 | +3/顿 | 0 |
| 豆腐焖饭 | +30/碗 | +2/顿 | 0 |
| 肉末焖饭 | +36/碗 | +5/顿 | 0 |
| 可乐（瓶） | +2 | −3 | +8 |
| 一箱水果 | +8 | +5 | +2 |
| 一盒点心 | +10 | +1 | +4 |

手动吃一份计一次；12:00/18:30 自动吃饭可能连续吃多碗，但营养只按一顿计算，纯白饭整顿扣 5，不按碗重复扣。如果一顿混吃多种饭，按实际吃下的碗数取营养变化平均值。饱腹时仍可喝可乐。

## 饮料购买

烟酒茶行原来已经出售单瓶饮料，位于“饮料点心”；现在显示为“可乐（瓶）”，保持旧物品 ID，不丢失旧饮料库存、货架与礼品用途。购买、装背包、结账后，背包选中可乐点“喝一瓶可乐”。农贸市场水果和烟酒茶行点心同样支持自己吃；盒装/箱装按现有商品单位消耗。
