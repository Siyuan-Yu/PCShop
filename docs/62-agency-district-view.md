# 中介地图聚焦负责片区（2026-11-04）

中介商铺地图不再默认把所属片区的所有场馆、住宅、地铁和商铺一起框入。远处场馆（例如行政上归社区的会展中心）此前会把镜头撑到包含大片湖面与空地，导致真正可租的街道和房源缩成一角。

## 当前视角

- 默认按**本中介负责的可交易商铺和中介建筑**计算取景；辖区范围仍沿用实际中介划分，不改房源归属或租赁条件。会展中心在地图中虽然使用Shop类型，但不可交易，不纳入默认取景；可拖动查看其他地点。
- 将各栋建筑的真实外观角点直接投影到相机平面再取范围，避免斜向街道先包世界轴对齐大框、再旋转框入大量空白。
- 俯视角由40度改为52度，保留三维鸟瞰，让街道与建筑分布更清楚。
- “全街”按钮改为“本片区”，恢复本片区商铺概览。定位中介、放大所选房源按建筑大小确定倍率，最高放大到8倍；边缘房源允许居中。
- 原辖区的其他地点仍可通过拖动查看，预览仍只允许选择辖区地点；看房、拖动与缩放不移动玩家、不签约、不扣费。
- 住宅租售页已在第63篇接入地图，并在[第68篇](68-residential-agency-district-map.md)与商铺页统一片区取景和镜头状态。

## 验证

镜头投影、建筑范围、商圈和现有UI联合检查**44/44通过**，见[测试原始结果](validation/62-agency-district-view-tests.xml)。新用例覆盖斜向街道减少空框、实际建筑角点全部纳入取景、平移不改变缩放范围和屋顶高度，以及社区不可交易会展中心不再拉大商铺概览。

四家实际中介的默认取景与单间放大检查见[图形记录](validation/62-agency-district-view-graphics.txt)，截图在`docs/previews/agency-district-view/`。不将画面取景改善声称为经营或帧率规则变化。
