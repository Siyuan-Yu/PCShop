# 试玩反馈修订与当前交接

本篇记录第 118 篇之后的试玩反馈、操作规则及验证结果。完整项目内容、125／126 独立流程和随机事件插图范围见[第 118 篇](118-current-project-handoff-2026-11-16.md)。旧专题的金额、开放门槛和操作说明如有出入，以本篇和当前源码为准。

## 顶栏、手机和地面交互

- 顶栏的按钮和悬停说明显示各自快捷键。我的 **M**、背包 **B**、手机 **P**、任务 **T**、员工 **U**、日程 **C**、资产 **J**、采购 **G**、品牌 **L**、赛车 **R**、通知 **N**、菜单 **Esc**。赛车补上图标。输入框编辑期间不触发这些快捷键，赛中 **R** 用于车辆复位。
- 手机应用的主窗口统一使用居中的 1500 × 880 布局，包括周转借款、证券和日程。证券仍用能容纳完整交易表格的横向布局。
- 环境行人根据道路实际宽度走两侧人行道，对向分流，同向保留间距。离开视野后从可用的街道端重新进入，避免在人群或车道边界上重叠生成。
- 中介房源、签约结算和等待入驻统一显示「还有 N 天交房」或「今天交房」。提前签约仍从签约当天计租。「委托店长开店」仅在本中介有可实际开办的店型时出现。「园区筹建／管理」仅在此处确实可筹建或管理现有园区时出现。

## 采购、运输和商店

| 反馈 | 当前操作 |
| --- | --- |
| 购买时优先送到对应类型的店 | 批发市场优先匹配同类型自家店。家具城根据所选适用店型优先匹配，共用的收银台等也遵循当前分类。可以手动改目的地。 |
| 叫货车筛物品 | 可按物品类别筛选待装的背包货物、后仓和暂存货物。已经装车的货物留在装货单，筛选时保留数量。 |
| 进货、网购和购买数量 | 数量可直接输入，按回车或移开焦点应用，同时保留加减、长按及原有「最大」入口。整数商品按件处理，米和食材按千克显示，仍校验库存、营业时间和容量。 |
| 调价按钮闪烁 | 库存和预览更新时复用调价控件。滑块显示草稿与已保存状态，确认后才将新价格应用到店铺。 |
| 二手上架提示 | 缺「二手转售品」货架、容量或承重不足等情况用弹窗提示。设置品类时，到货架旁按 F，选「选择摆什么」或「换品类」，再选「零售商品 → 二手转售品」。 |
| 二手人工与代管 | 收购师和卖家站在收购鉴定台两侧，按实际摆放位置和朝向就位。每日收购预算、单件上限、出价倾向和代管开关直接显示在柜台。 |
| 米家与设备 | 「米家手机」改名「米家」。开通收款码后可在米家购买 ¥4,500 的自助结账平台，店员或老板仍需在店营业。米家另售 ¥1,080,000 的居家办公台，配送到住处，在中型及以上住宅摆放后启用。初始小出租屋没有安装资格。 |

## 银行、证券和主线

- 银行柜台和手机周转借款共用额度。名望 0 时额度 ¥50,000，每满 1 点名望增加 ¥5,000，上限 ¥500,000。可用额度扣除尚未还清的计息借款本金，旧档中超过新上限的有效借款仍照常结算。
- 计息借款每月 20% 单利，每月 30 个游戏日。提前结清按实际使用月份向上取整，至少计 1 个月，最多计签约月数。例如借 ¥50,000 三个月，首月内结清付 ¥60,000，到期付 ¥80,000。借款和还款页并列显示今天结清金额与到期金额。点击还款提醒可导航到银行，到场后打开贷款页，没买手机也能办。
- 证券现货逐只股票提供「最大买入」和「全部卖出」。最大买入按当前报价、现金、手续费、100 股整手及市场限额计算。指数买入入口已移除，旧指数仓位仍可全部卖出。
- 城郊引荐条件为城郊开业 **5 家店**、**¥1,000,000 自有现金**、**所有贷款已结清**。自有现金进度扣除待还贷款本金，银行和事件无息借款均计入贷款门槛。普通打烊的已开业店仍算，装修当天的店从次日计。达标后进入原有三天邀请流程。

## 实际赴约和手动活动

- 已选好方案的预约在接待页显示同行者与付款方式，可点击开始。需付费的预约在开始时结算，邀请人请客时可直接免费开始。歌房、电子批发市场、旧物市场和展会等入口按预约导向对应的现场活动。
- 青湾垂钓场购买时长后直接打开手动钓鱼。同行垂钓预约沿用确认好的时长和费用，到场后点「付款并开始钓鱼」。周国良事件为 90 分钟，AA ¥300 或我请 ¥600。等候阶段不结算费用，确认开钓时只结算一次。可选钓位和鱼饵，实际抛竿、遛鱼，鱼获可带走、赠送或放生。
- 篮球、高尔夫与自由赛车练习按游戏内时长购买，购买后直接操作，专属预约继续使用约定项目。普通手动玩法不经「本次消费」中转。夏澄的新饮品品尝是单独的三杯流程，操作期间暂停世界时间，三杯品尝完统一结算 **90 游戏分钟**。

- 歌房全天营业，邀请排期核对实际路程和角色班次。同址赴约无需额外预留通勤，单独进店时仍校验其他活动冲突。
- 同一次活动中，同行者的好感增量按项目限制在 5–10 点的上限范围。到场交流、互动和完成奖励共用上限，读档会计入先前已获得的增量。
- 邀约弹窗复用同一场所的路线估算和可用时段结果。生态郊游按场地与可赴约时段显示，查无合适时间的事件不会弹出一屏不可选方案。夜宵邀约先选套餐，再选 AA、我请或商量让对方请客。
- 捡到钱包后，日程给出实际地铁站。玩家抵达后在站内等 **30 游戏分钟**，再交站务员，或等失主实际到站后当面归还。等候进度与目标站写入存档。
- 电子批发市场走访在前台可直接开始，按走访节点比较报价，再使用实际的采购入口。手机店帮忙事件到场时先打开换招牌任务，直接开始帮忙。
- 通讯录、对话和人物资料标明 KOL 身份。品牌代言及相关谈约入口在解锁社区片区后开放，城郊阶段可正常认识人物。

## 赛车登记和赛道

- 完整版的新手引导之后、社区引荐目标之前加入「办理赛车登记」。达到 **¥100,000 现金**且没有未结清贷款后，可从任务栏或赛车面板导航到城郊赛场车库。与负责人免费登记后立即解锁。已解锁赛车的旧档保留资格。
- 「城郊练习场」现名「城郊赛车报名点」。登记完成后继续按入门路线准备车辆、购买车位并入库，到报名点选择本区的入库车辆练习或比赛。
- 四条赛道的可行驶路面从 10／14／14／14 扩至 20／28／28／28 场景单位，中心线单圈周长统一变为原来的 **1.5 倍**。路面、起终点、护栏、碰撞和全景取景使用新版尺寸。扩建向湖内让出空间，原接待处、车库、入口和到达路线继续使用。
- 历史胜场、参赛次数和路线进度保留。新版个人最佳从新版赛道重新计时，原圈速不参与新版成绩比较。周一大赛与三日小赛继续各按原赛程办理，练习时长与正式比赛圈数分开。

## 设计原型与后续

「自定义目的地」已完成[可交互原型](previews/destination-picker.html)。下载 HTML 后可直接用浏览器打开。原型在同一行提供搜索、类型和街区下拉。左侧显示最近地点和筛选结果，右侧显示地点、营业时间及出行时间，可分别选择立即前往或保存到底栏。原型使用示例地点与时间，Unity 中仍沿用现有目的地选择器，等方案确认后再实现。

展会报名、MCN 招募代言人和车辆改装的既有功能继续可用，第 118 篇记录的三项布局改版仍待落地。

## 验证与构建

- 使用 Unity 2022.3.6f1，主场景为 `Assets/Scenes/Main.unity`。最后一次 Windows x64 全量构建成功，本机可运行 `Builds/FishingAppointment/PCShopSell.exe`，其中已包含赛车登记和扩建后的赛道。Windows 包、临时日志及私人存档继续保存在本机。
- GitHub 归档前重新运行 **49/49** 项 EditMode 专项检查，覆盖快捷键、手机窗口、采购与货车、二手店、还款导航和计息、证券、主线门槛、行人、现场预约及赛车。
- 垂钓、户外事件、现场玩法及确认预约联合 EditMode 测试 **125/125 通过**，其中包含周国良预约两种付款方式、同场直接进入手动钓鱼、扣款防重复及普通场地购买。
- 赛车及道路联合 EditMode 测试 **55/60 通过**。赛道尺寸、各车型完赛、赛道模型及旧成绩处理共 18 项通过，并核对了全城实景。5 项失败在修改赛道前已有记录，涉及赛车陪诊、验收档车辆数量、二手车、对手名次断言。其他扩展测试仍观察到住户路线、人物数据、餐馆开局奖励和旧主线邀请用例失败。这些结果的范围为上述专项和扩展组合。
