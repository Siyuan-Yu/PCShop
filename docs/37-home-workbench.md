# 居家工作台与生活托管（2026-11-02）

本轮实现大屏商品、真实操作的四页工作台、经营报表与品类行情、生活托管及存档。按用户最新范围，住宅扩容、搬家改造、实体安装启用及靠近大屏按F交互暂不做。后续已包含于 `Windows-Optimized-20261102-223752`，当前完整归档见 [第40篇](40-current-snapshot-2026-11-02.md)。

## 购买与入口

- 家具城电器分类新增“家庭经营大屏”（`home_workbench`），目录价¥28,000，重量160千克，使用现有购物车、货运和网购流程，原有运费及网购价格规则照常。
- 商品登记占地6.4×2.4米，为后续安装玩法保留数据。本轮只检查“已拥有”，不要求摆出、不检查住宅档次，也不新增住宅升级门槛。
- 送达家中后仓、临时存放、随身家具或原有家具库存即计入家庭持有；仅有在途订单不解锁，仅在别的店铺存放不计家中持有。
- 在家且持有设备时，可点右上“居家工作台”，也可从“我的”中进入。离家、失去设备或进入不兼容的工作/活动状态后关闭入口。原有手机不被删除或升级。
- 编辑器作弊栏新增“打开大屏（免购买接入）/关闭大屏（取消作弊接入）”。在家开启会直接打开工作台；在外开启后回家可用。关闭同时收起工作台并取消作弊权限，不扣钱、不生成或删除实体大屏。已购买的正常权限保留。打包版本不显示按钮，存档中的调试标记也不会解锁权限。

## 四个页面

### 总览：玩家本人

- 健康、精力、饱腹、心情、营养、住处、载具及最近24小时睡眠。
- 现金、净资产、债务及昨日/近7日/本月的日常收支；投资、融资、内部转账单列排除，不把借款当收入。第一天无“昨日”记录时显示零。
- 真实待选事件、生活托管异常、待回复城市活动邀请与近期预约，可进入原有事件、联系人和日程处理。首页不生成固定的采购确认/排班任务。
- 可进入账本、物业资产、债务还款、背包与家中物品。

### 经营：生意管理

- 报表沿用真实账本的门店归属，按今日/近7日/本月统计销售、经营支出与现金净额。现金净额不作为利润。
- 品类进货行情来自真实价格，已经营品类优先，其次服装/模型/电脑关注项；日历史最多保留31个日期，每30游戏分钟刷新当日样本。不足两日不编造涨跌；不足七日按已记录跨度标注。展示数值、趋势和详细历史。
- 独立选择目标店铺，直接修改整点营业时间、全局加价，以及实际已陈列商品的逐件售价。预览购买意愿后确认才生效。只在后仓的商品不进入调价列表；库存可查看，搬运仍需本人到场。
- 人员采购连接原有员工岗位/排班/培训、统一采购责任、各店进货员、采购清单、在途与收据记录，不移动人物，也不把所选分店写成当前店铺。
- 订单合作连接已解锁的直供、企业合同、推广合作；各店装机订单可查看配件、状态、期限并切换员工自动装机。手工装机仍需到店。
- 经营资产连接物业、租约、车辆占用及已解锁园区；专用场馆连接原有服务价格、营业时间和值守管理。原有签约/清店/到场条件继续校验。

### 投资

- 进入现有指数与虚构企业行情、持仓和交易确认页，使用相同的价格、手续费、资金预留确认、实际扣款和持仓变更；不增加另一套证券账户。
- 在家大屏可作为联网投资入口，无智能手机时也能使用；离家后仍沿用原手机条件，不永久赠送手机能力。

### 联系人

- 已交换联系方式的真实NPC、原有聊天、通讯录、邀约、城市日程与员工联系。
- 大屏在家提供聊天连接，但仍检查真实联系方式与NPC存在性，不能联系未认识的陌生人。见面、送礼等到场条件保留。

## 生活托管

- 默认未配置，不因买到设备而覆盖原有外卖/自动吃饭行为；保存托管设置后才接管在家用餐。
- 自动吃饭：优先已有熟饭、已摆冰箱内的饭食、开启取用且有纸箱时的家中后仓饭食、背包饭盒，实际扣除对应批次并应用原营养/心情/饱腹效果。
- 自动点饭：饭食不足或关闭已有饭食优先时，按所选餐档下单；实际扣款、按日预算限额，不自动降档、不透支。日支出与最后用餐时间保存，读档不重置预算、不重复吃饭。
- 自动睡觉：可选择整点入睡和起床，需要家里有床；沿用真实睡眠与时钟推进，经营、工资等系统照常结算。待选事件及不兼容活动不强行睡过去，处理完事件后在设定休息时段内继续执行。
- 自动换衣：需要衣柜，从已拥有的衣服中按实际温度推荐与装备，不凭空购买衣物。
- 自动取用：开启后可使用后仓饭食，并于每日16:00从家中纸箱后仓取用一次选定的水果、点心或可乐，实际消耗并应用相同属性效果。耐用品不按日消耗。
- 缺饭食、缺床/衣柜/纸箱、消耗品不足、预算或现金不足会提醒；相同未解决原因只提醒一次。条件恢复后可再次提醒新的短缺，通知状态、每日执行记录和设置均保存。
