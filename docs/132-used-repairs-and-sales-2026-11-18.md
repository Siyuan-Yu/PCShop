# 二手修复台、修复师与销售推介（2026-11-18）

## 已实施内容

- 家具城增加二手店专用的 **二手修复台**：¥1,200、35千克、占地1.3×0.75米，可按现有购物、叫车、摆放流程购置。属于可选经营设备，不增加开店必备条件。
- 新增 **修复师** 岗位，仅能安排到二手旧物店。沿用招聘、调岗、上下班、工资、员工名额和存档流程；枚举编号追加，不改变原岗位编号。
- 每台修复台配一位在岗修复师同时处理一件，实际并行数取修复台和在岗修复师人数的较小值。修复师在店内修复台旁显示，工作物品在台面展示；靠近按 F 打开修复入口。
- 收购鉴定台的待上架页增加修复入口与状态，柜台显示处理中件数。修复中的物品不能上架或丢弃。

小店仍最多4名员工，可选择“收银＋收购师＋修复师＋销售”；不额外赠送员工名额。上一轮“收银＋收购师＋两销售”的收益估算不能直接用来代表此配置。

## 修复规则

- 对象：已收购、已鉴定、尚未出售的普通瑕疵品或损坏品。已上架的先取回，顾客正在结账的不能操作。
- 文物、仿造品和好货不参加修复；不会把仿品修成真品。
- 每件只允许一次尝试。成功恢复为好货，失败保持原状态；耗材不退。
- 瑕疵品耗材为好货参考价的8%，损坏品为15%，向上取整至元。支付时进入门店进货支出，并计入该件总成本，避免出售毛利漏掉修复费用。
- 瑕疵品需90单位工作量，损坏品150单位。每个营业分钟的工作速度为 `0.5 + (动手×0.6 + 智力×0.4) / 100`。
- 成功率为 `0.5 + (动手×0.4 + 智力×0.6) ×0.004`，能力均限制在0～100。两项都是50时，工作速度1倍、成功率70%，对应纯修复时间约90／150分钟。
- 换人接手时按实际完成工作量累计成功率；休息、离岗、关门、修复台收起时暂停，不会持续扣钱或凭空推进。进度、已付耗材和尝试结果随物品保存。
- 在岗修复师配合修复台，会自动处理未上架且可修复的物品；现金不足时不会自动扣款。手动也可在待上架页安排。完成后尝试按新参考价上架，若无货架空间则留在待上架页。

## 销售推介

销售在岗时，顾客优先看到高价及久置旧物：标价≥¥1,000的物品增加推荐权重，待售时间也增加权重，时间加成最多按2天计算。仍按原有购买意愿和支付条件成交，绝不直接变现。

该权重使用原有全店销售加成，销售购买意愿加成上限仍是25个百分点；不为二手店额外叠加无限销售收益。
