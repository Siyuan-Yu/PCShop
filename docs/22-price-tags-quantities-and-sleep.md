# 价签加减、购物数量、自动到岗与自选起床时间

更新日期：2026-11-01。以本文覆盖历史文档里的数字输入、7小时睡眠和固定起床时间说明。本轮按要求不生成截图。

## 商品调价

- 配件货架上的每个有货型号，直接在其价签显示“− ¥售价 +”，不再在整座货架下方统一调价，也不需要键盘输入。
- 单击调整1元；按住超过0.4秒连续调整，之后逐渐加速，松手提交。达到上下限停住并禁用对应按钮。
- 同一价签显示当前售价对应的顾客购买意愿；提交后刷新。杂货货架也采用同样控件。
- “跟随”恢复该型号跟随全店定价。同型号盒装和散件仍按原有包装溢价联动，界面明确提示；不同型号独立。
- 保留原有0.9–1.6倍售价范围和购买概率规则，只改变交互方式。存档继续使用原有按型号加价记录。

## 所有购物数量统一加减

- 档口配件、家具、礼品、米菜肉、员工采购清单、1788批发和个人网购数量均使用“− 数量 +”。
- 数量按钮支持长按加速和边界限制；长按期间预览数量，松手一次应用，不会被随后的点击事件重复计入。
- 大米每档0.25千克；食材按原包装份量增减并显示千克。其他商品每档1件。背包优先、超重叫车的规则保持。
- 个人网购可选多件后下单；不可重复拥有的服装等仍保留其单件购买逻辑。
- 搬货保留长按批量装车、移入背包和拖拽操作，删除额外的“数量”弹窗。
- 自动补货的常备数量、保留天数、现金底线和日预算也改为可长按的加减按钮；金额每档100元，天数每档1天，日预算0显示“不限”。
- 搜索框保留文字输入；当前玩法页面已没有数字输入框调用。

## 打工签约与自动开始

- 签约当天明确显示“明天再来工作”，去掉“到岗，开始今天的工作”按钮。
- 次日起按合同排班进入签约门店自动上班；开工前1小时可进店等候。迟到、缺勤、周结、白班和夜班规则延续。
- 工作时操作锁和倍速选项保留，收工后自动恢复操作。

## 睡眠

- 床/地铺界面用“−30分钟 / HH:mm / +30分钟”选起床时间，显示今天或明天及预计睡眠时长，再点“睡到选定时间”。相同时间不允许开始。
- 增加“睡满8小时”快捷操作，保留“小睡2小时”。睡满8小时是睡眠时长，不是固定睡到早上8点。
- 按过去24小时累计睡眠，分次小睡也计入目标；睡够8小时消除欠觉并恢复满精力。不足时欠觉为8小时减实际睡眠时长，继续降低精力上限；床铺质量仍影响短睡恢复速度。
- 自愿睡眠区间持久化到存档，读档后仍累计；旧存档没有区间时保留原欠觉值，从新增睡眠开始累计。
- 原来凌晨4点仍醒着会晕倒的规则保留；睡眠中跨过4点不受罚。夜班工作、白天补觉和必须在到岗前醒来的例外保留。
- 原有内部Sleep接口仍保留固定8点/夜班补觉语义供历史流程使用；玩家床铺界面使用新的自选时间与8小时接口。
