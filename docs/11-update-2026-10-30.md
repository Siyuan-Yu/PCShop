## 2. 单店经营、生活与可靠性

- **订单与手装机**：可预留配件，避免零售卖掉；取消或过期归还散件。缺件清单可加入采购购物车，已有购物车数量保留，供应商切换重新报价。先检查交期，再推进实际装机耗时，最后结算；防止重复扣料、提前收钱和员工/老板重复交付同一订单。关闭小游戏保留累计失误。
- **员工**：老板在店时也照常收银；收银员可培训兼做装机，也可另雇专职装机员。分别排班、积累装机经验并保存工作进度，缩短班次不降低日薪。兼岗优先处理排队顾客，双岗可并行工作。
- **补货**：新增现金底线、房租/工资预留天数和每日预算；预算有限时按缺货程度购买可负担的部分。线上、面包车及直供共用在途数量和仓位预算，补计到期账款、月供、养护等资金需求。
- **行情**：市场先排定未来品类冲击，打听消息读取已存在的安排，不再由询问动作创造涨跌；显示持货、在途及指标敏感度。实际价格仍受多项因素叠加，消息不保证盈利。
- **资产与报表**：库存估值补计家中、展示机、顾客手持、订单预留和在途配件；单列退押金等非营业收款。现金变化、资产估值和利润概念分开；完整逐批成本核算仍待做。
- **经营便捷性**：知名度 8 且拥有收款码时，可花 ¥4,500 购买自助结账，一年目标仍可赠送；装修支持最多 30 步撤销/重做，同步恢复家具、展示机和库存，退出后清空本次历史。
- **生活与提示**：智能手机可选择无饭时自动送餐，默认关闭、优先吃自带饭；修理过程中可等到完成。相同短时通知合并，本次会话最近 150 条通知可回看；这与不提供教学回看是两件事。
- **界面**：弹窗内容可滚动并适应画面尺寸，店内页签/离店按钮与正文分开裁切，列表重建保留滚动位置；通知不盖过模态窗口，暂停与查看状态区分。
- **存档**：手动 `save1.json` 和自动 `autosave.json` 分离；临时文件写完再原子替换，保留 `.bak`，坏档回退备用档。新增经营、关系、员工、教学状态支持保存和旧档迁移；测试存档隔离，避免写入玩家正常存档。

| 系统 | 已实现范围 |

| 分店 | 电脑分店、社区网吧、电竞馆、简餐店、花店、民宿、二手车行七类委托经营；独立周转金、定价、维护、人员、停业成本、日结与清算。网吧/电竞馆实际调拨主店硬件。 |
| 园区 | 买下大型空铺及公共区改造，七天后开放 2×3 铺位；入驻、清退、搬迁/互换，相邻不同业态导流。 |
| 创作者/MCN | 三位原创创作者，粉丝、商务交情、抱负与资源；七日推广、赞助、提前退出、MCN 成立、90 日合约、分成、日薪和解约。推广营业额包含自然客流，不等于新增利润。 |
| 私人关系 | 商务关系与私人好感独立；见面消耗金钱和两小时，三人九段心事、分支记忆、交往、疏远和分开，不自动更改商务合约。 |
| 汽车与住处 | 合法小货车、轿车、载货/形象效果、日养护与回售；单间/公寓升级、住宅租购/按揭/出售，保留家具，调整室内外观与恢复效果。 |
| 物业与投资 | 主店物业及闲置商业物业的产权、按揭、维护、提前还贷、出售和托管租金；硬件景气指数持仓、买卖费用、债务和资产分列。 |

## 4. 美术与空间交互

- 采用暖色微缩街区/复古电脑店方向：奶油、烟灰绿、木色、黄铜与深墨绿；程序化倒角家具、条纹遮阳棚、实际店名、树冠和停放车辆，降低过强霓虹与后期效果。既有立绘保留，未引入参考游戏素材。
- 2D 界面统一圆角卡片、细边框、标题层级及状态色；装机配件加入图形细节。人物采用程序关节动作，换装随袖子和裤腿运动。
- 中介鸟瞰使用实际街区，支持滚轮/按钮缩放、拖动、全街总览和放大选房。挂牌建筑有名称、价格、面积、客流及等待时间，标签避让、连线与选中线框；右侧户型按真实室内尺寸绘制。夜间看房采光、关闭资源释放和主镜头隔离均有检查。
- 装修轮廓使用独立网格及 URP Shader，遮罩排除家具本体；本来的柜面、层板、饰件和配色正常显示。新放、拿起、旋转、改选、放下和退出均同步；墙面与圆形家具适用。不会改写家具共用材质，临时网格/材质随预览销毁。
