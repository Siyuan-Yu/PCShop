# PETSHOP 当前玩法与主分支交接（2026-11-19）

> 后续的多店经营与采购改版、最新 Windows 包基线和完整系统索引已汇总至[当前完整交接](145-current-game-and-store-management-2026-11-19.md)。

当前工程为 **PCShopSell**，开发分支为 `main`，使用 Unity **2022.3.6f1**。本文汇总现有玩法、本轮实际接入的规则、旧存档行为与本地构建边界。各系统的操作细节、事件清单和历史验证见[完整玩法索引](124-current-game-content-2026-11-17.md)和[11 月 18 日交接](133-current-project-handoff-2026-11-18.md)，同一功能以本文及[模型改胶与事件 CG 本轮交接](144-model-commissions-and-event-cg-handoff-2026-11-19.md)的更新为准。

## 城市、操作与主线

- 完整版在湖城生活和经营。玩家从城郊出租屋开始，做饭、租店、装修、采购、销售和招聘，逐步解锁社区、公园和花园。商铺、住宅、工作、预约和到场活动共用城市时钟与实际路网。自定义目的地支持搜索、按区域与类型筛选和保存快捷位；在室内出发会先绕开家具走向出口。[主线与片区](story-and-district-progression.md) · [自定义目的地](120-custom-destination-picker.md)
- WASD 移动，`F` 与设施、货架、人物和入口交互。底栏选择通勤方式、目的地和叫货车。顶栏状态与功能分行，功能栏可用 `Tab` 折叠。常用入口包括「我的」「背包」「手机」「任务」「日程」「经营」「物价」「股市」「品牌」「赛车」，部分入口随进度开放。
- 开局做饭和找中介沿用分步引导。焖饭期间按游戏时间自然完成，煮好后继续吃饭、打包。经营教学推进到买智能手机、开通收款码、买小电驴、了解股市和开第二家店。已有第二家店或已解锁赛车的旧进度沿用已有的证券课完成条件。
- 首次购买的小电驴可以用于通勤时，暂停世界时钟和移动，压暗界面并高亮底栏「小电驴」。点击切换出行方式后完成这一步。首辆车先停入车库时，等车辆可作通勤车并满足切换条件后再触发。
- 轮到证券教学时，暂停世界时钟和移动并高亮顶栏「股市」。功能栏原先折叠时会为这一步展开。打开证券后阅读说明，点「已了解，继续开店」完成教学，买卖股票可自行决定。银行柜台仍提供「证券交易」入口，可从该入口完成同一教学。

## 门店、采购与员工

| 经营入口 | 主要内容 |
| --- | --- |
| 电脑店 | 盒装与散件、兼容装机、展示台、个人委托、企业合同及自动装机。 |
| 宠物用品店 | 用品零售、猫狗代养、照料耗材、主人定期结算及饲养员。 |
| 服装店 | 按档次采购，季节、温度、试衣镜、销售员及顾客预算参与经营。 |
| 模型手办店 | 四个原创系列，常规款从批发渠道采购，限定款可在漫展现场采购。系列行情、陈列、采购和品牌展品共用实际商品库存。 |
| 二手旧物店 | 卖家排队、报价、收购、鉴定、修复、陈列与实际销售。修复师按动手能力和智力决定工作效果。 |
| 餐馆 | 堂食按桌位流转，厨师从冰箱取材，服务员上菜、桌边收款、收桌；已上架饮料可以加购。预订鱼餐按交期备料和交付。 |

- 区域开放后还可经营场馆和二手车业务。通用柜台显示客流、成交、流失、知名度、口碑及排队。员工采购可按清单或库存下限执行，使用真实货源、门店、车辆、容量及送货地点。线下采购、手机网购、叫车与物流各有入口。[员工和采购](13-employees-and-procurement.md) · [二手修复与销售](132-used-repairs-and-sales-2026-11-18.md)
- 「聘用与工作安排」和已聘人员的「安排工作」页在头像旁显示智力、魅力、动手能力、体能。切换岗位时显示相关属性及这名员工的实际效果，比如装机每台需要几分钟、进货货价优惠多少、服务员的小费概率。装机经验以实际完成台数显示。门店列表使用分栏，数量溢出时可滚动。
- 调价页、货架调价和居家工作台使用同一购买估算。手办和服装的估算计入顾客预算，实际挑货也使用同一套预算档位，成交判断采用商品实际售价。单品百分比估算的是考虑该商品的顾客中，愿意并买得起的比例。门店总览按陈列件数加权；排队、付款方式、季节、偏好和是否有现货仍会影响实际成交。
- 普通手办顾客有 **¥80、¥150、¥300、¥600** 四个基础预算档，预算随该系列行情修正。以基准价 **¥518** 的远航旗舰、四季庭院等常规高价款为例，统一加价 **1.25 倍**时，售价已高于普通手办顾客的最高档预算。销售员和口碑加成仍参与定价意愿，顾客因买不起离开时会显示「超出预算了」，单笔流失原因也区分预算与嫌贵。

## 货架、模型行情与经济简报

- 打开货架即可在手办商品卡的重量旁看到较昨日的行情。涨跌用箭头和百分比表示，持平显示「行情持平」，缺少昨日基准显示「—」。后仓有货但还没上架的商品卡也显示。普通商品和电脑配件货架同样显示趋势，配件沿用品类口径。
- 晨湾航行、雨巷守望、苔园来客、星灯工坊各有行情，同系列的常规款和限定款共用涨跌幅，各款保留自己的基础价格。模型在「物价 → 价格走势 → 模型行情」有独立筛选，也进入「今日变化」和经济简报「物价变化」。选择系列可看指数、走势、相关消息和对应款式，可跳到该系列的商品目录，查看当前零售参考价。
- 物价异动弹窗的模型系列可以直接点开。若提醒日期早于当前游戏日期且有历史快照，先显示异动当天，并提供「查看今日」入口。昨日及七日前使用对应日期，历史缺失时显示「—」。模型指数使用和异动提醒相同的行情数据，按游戏日和存档中的市场种子生成。
- 经济简报显示现金变化、实际收入和支出，可选日查看流水、查看门店明细和总账分类。自动提示支持每周、每两周、每月或关闭。现金差额包含投资、融资等现金变动，经营利润使用各自的成本与收入记录。[经济简报与物价界面](134-economic-and-price-dashboards-2026-11-18.md)

## 住宅、衣柜与日常生活

- 住宅租约的周租统一在周日扣款，多套住宅同日汇总。签约仍预付首周，首周结束后的首个周日才续扣。旧存档中已按旧日程缴过的租金覆盖完整七天，期间遇到周日会跳过，之后统一到周日。住宅合同、「我的」、中介和现金预留预测使用同一日程。商铺租金及持有出租物业的租金收入沿用各自规则。
- 在家靠近衣柜按 `F`，左侧显示角色和适温，右侧列出已有衣服。点衣服即试穿，点「换上」才更衣；「取消试穿」恢复当前穿着。默认展示全部，可按春、夏、秋、冬筛选。跨季衣服在对应季节都可找到，只有一套时收起筛选。适温决定天气提示，魅力加成为零时省略。
- 服装店柜台付款后衣服直接进入个人衣柜，可在营业中的服装店试衣镜旁换上。独立双栏服装店试衣原型提出先试穿、付款入柜、按需当场换上，当前接入的是家中衣柜版本。精简版商铺签约成功回执也处于设计阶段。
- 住房支持租买、搬入自有住宅、储物和家用工作台。睡眠、饱腹、健康、精力、体能、营养、天气及衣着参与模拟。可做饭、装饭盒、冷藏、点外卖和设置自动订餐。单门冰箱 **500 千克**，双门冰箱不限容量。中型及以上住宅安装办公台后，可查看门店、资产、投资及联系人。[居家工作台](37-home-workbench.md) · [饮食与冷藏](17-food-fridge-and-diet.md)

## 手机、银行与证券

- 智能手机自带「证券」，顶栏「股市」直接打开同一个手机应用。没有智能手机时按钮置灰，买到手机后可用。已拥有智能手机的旧存档读入时补齐预装应用，网购等其他可下载应用继续从应用商店安装。
- 银行柜台按当班柜员实际到岗办理存取款、借款和还款，白班 **08:00–20:00**，夜班 **20:00–次日 08:00**。手机周转借款与柜台使用相同额度规则，借款、还款与提醒接到账本和日程。
- 手机、银行和居家工作台共用证券行情与持仓。现货最少 **1 股**，增减档位为 **1、5、25、100、200、500 股**。保留走势、自选、新闻、统一成交、手续费、做空保证金与强平规则。自有品牌上市仍为后续功能。[证券操作与账务](90-stock-market-and-short-selling.md)

## 人物、活动、品牌与美术

- 固定 NPC 有住处、班次、兴趣、关系和独立故事。人物资料、对话、通讯录、关系图、邀约、店员、直播与活动使用同一个人物身份。日历记录约会、送货与到期事项；现场校验可达性、地点与集合时间，再按参与和结果结算。
- 垂钓、篮球、高尔夫、品尝、调饮、散步和摄影有各自的现场操作及结算。其他剧情涵盖邻里往来、亲友借款、读书、夜校、医疗、花灯会、漏水维修和商店事件。现有事件插图已重画为[暖色微缩 3D](137-event-cg-refresh-2026-11-19.md)，沿用游戏现有的人物图。完整事件、编号和插图进度见[事件索引](98-random-event-index.md)、[事件明细](100-random-event-details.md)和[现场玩法](115-onsite-events-51-58-and-76.md)。
- 品牌可绑定门店，参与代言、直播、季度展会和企业竞标。展会使用真实摊位、展品和库存，展后订单及企业合同需要实际履约。赛车按片区开放登记、车库、练习与正式赛事，通勤用途和入库参赛车辆分别管理。[品牌与展会](54-brand-expo-tender-playable.md) · [区域车库](85-regional-garages-and-parking-spaces.md)
- 主菜单用全屏封面，人物采用 B 版微缩造型，湖城、室内与 uGUI 使用暖色风格。首次进入或读档时按阶段显示加载遮罩，城市固定地图通过预生成缓存加载，保留回退路径。[美术与启动](125-art-ui-and-webgl-startup-2026-11-17.md) · [地图预生成与加载](地图预生成与加载.md)
- 模型店已接入[改胶与喷漆委托](128-model-painting-plan.md)。摆放喷漆台后可接到自带模型的顾客委托。家具城现价为喷漆台 ¥900、二手修复台 ¥600。玩家可手操三道工序，也可安排喷漆师加工，按品质交付和结算。
