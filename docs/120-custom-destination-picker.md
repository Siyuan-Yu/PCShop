# 自定义目的地

底栏「选择目的地」和自定义快捷位右侧的小三角都进入新版选择器。「城市生活 → 城市地图」仍可单独查看道路、收藏和赴约地点。界面以已确认的[交互原型](previews/destination-picker.html)为准。

## 地点怎么找

- 顶部同一行提供关键字、类型和街区。多个关键字用空格分隔，地点必须符合每个关键字和两个下拉筛选。搜索可匹配地点名、店名、店型、街区及常用用途，例如「城郊 还款」和「家具 货架」。
- 类型包含我的店、采购货源、住处、娱乐活动、已购物业和公共服务。同一地点符合多个类型时，可从对应的各个筛选找到。档口共用同一个市场入口，只有玩家当前已开放片区的地点进入列表。
- 默认按最近前往和其他地点分组，最近前往按时间倒序。其他地点优先显示街区场所和玩家住处，其余住宅随后列出。应用筛选后显示匹配数量，只有一项时自动选中。没有结果时可一键清空三个筛选条件。搜索框、类型和街区控件留在顶部，滚动区域只在左侧结果列表。

## 选中后怎么走

右栏显示地点名、街区和当前开放状态。有固定营业时间的场所显示实际时段，住宅显示当前能否回家或拜访。出行预览以玩家当前交通方式和地点门口的实际路线计算，打车时同时显示车费。路线不可达、道路封锁、当前无法出发或车费不足时，在详情给出原因。打烊的场所仍可走到门口，抵达时按开放规则进入。

| 按钮 | 结果 |
| --- | --- |
| 立即前往 | 从所选地点的详情发起游戏内导航，原底栏快捷位继续指向之前保存的地点。 |
| 保存到底栏 | 更新自定义快捷位。窗口留在原处显示「已保存到底栏」，玩家仍留在当前位置。 |
| 底栏主按钮 | 已保存地点时直接前往该处，尚未保存时打开选择器。 |

点列表行只更新详情。关闭窗口后保留最后一次明确保存的地点，读档继续使用相同的快捷位。地点、报价、选中状态和最近前往均使用游戏数据，原型保留为布局参照。

## 验证

- Unity 2022.3.6f1 的选择器专项 EditMode 测试 **3/3 通过**，覆盖组合筛选、空结果、保存读档、最近地点、直接出发及实际打车扣款。
- 扩展检查包含步行、银行和道路，结果为 **44/47 通过**。另用修改前的 `e1292f4` 对照复跑，贴墙斜走速度和手动／自动步行距离的三项断言同样失败。
- 使用 Unity 渲染了 1600 × 900 的选择器画面，核对顶部筛选、双栏和底部操作的位置。Windows x64 构建保存在本机 `Builds/DestinationPicker`，运行该目录内的 `PCShopSell.exe`。

## 工程入口

- `GameUi.CustomDestination.cs` 构建选择器、筛选和详情。
- `GameUi.CityNavigation.cs` 负责底栏快捷按钮及文字刷新。
- `GameSession.Travel.cs` 使用实际路线预览耗时、车费和道路限制。
- `CustomDestinationTests.cs` 覆盖选择、独立保存与出发、存档、组合筛选和空结果恢复。
