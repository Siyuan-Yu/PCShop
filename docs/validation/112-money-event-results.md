## 本批定向检查

`MoneyEventBatchTests`共20项，均已通过。覆盖：

- 随机目录120项，删除的三项不存在，111、124等后续验收编号不移位。
- 水电／租金必须有实际多付款才允许退款；只退实际差额，一次结清，存读档不重复。
- 正确扣款不能产生退款。水电抵扣按后续账单真实扣减，不足以用完时保留余额；同账单重放不二次消耗抵扣。
- 租金抵扣影响真实周租扣款与现金储备预测。旧租约结束，余额返还一次，不移给新租约。
- 彩票购入扣¥200，不刮不能领奖；手动刮开网格，至少87/144格后可兑奖；奖额、进度与兑付跨存档保留，不重抽、不重复兑付。
- ¥3,000年度投保，360天有效；提前续保从原到期日接续，过期停保，断保后从续费时重新起算。
- 对单次¥100,000、¥200,000、¥300,000真实住院账单分别报销80%，验证没有单次或累计上限；每笔不可重复理赔，门诊不赔。
- 实际`Hospitalize`住院流程按入院资格报销，住院跨过到期日仍享本次保障。
- 理财智力49／50／70／100／150的成功率分别为0／30%／50%／80%／80%。低智力选项仍可选，投入扣真实本金且到期才确认损失。
- 到期成功／失败两个存档分支，成功只回总额¥20,000，失败不返款；提前不结算，存读档不重抽或重复付款。
- 闲置出售要求真实随身物品、正确数量和到旧物市场，交货后入账；不会移走已摆放家具或修改玩家自营二手店。

## 实际图形与操作

入口`GameSceneBuilder.MoneyBatchFromBatch`使用生产GameController与UI。实际操作：买彩票、通过PointerEventData拖拽银色涂层、点击兑奖按钮；年度投保和真实扣款投资；调用实际住院流程报销¥160/¥200；在旧物市场通过出售按钮移出一件真实背包家具并收到对应回收价。家具来自编辑器验收预置，不是游戏凭空赠品。

图形复跑已报告`SMOKE RESULT code=0 errors=0`。首轮发现刮层缺CanvasRenderer，补上组件要求后复跑通过。人工检查了刮开进度、奖额遮挡、年度到期日和理财期限；最终界面移除了“有投资待到期却显示无待办”的矛盾提示。
