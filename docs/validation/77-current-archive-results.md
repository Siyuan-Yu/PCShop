## 本版操作入口

1. 品牌 → 代言人（KOL）→ 代言人市场：选择公司、实际前往社区联合接待处，营业时间内找对应公司人事，办理介绍或出示合约，确认后管理排班。
2. 手机 → 街坊直播：观看实际主播和商品；品牌现货不足时不显示虚构库存。品牌 → 代言人（KOL）→ 专场记录查看结算。
3. 品牌 → 展会：报名时选择统一合约中的代言人、准备实际展品，按期前往会展中心。屏幕只展示已邀请且到场的主播，展柜使用报名商品图。
4. 道路沿实际地图加载即可看到共用车道、人行道和入口衔接。既有道路前后实景对照随第74篇归档；本轮未新增截图。
