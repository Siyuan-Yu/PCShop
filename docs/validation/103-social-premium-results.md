## 新增检查覆盖

- 所有普通活动的消费服务数量均翻倍；KTV、酒吧各四项，街坊餐厅正餐与夜宵共八项；原有价格、互动选项编号保持。
- 高档 KTV 的真实价格、时长、类型和服务 ID，实际扣款与恢复后不重复收费；包间两人分摊 ¥900 或一人请客合计 ¥1,800。
- 43–50 八种邀请的到场前未认识、未扣费用、实际工作地点／住处、存读档、到场认识、完成结算、已认识后仍可邀约。
- ¥3,000 整桌庆功宴只扣一次，实际比赛胜利与参与人记录可生成邀约，取消重约后也不能重复使用同一胜利。
- 林荷 AA ¥1,000／请客 ¥2,000，拒绝不扣交情；家宴 ¥1,000 伴手礼实际进背包、保存、赠送，取消不吞礼物，缺礼物会暂缓带礼预约。
- 试听报酬 ¥1,500 完成后一次到账，低智力仍能选检查但必定未发现专业问题，高智力发现奖励最多一份；中途离开不支付报酬。
- 杜建川的炖菜故事在完成后解锁，提前离开不授予；合唱团实际参与人到场认识。
- ¥1,000 湿地训练的实际抓地与制动、退赛／完训、车损、无现金奖金、独立记录与预约存档。
- 41–50 批量验收的准备与编号保持；123 个随机事件、51 项 C# 注册和标准 JSON 格式校验通过。

测试中发现并修复了 JsonUtility 将空礼物字段恢复为空字符串后误触发「缺伴手礼」的问题。没有礼物约定的旧活动与新活动都可以正常恢复。赛车旧后续状态的空字符串也在读档边界归一化，避免误提示夜宵或求助。
