## 编辑器复核入口

1. 通过“作弊 → 社区资格与品牌展会验收”创建双品牌或三品牌档，再从顶部“品牌”展开创建。分别创立各行业品牌，检查门店账目和改名确认页。
2. 在“推广与代言”先选品牌，检查品牌级按钮、实际到店客流和合作列表。点新增合作再选候选人或 MCN。
3. 用 KOL 独立档设置一场品牌直播，打开手机的“街坊直播”，在下播时查看品牌名、知名度和口碑的变化。竞争品牌专场使用相同结算版式。
4. 给参展品牌签一位有效代言人，按季度流程准备并到达会展中心。开幕日可在人员页看头像，在现场聚焦对应人物，并在下午的舞台环节选择品牌介绍方式。
5. 持有多处可入住住宅时，在底栏切换地址，确认快捷按钮变为该住宅名。点击按钮，沿路线到卧室打开睡眠面板。

这次检查是所选 EditMode 用例的联合结果，覆盖代言人正常到场路径。整库全量回归、代言人迟到或缺席场景、性能重测和 Windows 重新打包均不在本次验证范围。上版完整归档的检查记录见[第71篇验证](71-current-archive-results.md)。
