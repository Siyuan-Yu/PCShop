# 钓鱼交互第二版验收

2026-11-13，Unity 2022.3.6f1，独立 `F:/_ci` 工程镜像和验收存档。

## 本轮变化

将文字提竿选项与随机成功结算替换为连续操作：按住蓄力、松开甩竿，力度决定 4–30 米落点；选饵影响鱼池与等待；3 秒提竿窗口；按住／松开控制绿区跟鱼，收鱼进度与鱼线张力共同决定结果。三种鱼挣扎速度不同。保留真实背包、做饭、赠送、放生、回收、59／60 真实邀约。

## 验证

- 钓鱼 EditMode：19／19 通过，见 `105-fishing-v2-tests.xml`。
- 钓鱼、人物邀约、城市活动及事件配置联合检查：59 项，58 通过、1 项已知旧失败，见 `105-fishing-v2-integration.xml`；钓鱼 19／19、人物邀约 25／25、事件配置 1／1、城市活动 13／14。旧失败为 `CityActivityTests.AllAuthoredWorkersRespectClosedVenuesOnInitializationAndDailyTicks`（赛车 NPC 在闭店场所工作），同名问题已有基线记录；不是钓鱼断言失败。
- Unity Direct3D 11 实际图形运行，使用生产 `GameController.Step`、uGUI 指针按下／松开、实际蓄力和等待、按鱼位置动态收放线，没有写鱼获或强制中奖。
- 实际支付 ¥300，抛竿 1 次，钓获鲤鱼 1 条，收入背包 1 条；截图与计数见 `../previews/fishing/`。
- 空格在钓鱼窗口内用于钓鱼；世界速度不改变蓄力和遛鱼速度。关闭窗口释放自己的暂停，遛鱼中关闭会脱钩；存读档保留鱼运动、控制区速度、进度和张力，不重抽结果。

当前为代码绘制的钓鱼交互原型，鱼竿、飞线、浮漂和控鱼界面都有运行状态驱动的动画；尚未制作正式钓鱼美术、音效，也未重打 Windows／WebGL 包。51–58 尚未借本轮钓鱼开发完成。

## 全屏池塘呈现调整

按用户反馈，后续将中央弹窗替换为独立池塘画面，满屏显示池塘、树木、芦苇、钓台、玩家及运行状态驱动的鱼竿／浮漂；操作放在底部，控鱼条放在右侧，支持直接在池塘按住／松开操作。原有核心钓鱼规则不变。

实际运行入口仍为 `FishingFromBatch`，指针事件作用于池塘本身；图形运行 `SMOKE RESULT code=0 errors=0`，实际支付 ¥300、抛竿一次、钓到鲤鱼一条并收入背包。已人工检查选饵和遛鱼两张 1920×1080 的实际渲染图，无弹窗边框或原有城市 HUD 透出。记录为 `105-fishing-pond-graphics.log`，截图在同一预览目录更新。

## 操作精简

后续精简为直接点钓台选位置、底部点鱼饵、单个随阶段变化的操作键。补饵只显示所选鱼饵，准备时隐藏力度条，张力过高时提示松手，底栏从 228 缩至 164 设计像素，统一为顶部「结束钓鱼」结束服务。再次执行生产图形流程，先通过钓台点击热区切换位置再恢复，确认移动不误触抛竿；完整完成甩竿、提竿、遛鱼和鲤鱼入包，`SMOKE RESULT code=0 errors=0`。记录为 `105-fishing-simple-graphics.log`。本轮只修改界面与图形验收，核心鱼种及钓鱼判定未改动。

## 20 鱼扩展

鱼种扩至 20，加入六类不同运动目标、鱼种权重、水层和鱼饵偏好、不同重量及回收价。原有三种 ID 保留；所有新鱼自动接入食材目录、承重、做饭、送礼和回收。存档版本 3：版本 2 等待或鱼口阶段的 0–99 抽签扩大为 0–9999；上岸／遛鱼中的既有鱼 ID 与进度保持，不重发鱼。

- `105-fishing-20-tests.xml`：66／66 通过，钓鱼 40、人物邀约 25、事件配置 1。逐鱼测试通过真实控线取得鱼获，再保存恢复、做饭和扣实物出售；不直接设置收鱼进度或凭空入包。
- 快速变向初始频率过高，经反应式控条模拟与逐鱼实际测试调整到可追赶范围，保留比平稳型更频繁的变向。
- `105-fishing-20-graphics.log`：`SMOKE RESULT code=0 errors=0`。生产图形流程支付 ¥300，实际甩竿一次，随机钓到麦穗鱼一条并入包。当前截图及 `runtime-results.txt` 已更新；没有强行设置候选鱼种或中奖结果。
- 本轮未重跑其他全项目测试或打包；此前已知城市活动及赛车旧失败继续保留。
