- **交互键改成 F**；能交互时头顶出现黄色 ▼ 和“[F] xxx”提示（街上走到店门口、屋里走近床/衣柜/电饭锅/门）。
- **房间信息不再靠“点交互”看**：右上角新增“我的”（状态、房间、吃的、家具背包、在路上的包裹、店里装饰分）和“网购”。屋里只能和家具交互：床 = 睡觉/小睡，衣柜 = 只能换已有的衣服，电饭锅 = 真做饭，门 = 出门。**不能再直接花钱升级**。
- **买东西两条路**：线下去“宜居家具城”（当场付全价，当天放进家具背包）；线上“网购”（85 折，**2 天后**送到家，衣服、大米也走这里）。
- **家具可以摆放**：家里和店里都是。点“我的”→“摆放家具”进入摆放模式：背包里点家具，鼠标指哪放哪，左键放下、R 旋转、右键/Esc 放回、X 收进背包，点已摆的家具可以拿起来挪（绿色=能放，红色=原因见右侧面板；不能压别的家具、挡门口、挡窗户）。睡眠质量、水电、装饰分都由屋里**实际摆着的**家具决定（床取最好的一张，没有床只能打地铺 ×0.6）。
- **店里改造要歇业一天**：“我的”→“装修店面”确认后今天店不营业（`ShopSimulation.ForcedClosed`），随便摆；摆设增加客流（装饰分 ×1%）和顾客耐心。注意：店铺升级（招牌、空调等）仍是即时生效，没有强制歇业。
- **做饭是真的**：开局 5 斤米（`Pantry`）；电饭锅里选放几斤米（≥0.5）和是否加食材，焖 40 分钟，1 斤约 4 碗；吃一碗 10 分钟；可装饭盒带出门，饭点优先吃饭盒 → 在家吃自己做的 → 才去外面花 ¥15。**没有冰箱**：做好的饭、食材隔天就坏。别的食物要去“农贸市场”（6:00–18:00）买米、青菜、鸡蛋、豆腐、猪肉。
- 地图：商业街的两家邻居店现在是“宜居家具城”（business=家具）和“农贸市场”（business=农贸）。
- **智能手机与背包**：新游戏没有智能手机，网购和 1788 下单都锁着；去“米家手机”（business=手机）花 ¥800 买，或菜单里勾“作弊工具”立刻拥有。出门有背包，承重 = 出行方式载货格数 × 2 公斤（步行 12 / 打车 30 / 电动车 20 / 三轮 80 公斤），进货的配件、买的米菜、礼品都算重量；米菜回家自动放进厨房，背包里的菜隔天也会坏。礼品（烟、名烟、水果、酒、饮料、点心、白酒）不能当场付钱送，要先在“烟酒茶行”/农贸市场买或网购进背包；“递烟打听行情”也要消耗一包烟。请吃饭（烧烤夜宵）仍然当面付钱。
- **大件家具要叫货车**：每件家具有重量，单件超过 20 公斤（弹簧床、实木床、衣柜、空调、书桌、沙发、等候沙发、LED 灯屏）太大件，背包装不下；在家具城点“叫货车 +¥120”，原价 + 运费，明早送到家（进家具背包）。轻便的（落地扇、窗帘、地毯、绿萝、海报等）自己背，算负重，回家或回店里自动放进家具背包。网购照旧 2 天快递到家，不用另付运费。

## 怎么跑测试
Unity 编辑器开着本工程时，命令行不能再打开同一个工程。所以脚本会先把 `Assets`、`Packages`、`ProjectSettings` 镜像到旁边的 `../_ci` 目录，再在镜像里运行。第一次运行会重新导入，比较慢。

```
powershell -File tools\run-tests.ps1                 # 单元测试
powershell -File tools\run-smoke.ps1 -CopyShots      # 冒烟测试 + 截图拷回 docs/previews
```

Unity 路径默认是 `D:\UnityEditor\2022.3.6f1\Editor\Unity.exe`，可用 `-Unity` 参数改。冒烟测试需要显卡，不能加 `-nographics`。

## 已知问题与限制
- 美术是灰盒：人物是胶囊，建筑是方块，没有音效。
- 只有一个存档位，存在 `Application.persistentDataPath/save1.json`。
- 字体用系统的微软雅黑，暂时没导入思源黑体和 TextMeshPro。
- 批处理截图里，店内"结账"标签和顾客位置有偏差。这是批处理里把画布改成相机模式造成的，正常 Play 用的是全屏叠加画布，坐标换算已核对过代码；验收时请顺便确认。
- 数值都是起步默认值，没调过平衡。冒烟测试里的脚本玩家一个月后现金为负，这不代表真实玩法的难度。
- 搬到别的街的新店面、主播、汽车、大老板直供等仍属 VS2。
