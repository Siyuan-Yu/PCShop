## 一次买的东西一起到只弹一个窗（2026-10-31）

- **问题**：一次在家具城买三件重型货架（每件 90 公斤，一辆车装两件），分了两辆车送达，就弹了两个“货送到了”，同种货还各报一行。

## 家具送到哪以购物车选择为准、送达弹窗（2026-10-31）

- **查证**：用户反映在家具城买店里用的货架、选了送到家里，回家却看不到，怀疑被默认送去店里。查下来购物车结账确实按“送到 ▼”选的地址走（`Checkout` 先算 `CourierShop` 并 `SetCourierDest`，每件家具执行时读同一个选择；新测试两种选法各验了一遍）。真正的原因有两条：① 家具不分家里 / 店里两个仓库，送到后统一进“我的”家具库，而**家里摆放面板只列家里用家具**，店里用的货架在家里被过滤掉，所以在家里完全看不到；② 叫车送达以前只发一句底部消息（`DeliverCouriers` 里 `Say`），很容易错过，看起来就像没送到。
- **修复可见性**：家里 / 店里摆放面板现在列出全部待安装家具，用不上的那类也显示，标“（店里用，去店里装修时摆）”/“（家里用，这里摆不了）”并禁用按钮（`GameUi.RefreshPlacementPanel`）。家具城顶部说明也写清了这一点。
- **送达弹窗**：叫车送达改成打断式弹窗（`DeliverCouriers` 改用已有的 `Show`/`Popup` 机制，和 1788 到货、网购包裹一致），标题“货送到了”，正文写明从哪叫的车、送到家里还是哪家店、每样东西放在哪（厨房 / 纸箱 / 临时存放 / 上货架 / “我的”家具库）。打电话叫货车搬东西送达走同一条，也弹窗。家具送达文案统一为“进了‘我的’家具库，在家里能查看，摆要去用得上的地方”。

## 纸箱按个数算容量、临时存放（2026-10-31）

- **问题**：送到家里的东西进了家里纸箱，但纸箱只有 20 公斤，屋里也看不出东西放哪；东西又能无限买，送多了放不下。
- **纸箱容量**：不管家里还是店里，每个纸箱固定装 200 斤（100 公斤，`GameSession.BoxCapacityKg`）。总容量 = 屋里 / 店里摆着的纸箱数 × 100 公斤（`HomeBoxes / ShopBoxes`，按 `FurnitureRole.Storage` 的家具数）。家里开局那堆“纸箱和塑料盆”算 1 个；新租的铺子送 3 个纸箱，从左前角沿左墙摆好（`GiveStarterBoxes`，摆不下的进“我的”；每家店只送一次，旧存档读档时补上）。家具城“家里用”和“店面设施”里都能买纸箱（¥20，0.6×0.5 米），摆得越多装得越多，房间大小就是上限。纸箱里还有东西、收起来就装不下时，不能把纸箱收回“我的”。
- **每家店各有一套纸箱**：原来所有店共用一个 40 公斤的“店里储物柜”，现在每家店各有自己的纸箱（`OwnedShop.Locker`），文字里的“储物柜”都改叫“店里纸箱”。店里走到纸箱旁边按 F 就能打开（头顶提示写着 ×个数和已放 / 上限）。
- **临时存放**（参考鬼谷八荒）：叫车送货、1788 送家里的配件到了，纸箱放不下的部分进“临时存放”（家里 `HomeTemp / HomeTempParts`，每家店 `OwnedShop.Temp`；店里的配件照常直接上货架）。纸箱窗口分两块：上面临时存放、下面纸箱和背包。临时存放里有东西时，人在家 / 在那家店里会自动弹出窗口，**不清空不能关**（关闭按钮和 Esc 都不行，按钮上写着还剩什么）。清空的办法：选中一格“放进纸箱”（按住放多件）/“拿进背包”/“扔掉”，或者“能放的都放进纸箱”、“打电话叫货车搬走”（叫货车窗口多了“临时存放”这一处来源）、“全部扔掉”（要确认）。临时存放里的吃的隔天也会坏，存档会保存。

## 怎么跑测试
Unity 编辑器开着本工程时，命令行不能再打开同一个工程。所以脚本会先把 `Assets`、`Packages`、`ProjectSettings` 镜像到旁边的 `../_ci` 目录，再在镜像里运行。第一次运行会重新导入，比较慢。

```
powershell -File tools\run-tests.ps1                 # 单元测试
powershell -File tools\run-smoke.ps1 -CopyShots      # 冒烟测试 + 截图拷回 docs/previews
```

Unity 路径默认是 `D:\UnityEditor\2022.3.6f1\Editor\Unity.exe`，可用 `-Unity` 参数改。冒烟测试需要显卡，不能加 `-nographics`。

## 已知问题与限制
- 美术是灰盒：人物是胶囊，建筑是方块。音效是程序合成的占位（`SoundFx.cs`：点按钮、收钱、门铃、出错；菜单里可关 / 调音量），正式音效音乐等朋友制作。
- 只有一个存档位，存在 `Application.persistentDataPath/save1.json`。
- 字体用系统的微软雅黑，暂时没导入思源黑体和 TextMeshPro。
- 批处理截图里，店内"结账"标签和顾客位置有偏差。这是批处理里把画布改成相机模式造成的，正常 Play 用的是全屏叠加画布，坐标换算已核对过代码；验收时请顺便确认。
- 数值都是起步默认值，没调过平衡。冒烟测试里的脚本玩家一个月后现金为负，这不代表真实玩法的难度。
