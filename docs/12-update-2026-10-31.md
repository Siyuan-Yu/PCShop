## 3. 今天的经营与交互规则

### 3.1 多家自营店与搬迁

- 已有店再签铺面就是增开一家自营店，不设固定数量上限。每家店有独立库存、家具、货架设置、员工、订单、营业时间、升级和补货目标；现金及知名度共用。
- 玩家进哪家店就切换到哪家；离开后保留最后经营的店。无人值守的店不营业，有员工在班的后台店继续经营。
- 每家店分别扣月租；网购/直供记录订单目的店，叫车可选家或任意自营店。
- 搬迁流程是签新铺 → 打电话叫货车搬货 → 回旧店“升级”页退租。主店可退，下一家接任；最后一家不能退。
- 当前退租代码没有覆盖纸箱/临时存放物品，不能把“退租已检查全部货物”当作已完成，见第 6 节。

### 3.2 购物车与货车

- 档口、家具城、烟酒茶行、农贸市场先加购物车，不立即扣款；购物车分叫车和背包两栏，支持逐件、按住连续操作和拖动。
- 背包超重可改叫车；“背得动的都放背包”自动分配。面包车每车 200 公斤，按装载和目的地计运费。
- 价格统一显示为“货款 + 运费（辆数 × 单价）= 合计”；结账按钮写“结账（付合计）”。“少拿一件”表示减少一件，不是整行删除。
- 通讯录“货车司机老蔡”可搬身上物品；在家还可搬厨房、纸箱、临时存放，在店里还可搬后仓和纸箱。装货单确认出发时才扣运费和移出物品，目的地不能是现在站的地方。
- 送达会弹窗说明来源、目的地和存放位置；同一目的地同时到达的多车合成一个提示，同类物品合并数量。

### 3.3 纸箱、临时存放与家具

- 每个摆出的纸箱容量 100 公斤（200 斤）。新游戏家里 3 个，共 300 公斤；每家新租店送 3 个。旧家存档不额外补两个箱子，已领取的新店纸箱不会反复赠送。
- 家和每家店独立存储。家里配件进入纸箱，店里配件进入库存；家里送到的米菜进厨房，礼品和家具进纸箱。纸箱放不下的送货进入当地临时存放。
- 临时存放可保留 3 个游戏日，家与每店分别计时，存读档保留倒计时。旧档没有计时字段时从读入后开始记录。清空后计时归零。
- 未到期时可正常关闭纸箱窗口；到期且玩家在该处时会自动打开，必须通过入箱、拿进背包、摆出家具、搬走或丢弃清空。食品仍按保质规则腐坏。
- 家具分类仅供商店展示，不再限制只能在家/店里摆。实际仍须符合房间占地、墙面、碰撞与门口通道规则。
- 叫车和网购送达的家具、摆好的家具收起后均进当地纸箱，满了进临时存放；背包一键卸货装不下的家具保留在背包。
- 摆放清单合并当地临时存放、纸箱和旧家具库，依次取用；纸箱里选家具可“摆出来”。店内编辑先确认歇业装修。撤销/重做还原布局和相关家具数量。
- 旧“我的”家具库仍保留任务奖励、老档及退租收回等来源，不宣称已经彻底移除。

### 3.4 营业、进门与任务

- 街上普通店/中介 9:00–21:00；农贸市场 6:00–18:00；档口工作日 9:00–18:00；车行 9:00–19:00。自己的店、家等适用自己的规则。
- 快捷出行仍可走到打烊店门口；按 F 或到达尝试进门时弹窗写营业时间，玩家留在门口，不先移动到路中间。
- 任务仅显示当前阶段说明与进度，不提供任务内一键前往、传送或代开页面。已完成教学不回看，未来任务不提前展示。
- 车行位于商业街原明亮眼镜的位置；经营总览开局隐藏，后续按条件开放。

### 3.5 暂停与继续（本次修复）

- 柜台、库存、定价、订单、装修、升级、招人这 7 个店铺侧栏页签不再额外持有暂停锁。切页保持玩家现有暂停/运行状态。
- 在任一页点击顶部“继续”或选 1×/2×/4×/8×均能推进游戏，不必切回柜台；空格与数字快捷键走同一时间控制。
- 弹出窗口和正式家具摆放模式仍保留各自的暂停锁；店铺侧栏不能释放它们。
- 角色移动统一检查时间运行状态。暂停时街上、店内和家里都不能 WASD 移动；家具编辑时也不移动角色。
- 核心修改：`GameUi.Shop.cs` 移除侧栏 Hold/Release；`GameController.HandleMovement` 增加运行状态/摆放检查；顶部提示及试玩文档同步更新。

## 4. 存档与源码结构

- `Assets/Scripts/Core`：纯 C# 规则；`GameSession` 分部文件按生活、库存、物流、多店、经营、存档等主题拆分。
- `Assets/Scripts/Game`：Unity 输入、UI、场景与表现。主要 UI 和场景由代码生成，地图位于 `Assets/Resources/Data/city_layout.json`。
- `OwnedShop` 保存单店租约、模拟、员工、布局、库存配置与本店纸箱/临时存放状态；会话的 `PlayerShop` 指当前焦点店。
- 手动 `save1.json`、自动 `autosave.json` 分开，保存到 `Application.persistentDataPath`，各有 `.bak`，读入失败尝试备用文件。
- 本次新增临时存放起始分钟：家/主店在 `SaveHome` 中，其他店在 `SaveShop.tempSince` 中。家具数量与存储位置参与存档；旧字段保留兼容。
- `_ci` 的缓存、测试存档、临时测试日志不作为正式源文件上传。
