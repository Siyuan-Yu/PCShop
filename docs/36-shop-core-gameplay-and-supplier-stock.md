# 店型核心玩法与线下供货上限（2026-11-02）

供货数量与采购频率已由 [第38篇](38-supplier-model-allocation-and-weekdays.md)更新：具体批发商、具体型号独立上限，按星期共享计划份额，频率为每日／一三五／仅周三。以下供货表为本篇首次实现时的历史基准。

## 线下供货与最大采购

每个货源、每种商品每天拥有独立供货数量，老板自采与所有门店进货员共用；付款或成功派出时占用，运输与到货不再次扣减。当天余额随存档保存，跨日恢复，不通过反复开关窗口刷新。

| 商品 | 正常日供货上限 |
| --- | ---: |
| 电脑配件 | 40件；实际可购量还受档口关系额度限制，陌生档口至少12件 |
| 常规模型 | 20件 |
| 服装 | 60件 |
| 食品、食材 | 80件／份；大米为80袋，每袋0.5千克 |
| 其他批发商品 | 40件 |

临时紧缺配额4件与漫展每届限定5件沿用更严格限制。农贸普通食材与批发装共享数量；大米内部以0.25千克为单位累计，兼容生活零售与0.5千克批发袋。员工采购的家具另限每货源每款每日10件。1788和直供继续各自原有渠道规则，本次线下库存不作为所有渠道共享的全城总量。

- 进货员清单每行有“最大”：保存的是每次执行购买最大可购量的意图，执行时重新读取剩余供货。点普通数量控件可恢复固定数量。
- 普通数量、起订量、当日剩余、现金、运输承重仍共同约束实际出发数量；按清单优先级允许部分采购，收据只记实际买到的数量和费用。
- 线下购物车也提供最大加购，结账时重新检查库存；仅放进购物车不会锁库存。
- 阈值补货仍按实际未覆盖缺口执行，不把“最大”解释成无限采购或绕过补货目标。

## 电脑店：科技迭代

- 在原18种配件上增加第二、第三代同档次变体，共54种配件；延续六类、三档与原接口兼容规则，不推翻已有装机流程。
- 游戏第31天第二代发布，第91天第三代发布；未发布的配件不进入线下及手机采购目录，采购API也拒绝提前买入。
- 落后一代的配件参考价为正常价78%，落后两代为55%；新品参考基价较原代分别提高18%、36%。原有宏观行情仍共同起作用。
- 新品可作为配件进货、陈列、销售；同档次顾客更偏好新代。旧配件继续可售、可用于原装机与低价整机，不删除旧库存。
- 已确认的单品售价按实际金额保存，不随新品行情强制改价；购买意愿按当前参考价重算。未单独确认价格的商品沿用统一加价。

## 模型店：作品热度

四个原创系列各有错开的40天作品热度周期：预告／开播／角色走红／完结降温／退潮。阶段参考倍率依次为1、1.25、1.9、1.35、0.65。批发报价、零售参考、顾客预算与购买倾向共同反映热度，而非只显示新闻文案。

柜台可查看本系列热度与因果，手机“行情”内有各行业信息。涨价不能代替销售结算；仍须真实陈列、购买和收银。限定款的漫展采购限制保留。

## 服装店：季节与低频供给

- 约90%的服装顾客仅挑应季服装；只有反季库存时，这部分顾客会拒购。其余少量顾客仍可能选择反季款。
- 按商品季节标签匹配春秋、夏、冬，不降低售价90%，也不把90%顾客直接挡在店外；混售的其他商品仍走各自选择逻辑。
- 平日参考价稳定。每360天有两段供给事件：第71—90天棉花减产涨35%，第251—280天暴雨供给受阻涨50%。倍率以正常目录参考价为基准，不逐日复利叠加。
- 新闻、进价与实际成交估值使用同一规则；库存不因换季自动消失。

## 二手旧物店：风险收购与买后鉴定

- 购买并摆放“收购鉴定台”和“二手销售展示台”，不要求普通货架或装机台。
- 首批旧台灯、旧音箱、旧腕表、旧装饰摆件；12位可重复出现的卖家、3种性格倾向、4套循环说辞。性格影响说真话概率，但不提供确定答案。
- 卖家带来物品时就确定真实状态、说辞、要价与接受底价。收购前只能听说辞和报价，不能检查真实状态；玩家出价或拒收。
- 买下后一次检查揭晓好货、瑕疵品、仿造品、完全损坏。检查及读档不会重新抽取状态。
- 四类参考转售价分别为正常价值的100%、55%、22%、3%；损坏品按废件残值公开出售，不能保证回本。每件独立成本、状态和售价，玩家可承受亏损、降价或主动丢弃。
- 每台销售展示台4个位置，最多持有20件未售旧物。顾客按实际标价相对真实价值决定购买，收入记录实际成交；不会鉴定后直接发利润。
- 提供单件金额输入、加减调价、鉴定、上架、改价、拒收与丢弃。室内显示卖家与已陈列旧物。

### 收购师

新增员工智力，招聘范围20—95；旧员工默认50，能力随人保存、换岗保留。收购师是可安排岗位，继续共用人员名额、工资、排班、在岗和跨店调动。

开启代管后设置每日收购预算、单件限价和谨慎／均衡／积极倾向。智力对应的判断准确率为30%＋智力×0.6%，上限90%；员工仍可能被误导或买亏，不在买前获得必然正确的鉴定。每个卖家仅判断一次，不按分钟反复重抽判断。员工完成收购后的鉴定与按参考价值陈列；实际出售才入账。

## 餐馆：厨房、火候、堂食

原食品零售类型退出新开店选项，新增独立餐馆类型。需要加工台、炒锅灶台、传菜台、餐桌、冰箱，设施均可在家具城购买、配送与正常摆放，有对应程序化模型。

- 首版菜单为青菜炒饭18元、鸡蛋炒饭22元、肉末炒饭28元，可逐道暂停供应，菜单定价倍率0.8—1.6；较高价格降低接单需求。已点单金额固定，不追溯改价。
- 每份实际消耗0.25千克大米与1份对应食材。读取本店冰箱、后仓及经营食材库存，不凭空生成菜品。
- 实际流程：顾客入座点单 → 备料投锅 → 8游戏分钟后熟 → 及时出锅到传菜台 → 上菜 → 用餐15分钟 → 付款 → 收桌。
- 第38分钟焦糊，不能上菜；倒掉重做需要再次耗料。等待100分钟仍未上菜的顾客离开，不产生收入。锅位与餐桌按实际摆放数量限制，并发不能重复占用或扣料。
- 暂停时火候暂停，所有倍速共用游戏时钟；界面实时显示距离熟透或焦糊的剩余分钟。
- 厨师与服务员是独立可安排岗位。实际在岗的厨师负责投锅出锅，服务员负责上菜收桌；老板可手动兼任。离店后有实际在岗人员才能继续接客，收款只发生一次。
- 柜台提供“店内食材放入冰箱”，在实际容量内转入，保留原批次并停止消耗保质期；冰箱外食材仍正常过期。
- 室内显示餐桌顾客、锅内状态和上桌食品。靠近专用家具可按F打开操作，顶部营业标记和室内门面与实际经营状态一致。

## 店型入口与旧档

新开店／主售选项为电脑、模型、服装、二手、餐馆；不加入宠物店，不再提供生鲜、花店及旧食品零售作为新选项。

旧花店、生鲜、食品店继续读入，保留原库存、设施、员工与采购，不强制清空或无偿换成餐馆。可在柜台转型，原资产仍保留。专用店有未处理订单、待收卖家或未售旧物时，禁止直接转型、结束经营或搬店；先处理物品与订单。正常空店搬迁保留经营状态和账务归属。

所有新订单、旧物、真实状态、员工智力、供货消耗、最大采购意图和已确认的单品售价均进入存档。已完成订单读档不重复收款、收购或扣材料。
