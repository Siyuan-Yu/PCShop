# 赛车手动视角与固定1倍速（2026-11-07更新）

竞速比赛与免费计时练习统一以真实秒数、60Hz固定物理步长运行，不乘城市的1／2／4／8倍速。开始驾驶时城市倍速设为1，驾驶期间持续锁定；普通城市倍速按键不进入驾驶输入分支，HUD隐藏城市倍速按钮并明确显示“固定1×”。结束或退赛后恢复进入前的城市倍速与用户暂停状态，城市仍按原规则在赛车结束时结算30游戏分钟。

镜头只跟随车辆位置，不随转向自动旋转。每场开始时对齐起步车头，之后偏航与俯仰仅由鼠标右键拖动调整；A/D不改变镜头角度。默认56°斜俯视，可右键上下拖动调整。视野中心沿当前镜头朝向略向前偏移，车速变化时缩放平滑过渡。

- W／上箭头：沿车头方向向前加速。
- S／下箭头：先刹车，低速后倒车；倒车时镜头不反转。
- A／D或左右箭头：只控制车辆向左／向右转向。
- 鼠标右键拖动：手动旋转和俯仰镜头，松开后保持该观察方向。
- 空格手刹、R复位、Esc暂停沿用原规则。
- Tab仍切换跟车／全景，两种视野都保留用户选择的观察方向；全景按实际镜头角度、俯仰和屏幕比例计算取景范围。

小电驴五款车型的赛车极速和加速度提高到此前2倍，显示性能同步；小电驴组对手也使用对应的新速度，不改变赛车时间倍率。三轮、轿车性能保持原数值。

比赛和免费练习取消玩家健康40、精力30的准入条件，低健康、低精力也可开始；保留实际车辆可用性、车况和场地条件。全局日常、活动、事件与赛车的精力消耗统一降为此前80%，日常每游戏小时从5.5变为4.4，赛车每场固定消耗从8变为6.4；恢复、存档精力值和精力上限校正不按消耗处理。
