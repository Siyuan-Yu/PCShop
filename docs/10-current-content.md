# 现有内容总览（2026-10-30）

这份文档把游戏**目前已经做进去**的内容按系统整理在一起，方便一次看全。具体怎么试玩、验收什么见 [`07-vs1-acceptance.md`](07-vs1-acceptance.md)；开发进度和历次改动记录见 [`08-current-status.md`](08-current-status.md)。数值都是占位，没做过平衡。

项目：Steam 游戏 PCShopSell（Unity 2022.3.6f1、URP），玩家在城中村经营一家小电脑店，三年为一个完整周期。

## 1. 世界与操作

- **场景**：商业街（19 家店 + 安居房产中介；开局没有自己的店，街尾空铺最小最偏也最便宜）、地铁站、城中村出租屋、约 2 公里外的电子市场（4 个档口 + 车行 + 地铁站），另有家具城、农贸市场、烟酒茶行、手机店。
- **移动**：街上 WASD 自由走（沿街道范围滑动，进不了楼里），右键拖动 / Q R / V 控制视角；走到门口按 F 进门；底栏“快捷前往”可自动走过去；店内 WASD 走动。
- **步行速度**：约 3 公里/小时（49 米/分钟，画面 11 米/秒），500 米要走 11 分钟；打车约 24 公里/小时、小电驴 15、三轮车 12，用载具明显省时间。
- **时间**：1× 下 1 游戏分钟 = 0.7 秒（一天约 17 分钟真实时间），可 1×/2×/4×/8×、空格暂停；走路和站着时钟速率一致；打开面板自动暂停（店内“柜台”页不暂停）。
- **载具**：步行（6 格）、打车（15 格，按里程计费）、小电驴 ¥1,800（10 格）、三轮车 ¥2,500（40 格，城里不让上路，会被交警追）、地铁 ¥3。
- **交警**：骑三轮车时 8:00–20:00 有概率上岗，视线扇形可见，被看到会追，追上罚 ¥200 并可能扣车。
- **Esc**：关闭最上面一层窗口。

## 2. 出租屋与生活

- **真实房间**：开局和回家都进入一间破旧的出租屋，WASD 在屋里走，走近家具头顶出现提示后按 F：床（睡觉/小睡）、衣柜（换衣服，镜子里看自己的外观）、电饭锅（实时煮饭，按真实时间煮好才能吃）、纸箱（家里的格子储物箱，背包里的东西都能放，上限 20 公斤）、塑料凳 / 沙发（坐下）、门（出门）。
- **家具**：只能买后自己摆（家具城当天拿，网购 2 天到）。家具城和农贸市场一样，先选“装进背包 / 叫车送到家里”，再一件件买；背包装不下只能叫车。叫的是面包车，每辆最多 200 公斤，面板显示当前这辆已装多少、还能装多少，装满了自动叫下一辆、每辆各收一次运费，二三十分钟送到家。床、空调、窗帘、台灯等决定睡眠恢复和水电。
- **衣着**：衬衫 / 夹克 / 西装（魅力 +2/+4/+7），只能网购，到家后在衣柜换；人物外观会跟着变。
- **吃饭**：电饭锅焖好饭后头顶一直跳着闪“饭好了！”，直到取完；饭可以吃掉或装成饭盒进背包（每盒 0.5 公斤）。每天 12:00、18:30 饿两次：在家吃锅里的，出门吃背包里的饭盒，没有就饿着（不会自动花钱买饭），饿到 0 会掉健康。
- **生存**：饥饿、精力、健康；只能在家 18:00–8:00 睡觉或小憩；凌晨 4 点不睡会晕倒；健康太低住院。
- **修电器**：家里坏的东西不能自己修，只能“约师傅”：预付、不退款，师傅会真的上门，日程里有记录和提醒；师傅进屋修东西期间（约 30 分钟）玩家不能出门。
- **每日“昨日营业”小结**：零点弹出进店、成交、营业额、走了几个人及原因，并给一句建议。

## 3. 手机、背包、日程

- **按键机 vs 智能手机**：新游戏只有按键机，只能打电话、发短信（短信常没人回）；去手机店 ¥800 买智能手机，在应用商店下载 app（网购、聊天、1788；应用商店、通讯录、日历自带）。
- **日程**：没智能手机时是写在笔记本上的最近几天安排（自动记录，没有提醒）；有智能手机是真正的日历，能一直往后看，约会 / 师傅上门前 30 分钟提醒。
- **背包**：格子背包（B 键开关），有承重（步行 12 公斤），礼品、家具、食物、饭盒都放这里；家里纸箱窗口和背包是同样的格子形式。背包里的东西不会自己消失，只有在自己的店或家里才能点“一键全放到店里 / 家里”。
- **买了怎么拿**：农贸市场、烟酒茶行、档口、家具城都可以选“装进背包”或“叫车送货”；叫车时用“送到 ▼”下拉框选家里或我的店里（档口默认店里、其他默认家里），按路程收运费，同一家店接着买先装当前这辆车，每车 200 公斤。送家里：米菜进厨房，礼品、配件进纸箱；送店里：配件上货架，吃的、礼品进店里储物柜。
- **店里储物柜**：40 公斤，格子窗口和纸箱一样，在店里的背包窗口或右侧面板“库存”页打开；配件放进去直接上货架。
- **礼品**：烟酒茶行（现场付钱）或网购买进背包，再当面送人，不再当场花钱；送店员也一样，从背包里挑（一瓶饮料 ¥5 就行）。

## 4. 我的店

- **租铺子**：开局现金 ¥10,000、没有店，要去「安居房产中介」签约。中介列着在租的铺子（会时不时挂出来、挂一段时间没人租就下架；隔壁五金杂货约 5 个月后空出来）。月租看大小和离地铁站远近：小 ¥1,500~3,800、中 ¥4,500~11,000、大 ¥12,000~30,000；签约付首月 + 押金 + 中介费（各一个月）；中型要知名度 ≥ 25、大型 ≥ 60。已有店再签就是搬家（退押金，搬家费 ¥800，货和人跟着走）。作弊按钮可直接租下街尾小店回到旧开局。

- **门外的街**：店里能看到门外的人行道和马路，路人来回走、车开过（白天多、半夜少，路灯晚上亮）；顾客从街上走过来进门，买完出门走远。走到门口按 F（或接着往外走）就出门回到街上。

- **顾客**：按分钟生成，在店里能看到他们走到货架前逛、拿货（手里真的拿着盒子，货架这时才少一件）、拿到柜台排队、等你结账；你不来，等到不耐烦（40 游戏分钟）就把货**放回货架**再走。头顶有“想买：xx”和离店原因小字（太贵 / 等太久 / 没货 / 没带现金 / 关门…），收款飘“+¥”。
- **收银**：老板必须站在收银台旁才能结账（按 F，或点气泡 / 右侧“结账”）；不在时顾客头顶写“等你到收银台”，继续排队直到不耐烦。收款码、自助结账平台等升级让顾客更快、甚至自动结账。
- **寻路**：顾客按规划好的路线绕开展示桌（桌角当路点，可见性图 + Dijkstra），不会在桌边来回卡住。
- **库存**：容量以“格”计（小店 40，中 120，大 300）；盒装 1 格、散件 0.4 格，显卡和电源机箱 ×2；盒装更贵、更受信任，可拆包装（不可逆）。
- **定价**：全局加价（0.9–1.6）+ **每件配件单独定价**（“跟随”恢复全局）；盒装再贵 12%。右侧面板“定价”页和货架窗口里都能调（货架上显示售价、市场价、顾客买的概率）。每类配件只有一个货架。
- **补货与缺货提醒**：走到货架前提示“缺货！/快没了”；同一天同一类缺货让顾客空手走了会弹提示；手机 1788 app 的“自动补货”页给每件配件设常备数，每天 9:00 库存（含在途）低于目标 40% 就用手机在 1788 自动补到目标（需要智能手机 + 1788、剩余现金 ≥ ¥500、放得下仓位，可指定下单的店）。
- **货架与展示台**：每个货架前按 F 看这一类配件的整盒 / 散件数量；店**正中间**的长桌是**整机展示台**（小店 2 个机位、中店 4 个、大店 8 个；用库存配件装好摆上去，想买整机的顾客直接抱去结账，摆得越多想买整机的人越多；大门开在右前方货架这一侧，收银台在左边，顾客进门先逛货架、绕开展示桌，再回左边排队结账）。货架窗口画成真的木货架：上层摆整盒、下层摆散件，入门 / 主流 / 高端各一格，货按数量摆在板上，价签挂在板边，缺货显示灰影；展示台窗口画成三台开着的整机，屏幕上是档次和成交价，台下的展牌写配置和每样配件有没有货，可直接跳到装机单。
- **装机订单**：顾客下整机单，两天内装好才收全款；拖拽装机小游戏，错装算失误，超时作废并掉知名度。
- **经营报表**：“柜台”页底部按钮，近 14 天营业额（绿）/ 支出（红）柱状图。
- **店铺升级**（9 项）：收款码、自助结账、货架扩容 ×3、招牌灯箱、空调、监控；店面大小不在这里升级，去房产中介换铺子。
- **雇人**：贴招聘，次日有应聘者，日薪，员工 9:00–21:00 看店自动结账。
- **其它面板**：摆放店里家具要歇业装修一天；“我的”显示状态；“行情”显示新闻和价格指数。

## 6. 行情

新闻 → 三个宏观指标（币圈热度、AI 需求、新品周期）→ 六个品类价格指数（0.6–1.8）；第 9 天固定矿潮头条，第 19 天新一代处理器。档口老板和人脉会私下透露“涨 / 跌”小道消息，有真有假，5 天后对账并显示每个人的应验率。

## 7. 人物与立绘

- **9 位固定人物**：老张（熟客，中学老师）、李姐（房东）、老周（电子市场老货商）、阿杰（隔壁手机店老板）、老李 / 阿王 / 钱姐 / 老孙（四家档口老板）、小林（发小）。每人有 0–100 的交情，靠事件选择、送礼（每人每 5 天一次）、约出去玩来涨，到门槛有实际好处（客流、房租、进货价、救急、进价折扣与额度）。
- **约出去玩**：约晚上 19:00 或周末白天 10:00（交情 ≥ 15，对方不一定答应），到点弹出选择去哪玩，花钱花时间，涨交情，对方爱的活动涨 1.5 倍；放鸽子、错过会掉交情。
- **立绘与交谈**：9 位人物各有一张 AI 生成的半身立绘（`Assets/Resources/Portraits/{id}.jpg`，干净的 2D 游戏角色插画风（介于写实动漫和 Q 版卡通之间）：正常头身比、每人脸型 / 眼睛 / 眉形 / 痣疤等面部特征各不相同（不只靠服装发型区分）、有色轮廓线、明亮平涂只留一层柔和阴影、每人一种淡彩底色加一个平涂圆，可整体替换）。档口窗口改成**左边老板立绘 + 右边货品**，点人物后出现一组**选项**（灰着的写明解锁条件）：随便闲聊（每天一次、10 分钟、交情 +0.8，涨到 50 为止）、赠送礼品、聊聊行情（递烟，档口老板才有）、聊聊人生（交情 30 / 50 / 70 各解锁一段过去的故事，每天一次，交情 +2.5）、交心打听内幕（交情 60 解锁，档口老板，不用递烟、消息一定是真的、一周一次）、发出邀约、砍价（在档口里）。目标面板“认识的人”有小头像和“交谈”按钮。
- **普通店主**：烟酒茶行（老胡）、手机店（小唐）、家具城（小赵）、农贸市场（王婶）、车行（老马）也用同一套模板：左边立绘 + 一句话（点头像换一句），右边原来的商品内容。他们没有交情系统。

## 8. 随机事件与三年路线

- **随机事件**：每天 11:00 约 55% 概率触发（第 2 天起，同类有冷却）：城管检查、熟客推荐、停电、小偷、学生团购、同行低价竞争、捡到钱包、朋友请吃饭、借钱、差评、发传单、感冒等 12 个；弹出后必须选一项。
- **路线**：第一个月（第 30 天，身家 ≥ ¥8,000 且雇过人）→ 站稳一年（第 365 天，身家 ≥ ¥30 万、知名度 ≥ 30）→ 有名号的店（第 730 天，身家 ≥ ¥150 万且在中介换到中型以上）→ 三年之后（第 1095 天出结局：勉强糊口 / 稳稳当当 / 电脑城新星 / 电脑城大亨）。没过检查点只会让店租 +10%。
- **经营压力**：每月 1 日扣房租（店租按租约，街尾小店 ¥1,500；出租屋 ¥450；随交情和检查点变化；没店不扣店租）；现金连续 3 天为负破产。

## 9. 存档

每天开始自动存档（路上不存），菜单可手动存 / 读，含随机数状态、背包、家具、手机、日程、预约、定价、补货目标等；单存档位，位于 `Application.persistentDataPath/save1.json`。

## 10. 代码与测试

- 规则层 `Assets/Scripts/Core/`（纯 C#，不依赖 Unity）：`Session/GameSession*.cs`（按主题拆分的分部类，如 Home / Pack / Visits / Npcs / Social / Trade / Shop / Restock / Save …）、`Shop/ShopSimulation.cs`、`Finance/`（账本、报表）、`Market/`、`Trade/`、`Catalog/`、`Inventory/`、`Home/`。
- 表现层 `Assets/Scripts/Game/`：`Runtime/`（GameController、街道 / 店内 / 出租屋场景、相机）、`UI/`（代码生成的 uGUI：HUD、各面板、`GameUi.Npc.cs` 立绘与交谈）。
- 测试：`tools\run-tests.ps1` 跑 EditMode 单元测试（目前 293 个全过）；`tools\run-smoke.ps1 -CopyShots` 批处理冒烟 + 截图拷到 `docs/previews/`（目前到 `vs1_85`）。冒烟依赖随机客流，极少数情况会因顾客来得太慢偶发失败，重跑即可。

## 11. 已知缺口与待办

- **没做**：小偷（店里偷东西）、正式音效 / 音乐（现有程序合成占位音）、街上路人 / 修理师傅 / 顾客的立绘（现在没有用到它们的界面）、VS2 内容（主播、汽车、大老板直供、网吧 / 电竞馆）。
- **美术**：世界仍是低多边形灰盒；立绘是 AI 生成的干净 2D 游戏角色插画风（暂定画风，之后可再调整；之前试过写实、赛博霓虹、明日方舟式、Q 版卡通，要么太像 AI 漫剧、要么太卡通）。
- **时钟**：打车、小电驴、三轮车时游戏时钟比站着略慢（约 0.7–0.9 游戏分钟/秒 对 1.43），还没统一。
- **数值**：全部是起步默认值，没调过平衡。
- **用户侧待办**：Unity 许可证、仓库私有性、Steam 账号、游戏名 / 商标、画风测试。
