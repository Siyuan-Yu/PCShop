# 现有内容总览（2026-10-30）

这份文档把游戏**目前已经做进去**的内容按系统整理在一起，方便一次看全。具体怎么试玩、验收什么见 [`07-vs1-acceptance.md`](07-vs1-acceptance.md)；开发进度和历次改动记录见 [`08-current-status.md`](08-current-status.md)。数值都是占位，没做过平衡。

项目：Steam 游戏 PCShopSell（Unity 2022.3.6f1、URP），玩家在城中村经营一家小电脑店，三年为一个完整周期。

## 1. 世界与操作

- **场景**：商业街（19 家店 + 安居房产中介；开局没有自己的店，街尾空铺最小最偏也最便宜）、地铁站、城中村出租屋、约 2 公里外的电子市场（4 个档口 + 车行 + 地铁站），另有家具城、农贸市场、烟酒茶行、手机店。
- **移动**：街上 WASD 自由走（沿街道范围滑动，进不了楼里），右键拖动 / Q E / V 控制视角；走到门口按 F 进门；底栏“快捷前往”可自动走过去；店内 WASD 走动。
- **人物动作**：家中、店内和街上的移动有交替迈步、屈膝、摆臂和身体起伏；顾客与路人等共用动作。停下或撞墙后收步，骑车不踏步，暂停冻结姿势，进出场景不误播；衣服和裤腿随关节一起运动。
- **步行速度**：仅街道上的玩家手动/自动步行画面速度降低 50%，走路动作同步放慢。室内恢复原速：店内 4.8、家中 2.6 单位/秒；载具和 NPC 不变。游戏路程折算仍为 49 米/分钟，500 米约 11 游戏分钟；打车约 24 公里/小时、小电驴 15、三轮车 12。
- **时间**：1× 站立经营时每游戏分钟约 0.23 秒，一天约 5.6 分钟；支持暂停、1×/2×/4×/8×。出行按路线距离和交通方式折算游戏分钟，不保证与站立的现实时间速率一致；打开面板自动暂停，店内“柜台”页除外。
- **载具**：步行（6 格）、打车（15 格，按里程计费）、小电驴 ¥1,800（10 格）、三轮车 ¥2,500（40 格，城里不让上路，会被交警追）、地铁 ¥3。
- **交警**：骑三轮车时 8:00–20:00 有概率上岗，视线扇形可见，被看到会追，追上罚 ¥200 并可能扣车。
- **路人搭话**：街上路人走近（约 1.3 米）时提示“和路人聊聊”，按 F 搭话，路人停下转身面对你。8 种路人（大爷、阿姨、学生、白领、外卖小哥等）各有开场白和闲聊；“打听点事”会给实用消息（中介提前签约的坑、升级在哪买、电子市场、最新新闻）；有店后可“推荐一下我的店”一次。路人只能按 F，不能用鼠标点。
- **Esc**：关闭最上面一层窗口。

## 2. 出租屋与生活

- **真实房间**：开局和回家都进入一间破旧的出租屋，WASD 在屋里走，走近家具头顶出现提示后按 F：床（睡觉/小睡）、衣柜（换衣服，镜子里看自己的外观）、电饭锅（实时煮饭，按真实时间煮好才能吃）、纸箱（家里的格子储物箱，背包里的东西都能放，上限 20 公斤）、塑料凳 / 沙发（坐下）、门（出门）。
- **家具**：只能买后自己摆（家具城当天拿，网购 2 天到）。家具城和农贸市场一样，先选“装进背包 / 叫车送到家里”，再一件件买；背包装不下只能叫车。叫的是面包车，每辆最多 200 公斤，面板显示当前这辆已装多少、还能装多少，装满了自动叫下一辆、每辆各收一次运费，二三十分钟送到家。床、空调、窗帘、台灯等决定睡眠恢复和水电。
- **衣着**：衬衫 / 夹克 / 西装（魅力 +2/+4/+7），只能网购，到家后在衣柜换；人物外观会跟着变。
- **吃饭**：电饭锅焖好饭后头顶一直跳着闪“饭好了！”，直到取完；饭可以吃掉或装成饭盒进背包（每盒 0.5 公斤）。每天 12:00、18:30 饿两次：在家吃锅里的，出门吃背包里的饭盒，没有就饿着；可在“我的”中主动开启智能手机送餐（¥25/餐，默认关闭），饿到 0 会掉健康。
- **生存**：饥饿、精力、健康；只能在家 18:00–8:00 睡觉或小憩；凌晨 4 点不睡会晕倒；23:00–4:00 屏幕正中间出现红色横幅“太晚了，该睡觉了！”，显示离晕倒还有多久、去哪睡，越晚闪得越快；横幅不挡点击、不暂停游戏。健康太低住院。
- **修电器**：家里坏的东西不能自己修，只能“约师傅”：预付、不退款，师傅会真的上门，日程里有记录和提醒；师傅进屋修东西期间（约 30 分钟）玩家不能出门，可在“我的”里一键等到修好。
- **每日“昨日营业”小结**：零点弹出进店、成交、营业额、走了几个人及原因，并给一句建议。

## 3. 手机、背包、日程

- **按键机 vs 智能手机**：新游戏只有按键机，只能打电话、发短信（短信常没人回）；去手机店 ¥800 买智能手机，在应用商店下载 app（网购、聊天、1788；应用商店、通讯录、日历自带）。
- **日程**：没智能手机时是写在笔记本上的最近几天安排（自动记录，没有提醒）；有智能手机是真正的日历，能一直往后看，约会 / 师傅上门前 30 分钟提醒。
- **背包**：格子背包（B 键开关），有承重（步行 12 公斤），礼品、家具、食物、饭盒都放这里；家里纸箱窗口和背包是同样的格子形式。背包里的东西不会自己消失，只有在自己的店或家里才能点“一键全放到店里 / 家里”。
- **买了怎么拿**：农贸市场、烟酒茶行、档口、家具城都可以选“装进背包”或“叫车送货”；叫车时用“送到 ▼”下拉框选家里或我的店里（档口默认店里、其他默认家里），按路程收运费，同一家店接着买先装当前这辆车，每车 200 公斤。送家里：米菜进厨房，礼品、配件进纸箱；送店里：配件上货架，吃的、礼品进店里储物柜。
- **店里储物柜**：40 公斤，格子窗口和纸箱一样，在店里的背包窗口或右侧面板“库存”页打开；配件放进去直接上货架。
- **礼品**：烟酒茶行（现场付钱）或网购买进背包，再当面送人，不再当场花钱；送店员也一样，从背包里挑（一瓶饮料 ¥5 就行）。

## 4. 我的店

- **租铺子**：开局现金 ¥10,000、没有店，要去「安居房产中介」签约。中介用真实三维街区鸟瞰图展示全部沿街铺面、地铁、住宅楼和城中村路口，可缩放、拖动及直接点建筑选房，挂牌处直接标月租、面积、客流和出租时间；点选后看真实室内户型、地铁距离及签约费用，核对后确认付款。营业中未挂牌的店也显示位置；点选和签约均不自动出行。房源会时不时挂出来、挂一段时间没人租就下架，隔壁五金杂货约 5 个月后空出来。月租看大小和离地铁站远近：小 ¥1,500~3,800、中 ¥4,500~11,000、大 ¥12,000~30,000；签约付首月 + 押金 + 中介费（各一个月，和中介小陈混熟后中介费最多打 5 折）；房东不再送东西，开局货架、收银台和 CPU、显卡改为任务奖励（见“阶段任务”）。**提前签约（坑）**：现租户还没搬走、要“第 N 天才能租”的铺面也能直接签，当场付清首月 + 押金 + 中介费，但要等到那天才交房；房租从签约当天就开始算（每月 1 日照扣“还没交房”的月租），这条只写在确认窗口底部的灰色小字里。交房前不能再签别的铺子；到日子自动交房（搬店时那天才退旧押金、收搬家费）。更多货架、展示桌、操作台可去家具城买，在摆放模式摆好，至少 1 收银台 + 1 货架，摆完第二天才能开业；中型要知名度 ≥ 25、大型 ≥ 60。已有店再签就是搬店（退押金，搬家费 ¥800，库存搬迁、已摆家具收回“我的”，人物仍留在中介）。作弊按钮可直接租下街尾小店回到旧开局。

- **门外的街**：店里能看到门外的人行道和马路，路人来回走、车开过（白天多、半夜少，路灯晚上亮）；顾客从街上走过来进门，买完出门走远。走到门口按 F（或接着往外走）就出门回到街上。

- **顾客**：按分钟生成，在店里能看到他们走到货架前逛、拿货（手里真的拿着盒子，货架这时才少一件）、拿到柜台排队、等你结账；你不来，等到不耐烦（40 游戏分钟）就把货**放回货架**再走。头顶有“想买：xx”和离店原因小字（太贵 / 等太久 / 没货 / 没带现金 / 关门…），收款飘“+¥”。
- **收银**：老板必须站在收银台旁才能结账（按 F，或点气泡 / 右侧“结账”）；不在时顾客头顶写“等你到收银台”，继续排队直到不耐烦。收款码、自助结账平台等升级让顾客更快、甚至自动结账。
- **寻路**：顾客按规划好的路线绕开展示桌（桌角当路点，可见性图 + Dijkstra），不会在桌边来回卡住。
- **库存**：容量以“格”计（小店 40，中 120，大 300）；盒装 1 格（2 公斤）、散件 0.5 格（重量减半），显卡和电源机箱 ×2；盒装更贵、更受信任，可拆包装（不可逆）。这是“后仓”，顾客只买货架上摆着的。
- **定价**：全局加价（0.9–1.6）+ **每件配件单独定价**（“跟随”恢复全局）；盒装再贵 12%。右侧面板“定价”页和货架窗口里都能调（货架上显示售价、市场价、顾客买的概率）。
- **补货与缺货提醒**：每天 9:00 检查库存及在途，低于目标约 40% 时补货；需智能手机及 1788。支持现金底线、房租/工资预留天数、每日预算，并计入近期债务与仓位。钱不足时按缺货程度买可负担的部分；无法执行显示原因，缺货提示区分未设置货架、在途和售罄。
- **货架**：普通 ¥300 / 60 公斤，加固 ¥700 / 100 公斤、后仓 +10 格，重型 ¥1,500 / 160 公斤、后仓 +20 格。每架只设一种货类：六类配件或烟、酒、饮料、点心、水果；在货架前按 F 或库存页设置。未设置为空架，同类多架叠加容量；货物在后仓，货架空了自动补，顾客只买对应货架上的货。
- **营业时间**：“柜台”页可设开门、关门时间（各按 1 小时调，支持过夜营业），默认“不限时”与旧版一致；营业时间外不进客，页面提示现在不在营业时间。随存档保存。
- **鼠标点货架**：店里鼠标指着货架、整机展示桌或装机台，头顶出现名称和“左键查看 / 设置”，左键直接打开对应窗口，和走近按 F 效果一样。
- **货架窗口与展示台**：货架前按 F 查看整盒/散件、各档型号、数量、价签及容量。每张整机展示桌提供两个机位，用库存配件装机后摆售，顾客可直接抱去结账；家具的位置由装修决定，顾客和老板站位随实际摆放更新。
- **装机订单**：顾客下整机单，两天内装好才收全款；拖拽装机小游戏，错装算失误，超时作废并掉知名度。支持预留配件、缺件采购清单、取消退回散件、员工委托装机；实际装机耗时结束才结算。
- **经营报表**：“柜台”页底部按钮，近 14 天营业额（绿）/ 支出（红）柱状图。
- **前期引导任务与奖励**：① 找到安居房产中介租下一间铺子 → 奖励一个货架 + 一个收银台（进“我的”待摆放）；② 去宜居家具城随便买任意一件东西 → 奖励入门 CPU + 入门显卡各一件（直接放进店里库存）；之后是摆家具、设货架、上货、第一单、雇人、买手机、去手机店开收款码。每完成一个任务**强制弹窗**，写明完成了什么、拿到的奖励、下一个任务去哪做什么。左上角任务条右上角“×”可收起，顶栏“任务”按钮（或 T 键）重新打开当前任务说明并显示任务条；暂时没有任务时说明窗口写“暂时没有新任务（已完成 N 个）”。作弊开局 / 老存档自带铺子，跳过前两个任务。
- **阶段任务**：开局只提示租铺，完成当前一步后再推进；开店后逐步接入整机、自动化，企业合同、直供、分店、园区等到实际条件满足才提示。左上角仅显示当前任务和「怎么做」，详细说明只含这一步的地点、操作与进度；所有现有和后续教学均不提供快捷前往、自动寻路或代开页面，由玩家自行移动、操作。没有章节目录、总步数、手选跳步和已完成回看；开场不自动打开教学窗口，无当前任务时隐藏任务条，顶栏“任务”按钮始终保留。内部共 23 个节点，实际完成和已派发状态随存档保存；旧版手选与暂缓标记自动清理，提前完成的里程碑不遗漏，搬店或关闭业务不抹去完成历史。页面只展示当前任务的提示，未来任务不会因浏览页面提前出现。教学不强制赊账、买房或填满园区。三年目标仍是独立面板。
- **店铺升级（只能去店里买）**：店里“升级”页只列清单——价格、在哪买、还差什么条件、已装好的标“已装好”，没有购买按钮。收款码、自助结账平台、监控在**手机店**买；招牌灯箱、空调在**宜居家具城**买，买了当天装进自己店里。收款码（要先有智能手机）、招牌灯箱、空调、监控；店面大小去房产中介换铺子，**手机去手机店买，更好的货架去家具城买**（普通货架 ¥300 / 60 公斤；加固货架 ¥700：100 公斤、后仓 +10 格；重型货架 ¥1,500：160 公斤、后仓 +20 格），**自助结账平台可在知名度 8、拥有收款码后花 ¥4,500 购买**（第 365 天“站稳一年”目标达标也会赠送）。老存档里已经买过的手机 / 货架扩容 / 自助结账照样生效。
- **雇人**：贴招聘，次日有应聘者，日薪，收银与装机两个岗位可分别排班；员工在老板在场时也收银，培训后可在空闲时装机，专职装机员与收银员可同时工作。
- **其它面板**：摆放店里家具要歇业装修一天；“我的”显示状态；“行情”显示新闻和价格指数。
- **家具摆放预览**：家具保留原材质与配色，可放时绿色边缘发光，不可放时红色边缘发光，右侧说明原因；地面显示空心占地框。家中、店内、墙面家具与拿起旧家具都适用，放下或取消后轮廓清除。

## 6. 行情

新闻 → 三个宏观指标（币圈热度、AI 需求、新品周期）→ 六个品类价格指数（0.6–1.8）；第 9 天固定矿潮头条，第 19 天新一代处理器。档口老板和人脉会私下透露“涨 / 跌”小道消息，有真有假，5 天后对账并显示每个人的应验率。

## 7. 人物与立绘

- **9 位固定人物**：老张（熟客，中学老师）、李姐（房东）、老周（电子市场老货商）、阿杰（隔壁手机店老板）、老李 / 阿王 / 钱姐 / 老孙（四家档口老板）、小林（发小）。每人有 0–100 的交情，靠事件选择、送礼（每人每 5 天一次）、约出去玩来涨，到门槛有实际好处（客流、房租、进货价、救急、进价折扣与额度）。
- **约出去玩**：约晚上 19:00 或周末白天 10:00（交情 ≥ 15，对方不一定答应），到点弹出选择去哪玩，花钱花时间，涨交情，对方爱的活动涨 1.5 倍；放鸽子、错过会掉交情。
- **立绘与交谈**：9 位人物各有一张 AI 生成的半身立绘（`Assets/Resources/Portraits/{id}.jpg`，干净的 2D 游戏角色插画风（介于写实动漫和 Q 版卡通之间）：正常头身比、每人脸型 / 眼睛 / 眉形 / 痣疤等面部特征各不相同（不只靠服装发型区分）、有色轮廓线、明亮平涂只留一层柔和阴影、每人一种淡彩底色加一个平涂圆，可整体替换）。档口窗口改成**左边老板立绘 + 右边货品**，点人物后出现一组**选项**（灰着的写明解锁条件）：随便闲聊（每天一次、10 分钟、交情 +0.8，涨到 50 为止）、赠送礼品、聊聊行情（递烟，档口老板才有）、聊聊人生（交情 30 / 50 / 70 各解锁一段过去的故事，每天一次，交情 +2.5）、交心打听内幕（交情 60 解锁，档口老板，不用递烟、消息针对已排定的变化，实际价格仍受其他因素叠加影响、一周一次）、发出邀约、砍价（在档口里）。目标面板“认识的人”有小头像和“交谈”按钮。
- **普通店主**：烟酒茶行（老胡）、手机店（小唐）、家具城（小赵）、农贸市场（王婶）、车行（老马）也用同一套模板：左边立绘 + 一句话（点头像换一句），右边原来的商品内容。他们没有交情系统。

## 8. 随机事件与三年路线

- **随机事件**：每天 11:00 约 55% 概率触发（第 2 天起，同类有冷却）：城管检查、熟客推荐、停电、小偷、学生团购、同行低价竞争、捡到钱包、朋友请吃饭、借钱、差评、发传单、感冒等 12 个；弹出后必须选一项。
- **路线**：第一个月（第 30 天，身家 ≥ ¥8,000 且雇过人）→ 站稳一年（第 365 天，身家 ≥ ¥30 万、知名度 ≥ 30）→ 有名号的店（第 730 天，身家 ≥ ¥150 万且在中介换到中型以上）→ 三年之后（第 1095 天出结局：勉强糊口 / 稳稳当当 / 电脑城新星 / 电脑城大亨）。没过检查点只会让店租 +10%。
- **经营压力**：每月 1 日扣房租（店租按租约，街尾小店 ¥1,500；出租屋 ¥450；随交情和检查点变化；没店不扣店租）；现金连续 3 天为负破产。
