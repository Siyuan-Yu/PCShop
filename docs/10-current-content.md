# 现有内容总览（2026-10-30）

这份文档把游戏**目前已经做进去**的内容按系统整理在一起，方便一次看全。具体怎么试玩、验收什么见 [`07-vs1-acceptance.md`](07-vs1-acceptance.md)；开发进度和历次改动记录见 [`08-current-status.md`](08-current-status.md)。数值都是占位，没做过平衡。

项目：Steam 游戏 PCShopSell（Unity 2022.3.6f1、URP），玩家在城中村经营一家小电脑店，三年为一个完整周期。

## 1. 世界与操作

- **场景**：商业街（18 家店 + 安居房产中介 + 顺风车行（原明亮眼镜的位置，在老王修鞋旁边）；开局没有自己的店，街尾空铺最小最偏也最便宜；商业街的马路是连接路和城中村路口的两倍宽）、地铁站、城中村出租屋、约 2 公里外的电子市场（4 个档口 + 地铁站），另有家具城、农贸市场、烟酒茶行、手机店。
- **移动**：街上 WASD 自由走（沿街道范围滑动，进不了楼里），右键拖动 / Q E / V 控制视角；走到门口按 F 进门；底栏“快捷前往”可自动走过去（步行沿店门那侧人行道走，走到目的地门口才进门；出门也站在门口）；店内 WASD 走动。
- **人物动作**：家中、店内和街上的移动有交替迈步、屈膝、摆臂和身体起伏；顾客与路人等共用动作。停下或撞墙后收步，骑车不踏步，暂停冻结姿势，进出场景不误播；衣服和裤腿随关节一起运动。
- **步行速度**：仅街道上的玩家手动/自动步行画面速度降低 50%，走路动作同步放慢。室内恢复原速：店内 4.8、家中 2.6 单位/秒；载具和 NPC 不变。游戏路程折算仍为 49 米/分钟，500 米约 11 游戏分钟；打车约 24 公里/小时、小电驴 15、三轮车 12。街上的载具画面速度和步行一样减半（交警追车速度同比减半）。
- **时间**：1× 站立经营时每游戏分钟约 0.23 秒，一天约 5.6 分钟；支持暂停、1×/2×/4×/8×。出行按路线距离和交通方式折算游戏分钟，不保证与站立的现实时间速率一致；打开面板自动暂停，店内“柜台”页除外。
- **载具**：步行（6 格）、打车（15 格，按里程计费）、小电驴 ¥1,800（10 格）、三轮车 ¥2,500（40 格，城里不让上路，会被交警追）、地铁 ¥3。
- **交警**：骑三轮车时 8:00–20:00 有概率上岗，视线扇形可见，被看到会追，追上罚 ¥200 并可能扣车。
- **街上的人都是真实街坊**（`Residents`）：23 个有名有姓、有立绘的人按作息出门。9 个是店里的人（家具城小赵 / 周敏 / 阿旺、农贸市场王婶、烟酒行老胡、手机店小唐 / 小乐、车行老马、中介小陈），上班前从地铁站或城中村路口走到店门口进去，下班再走出来；7 个在街上其他小店上班（修鞋老王、理发阿芳、奶茶小雨、面包刘师傅、花店晓晴、药房何药师、快餐胖哥），上班间隙会出来走走；7 个是住附近的人（外卖骑手小吴、周大爷、张阿姨、大学生小宇、程序员陈工、宝妈吴姐、中学生乐乐），按时段在街上逛。白天人多、半夜街上没人。走近（约 1.3 米）提示“和小赵（家具城导购）聊聊”，按 F 打开和店员一样的对话框：立绘、熟络度、随便聊聊、送东西、听他讲讲自己的事（每人三段），另外能“打听点街上的事”。熟络度和在店里见到他时是同一份。
- **人脉图**：顶栏“人脉”按钮（“目标与人脉”里也有入口）。网状图，“我”在中间，认识的人按圈子分扇区（朋友熟客 / 电子市场 / 商业街店铺 / 街坊）；越熟离你越近、连线越粗越亮；他们彼此认识（老板和店员、老姐妹、老街坊……）也连细线。点头像看详情：熟络程度、在哪找他、交情好处、他认识的人；有联系方式的人能直接“联系他”。只显示见过或聊过的人。
- **Esc**：关闭最上面一层窗口。

## 2. 出租屋与生活

- **真实房间**：开局和回家都进入一间破旧的出租屋，WASD 在屋里走，走近家具头顶出现提示后按 F：床（睡觉/小睡）、衣柜（换衣服，镜子里看自己的外观）、电饭锅（实时煮饭，按真实时间煮好才能吃）、纸箱（家里的格子储物箱，背包里的东西都能放，上限 20 公斤）、塑料凳 / 沙发（坐下）、门（出门）。
- **家具**：只能买后自己摆（家具城当天拿，网购 2 天到）。家具城和农贸市场一样，先选“装进背包 / 叫车送到家里”，再一件件买；背包装不下只能叫车。叫的是面包车，每辆最多 200 公斤，面板显示当前这辆已装多少、还能装多少，装满了自动叫下一辆、每辆各收一次运费，二三十分钟送到家。床、空调、窗帘、台灯等决定睡眠恢复和水电。
- **衣着**：衬衫 / 夹克 / 西装（魅力 +2/+4/+7），只能网购，到家后在衣柜换；人物外观会跟着变。
- **吃饭**：电饭锅焖好饭后头顶一直跳着闪“饭好了！”，直到取完；饭可以吃掉或装成饭盒进背包（每盒 0.5 公斤）。每天 12:00、18:30 饿两次：在家吃锅里的，出门吃背包里的饭盒，没有就饿着；可在“我的”中主动开启智能手机送餐（¥25/餐，默认关闭），饿到 0 会掉健康。
- **生存**：饥饿、精力、健康；只能在家 18:00–8:00 睡觉或小憩；凌晨 4 点不睡会晕倒；23:00–4:00 屏幕正中间出现红色横幅“太晚了，该睡觉了！”，显示离晕倒还有多久、去哪睡，越晚闪得越快；横幅不挡点击、不暂停游戏。健康太低住院。
- **修电器**：家里坏的东西不能自己修，只能“约师傅”：预付、不退款，师傅会真的上门，日程里有记录和提醒；师傅进屋修东西期间（约 30 分钟）玩家不能出门，可在“我的”里一键等到修好。
- **每日“昨日营业”小结**：零点弹出进店、成交、营业额、走了几个人及原因，并给一句建议。

## 3. 手机、背包、日程

- **按键机 vs 智能手机**：新游戏只有按键机，只能打电话、发短信（短信常没人回）；去手机店 ¥800 买智能手机，在应用商店下载 app（网购、聊天、1788；应用商店、通讯录、日历自带）。
- **日程**：没智能手机时是写在笔记本上的最近几天安排（自动记录，没有提醒）；有智能手机是真正的日历，能一直往后看，约会 / 师傅上门前 30 分钟提醒。
- **背包**：格子背包（B 键开关），有承重（步行 12 公斤），礼品、家具、食物、饭盒都放这里；家里纸箱窗口和背包是同样的格子形式。背包里的东西不会自己消失，只有在自己的店或家里才能点“一键全放到店里 / 家里”。
- **买了怎么拿**：农贸市场、烟酒茶行、档口、家具城都可以选“装进背包”或“叫车送货”；叫车时用“送到 ▼”下拉框选家里或我的店里（档口默认店里、其他默认家里），按路程收运费，同一家店接着买先装当前这辆车，每车 200 公斤。送家里：米菜进厨房，礼品、配件进纸箱；送店里：配件上货架，吃的、礼品进店里储物柜。
- **店里储物柜**：40 公斤，格子窗口和纸箱一样，在店里的背包窗口或右侧面板“库存”页打开；配件放进去直接上货架。
- **礼品**：烟酒茶行（现场付钱）或网购买进背包，再当面送人，不再当场花钱；送店员也一样，从背包里挑（一瓶饮料 ¥5 就行）。

## 4. 我的店

- **租铺子**：开局现金 ¥10,000、没有店，要去「安居房产中介」签约。中介用真实三维街区鸟瞰图展示全部沿街铺面、地铁、住宅楼和城中村路口，可缩放、拖动及直接点建筑选房，挂牌处直接标月租、面积、客流和出租时间；点选后看真实室内户型、地铁距离及签约费用，核对后确认付款。商业街的店都要走到门口（门前人行道 3 米内）才能按 F 进去，站在马路中间不行。营业中未挂牌的店也显示位置；点选和签约均不自动出行。房源会时不时挂出来、挂一段时间没人租就下架，隔壁五金杂货约 5 个月后空出来。月租看大小和离地铁站远近：小 ¥1,500~3,800、中 ¥4,500~11,000、大 ¥12,000~30,000；签约付首月 + 押金 + 中介费（各一个月，和中介小陈混熟后中介费最多打 5 折）；房东不再送东西，开局货架、收银台和 CPU、显卡改为任务奖励（见“阶段任务”）。**提前签约（坑）**：现租户还没搬走、要“第 N 天才能租”的铺面也能直接签，当场付清首月 + 押金 + 中介费，但要等到那天才交房；房租从签约当天就开始算（每月 1 日照扣“还没交房”的月租），这条只写在确认窗口底部的灰色小字里。交房前不能再签别的铺子；到日子自动交房（搬店时那天才退旧押金、收搬家费）。更多货架、展示桌、操作台可去家具城买，在摆放模式摆好，至少 1 收银台 + 1 货架，摆完第二天才能开业；中型要知名度 ≥ 25、大型 ≥ 60。已有店再签一间就是**多开一家**（自营店不设上限：我的电脑店 / ·二店 / ·三店 / ……，每家各有库存、货架摆放、员工、升级、营业时间、订单和补货目标，现金和知名度共用；人进哪家店就经营哪家，人不在的店要有员工在班才开门；每月每家各扣月租；网购、直供送到下单那家店，叫车可以选送到家里或任意一家店）。**没有一键搬店**：想换地方就签新铺子，打电话叫货车把货搬过去，再回旧店在“升级”页退租（要在店里、货搬空、没有未交付装机单和在途的货；家具收回“我的”，员工辞退，押金退回；主店也能退，下一家当主店；最后一家不能退）。**买东西先进购物车**：档口、家具城、烟酒茶行、农贸市场窗口最上面有分类标签（家具城：家里用 / 店面设施 / 店里装饰 / 店铺设备 / 寄存的货；烟酒：烟 / 酒 / 饮料点心；农贸：米 / 菜蛋肉 / 水果；档口按配件类别），货品列表占满窗口剩下的高度；点“加入购物车”不扣钱；下方购物车左栏“叫车送”、右栏“装进背包”，点“放进背包”就自己背（点一下 1 件，按住放多件；也能拖过去，超重了点“改叫车”挪回去），剩下的按总重算几辆面包车（每辆 200 公斤），选好送到哪，点“结账”一次付货款和运费。**手机叫货车**：通讯录里的“货车司机老蔡”随时能叫，把身上的东西（在家还有厨房、纸箱，在自己店里还有后仓和储物柜）拖进装货单，选好送到家里或哪家店，出发时付运费；买错送到家里的配件就这样送去店里。**作弊工具只在 Unity 编辑器里有**：顶栏最左边的“作弊”按钮，可加钱、跳过找铺子（直接租下街尾小店回到旧开局）、拥有智能手机、完成当前任务、加知名度、所有人交情 +20、时间往后拨、直接打开经营总览；打包出来的游戏里没有这个按钮（`GameUi.Cheats.cs` 整个文件在 `#if UNITY_EDITOR` 里）。开局窗口和菜单里不再有作弊选项。

- **门外的街**：店里能看到门外的人行道和马路，路人来回走、车开过（白天多、半夜少，路灯晚上亮）；顾客从街上走过来进门，买完出门走远。走到门口按 F（或接着往外走）就出门回到街上。

- **顾客**：按分钟生成，在店里能看到他们走到货架前逛、拿货（手里真的拿着盒子，货架这时才少一件）、拿到柜台排队、等你结账；你不来，等到不耐烦（40 游戏分钟）就把货**放回货架**再走。头顶写着点名要的具体型号（如“想买 星耀 RX 660”，货架上有这款 / 没这款但同类有几件 / 这类一件都没有），没有这款时会退而求其次挑同类别的；还有离店原因小字（太贵 / 等太久 / 没货 / 没带现金 / 关门…），收款飘“+¥”。
- **收银**：老板必须站在收银台旁才能结账（按 F，或点气泡 / 右侧“结账”）；不在时顾客头顶写“等你到收银台”，继续排队直到不耐烦。收款码、自助结账平台等升级让顾客更快、甚至自动结账。
- **寻路**：顾客按规划好的路线绕开展示桌（桌角当路点，可见性图 + Dijkstra），不会在桌边来回卡住。
- **库存**：容量以“格”计（小店 40，中 120，大 300）；盒装 1 格（2 公斤）、散件 0.5 格（重量减半），显卡和电源机箱 ×2；盒装更贵、更受信任，可拆包装（不可逆）。这是“后仓”，顾客只买货架上摆着的。
- **定价**：全局加价（0.9–1.6）+ **每件配件单独定价**（“跟随”恢复全局）；盒装再贵 12%。右侧面板“定价”页和货架窗口里都能调（货架上显示售价、市场价、顾客买的概率）。
- **补货与缺货提醒**：每天 9:00 检查库存及在途，低于目标约 40% 时补货；需智能手机及 1788。支持现金底线、房租/工资预留天数、每日预算，并计入近期债务与仓位。钱不足时按缺货程度买可负担的部分；无法执行显示原因，缺货提示区分未设置货架、在途和售罄。
- **货架**：普通 ¥300 / 60 公斤，加固 ¥700 / 100 公斤、后仓 +10 格，重型 ¥1,500 / 160 公斤、后仓 +20 格。每架只设一种货类：六类配件或烟、酒、饮料、点心、水果；在货架前按 F 或库存页设置。未设置为空架，同类多架叠加容量；货物在后仓，货架空了自动补，顾客只买对应货架上的货。
- **营业时间**：“柜台”页用下拉选择开门、关门时间（整点，支持过夜营业），默认“不限时”与旧版一致；营业时间外不进客，页面提示现在不在营业时间。随存档保存。
- **鼠标点货架**：店里鼠标指着货架、整机展示桌或装机台，头顶出现名称和“左键查看 / 设置”，左键直接打开对应窗口，和走近按 F 效果一样。
- **货架窗口与展示台**：货架前按 F 查看整盒/散件、各档型号、数量、价签及容量。每张整机展示桌提供两个机位，用库存配件装机后摆售，顾客可直接抱去结账；家具的位置由装修决定，顾客和老板站位随实际摆放更新。
- **装机订单**：顾客下整机单，两天内装好才收全款；拖拽装机小游戏，错装算失误，超时作废并掉知名度。支持预留配件、缺件采购清单、取消退回散件、员工委托装机；实际装机耗时结束才结算。
- **经营报表**：“柜台”页底部按钮，近 14 天营业额（绿）/ 支出（红）柱状图。
- **前期引导任务与奖励**：① 找到安居房产中介租下一间铺子 → 奖励一个货架 + 一个收银台（进“我的”待摆放）；② 去宜居家具城随便买任意一件东西 → 奖励入门 CPU + 入门显卡各一件（直接放进店里库存）；之后是摆家具、设货架、上货、第一单、雇人、买手机、去手机店开收款码。每完成一个任务**强制弹窗**，写明完成了什么、拿到的奖励、下一个任务去哪做什么。左上角任务条右上角“×”可收起，顶栏“任务”按钮（或 T 键）重新打开当前任务说明并显示任务条；暂时没有任务时说明窗口写“暂时没有新任务（已完成 N 个）”。作弊开局 / 老存档自带铺子，跳过前两个任务。
