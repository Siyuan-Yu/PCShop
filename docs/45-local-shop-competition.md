# 同类店铺商圈分流（2026-11-03）

为了限制在同一地点密集开设同类分店，每间店现在有一个半径40米的圆形商圈。初始半径参考当前地图相邻铺面约15—20米的间距，约覆盖沿街左右各两间；不同街段密度和对街店面会使圈内实际数量不同。

## 计算规则

- 从店铺实际入口取圆心，按平面直线距离计算；距离等于40米也算在内。不是道路行走距离，也不是方形区域。地图距离缩放统一换算为游戏内米。
- 统计圈内已接手的同类型自营店，包含本店。1家保留原客流，2家各保留自己的1/2，3家各保留自己的1/3，4家各保留自己的1/4，以此类推。
- 每家店单独统计自己的圆。A只挨着B，B同时挨着A和C，C只挨着B时，A/C保留1/2，B保留1/3；不会沿连锁邻接关系把远处同类店无限纳入。
- 不同店型、未租空铺、待交付铺面、背景NPC商店及专用场馆不参与本轮自营零售分流。已接手但临时关门、未装修完的同类店仍计入，避免通过开关门绕开规则。
- 新租、退租、搬店、转型和读档后按当前店铺状态计算，不需等待下一天，不新增存档字段。已到店顾客不会因新店开张而被清走。

本轮以已接手的自营店为范围，针对玩家集中开同类分店的问题；原有城市竞争事件和其他经营修正仍保留。

## 实际经营与直观数据

普通零售的实际来客速率乘以1/N。餐馆和二手店的专用来访间隔按同样的N拉长，使用既有分钟计时精度；已排定的下一次来访不追溯取消，之后按新间隔安排。改类之后的顾客偏好和商品购买意愿继续按原规则运行。

地段本身的“预计每日经过人数”不因玩家多开店而改变，也不因此降低地段租金。界面另列“分流后预计每日客流”，等于地段预计人数÷N，显示时取整数，模拟保留比例精度。经过人数不等于进店或成交人数。

例如地段预计每天300人，同类自营店2家时该店分流后约150人，3家时约100人。地段本身更好的店仍可能比同一商圈里的小店分到更多人，因为每家都按自己的基础人数除以N。

## 查看范围

- 中介地图点击商铺后，在真实街景上显示橙色40米圆圈，右侧显示同类店数量、保留比例和分流后人数。
- 店铺柜台增加“查看商圈”按钮，餐馆及二手店同样有入口。打开后能看到本店、附近自营店标记和完整的范围圈，支持拖动和滚轮缩放。
- 空铺可切换试算店型，展示假设在此开店后的本店分流比例，不会签约或改变现有店型。
- 圆圈由同一入口位置和半径投影到地图，缩放、拖动时随地图更新；图层不拦截地图操作。店内查看时临时渲染街景并恢复原场景可见状态。

## 实现和验证

`GameSession.ShopCompetition` 缓存静态位置的邻店集合，每次查询只遍历已建店铺状态；不会每帧寻路，也不持续扫描全图或重新创建圆圈。圆圈使用96段线，只在打开窗口或改变地图视角时更新。来客倍率通过 `ShopSimulation.CompetitionFactorOf` 读取，专用店型使用同一个计数。

相关回归71/71通过，包含14项新增商圈用例。验证结果见[测试摘要](validation/45-competition-results.txt)及[测试报告](validation/45-competition.xml)。实际图形检查见[店内商圈](previews/competition/shop_competition_three.png)、[720p商圈](previews/competition/shop_competition_three_720.png)、[中介地图](previews/competition/agency_competition.png)、[720p中介地图](previews/competition/agency_competition_720.png)。
