# 成长主线与关键支线节点配置

版本：2026-11-03.1

主线为节点配置；尚未接入完整任务执行器。公司上市、发行人股价和项目履约凭据仍需对应机制。

这里记录内容配置，不代表所有节点已经能在游戏中完整触发。所有行业共用主线，行业教学另行处理。接入任务执行器时，应从真实交易、赴约、物品交付与经营结算生成凭据；查看配置、点开对话或单纯加好感不得伪造履约。

## 当前阶段分配

### 城郊 → 社区

阶段ID：`district.community`；模块：community_entry

- 城郊已有5家实际开业门店（`OpenDistrictShops` / `suburb`）
- 手上现金至少100万元（`Cash` / `player`）

完成后：获得社区商铺洽谈资格；租金、押金照常支付。

### 社区 → 公园

阶段ID：`district.park`；模块：community_cooperation、rare_model、brand_listing

- 社区至少6家实际开业门店（可调为7家）（`OpenDistrictShops` / `community`）
- 资产门槛暂定3000万元；建议净资产口径，待平衡确认（`NetAssets` / `player`）
- 已成立自己的品牌/公司（`OwnBrandFormed` / `player`）
- 自己的品牌/公司已上市；购买别人的股票不算（`OwnBrandListed` / `player`）

完成后：任帆与沈远共同引荐，开放公园商铺机会。

### 公园 → 花园

阶段ID：`district.garden`；模块：garden_project、industry_dominance

- 一个完整已结算月，同一行业的全部自营门店营业收入达到1亿元；不同业态不可合并（`ClosedSectorMonthlyRevenue` / `one_owned_sector`）
- 对应自有上市品牌股价达到100元（暂定值，需结合发行股数平衡）（`OwnSharePrice` / `same_issuer`）
- 次月才发起邀约；以结算月标记去重，不在月中预支触发（`FollowingMonth` / `qualified_month`）

完成后：完成合作后开放花园经营资格；不赠送房产或保证收益。

## 配置迁移规则

`CreatePlan(listingAtGarden, dominanceAfterGarden)` 可将品牌上市条件移至花园阶段，或将行业月收入/股价条件移至花园之后的终章。默认两项均为 false。每次调用返回独立配置；节点和事实ID不变。未来任务存档应独立保存已达成事实、节点完成记录和已发放资格，变更阶段映射不得清空既有进度或重复发奖。

当前尚无这套新主线的执行进度字段，因此本轮没有声称完成其存档迁移器。旧有四条人脉故事仍按原系统运行，不被这些配置覆盖。
