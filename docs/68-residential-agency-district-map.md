# 住宅与商铺中介共用片区地图

每家中介仍只负责自己的片区。住宅与商铺页现在使用相同的片区建筑集合、默认取景、拖动范围和镜头状态，切换页签时保留当前位置与缩放；住宅页更换为住宅房源标记，只接受本片区住宅的点击。

之前住宅页单独收集住宅与中介，并把分散的住宅一起框入镜头，导致画面远于商铺页。现在两页统一沿用商铺页按本片区可交易商铺和中介建筑计算的取景，不再因为切到住宅页而拉远镜头。街道、商铺和住宅保留为同一张地图的背景，其他片区房源不参与选择。

住宅页补齐“定位中介”和缩放倍率，保留“本片区”复位与“放大这套”。边缘住宅仍可通过拖动或放大所选房源查看。换到另一家中介时，镜头重置为新中介负责的片区，旧住宅选择也会按该片区重新确定。

租住、自住购买、带NPC住户购买产权、原片区交易限制及住房存档规则不变。看房、切换页签、缩放与定位不移动玩家，不扣钱。

四个片区检查两页默认相机位置和尺度一致、住宅点击范围正确、房源可定位；实际UI页签检查镜头连续与更换中介后的复位。相关住宅交易与存读档一并回归，结果见[验证记录](validation/68-residential-agency-map-results.txt)。按用户要求未截图或查看游戏画面，未打包或提交GitHub。
