# 初始主菜单与中日英三语

## 当前范围

启动游戏统一进入主菜单，提供开始游戏、加载存档、设置、关于、帮助、退出。由游戏中返回时另有继续游戏。

本阶段三语覆盖主菜单、游戏暂停菜单、设置、存档选择、帮助、关于、确认/错误提示和开场说明。**游戏内经营界面、任务、物品名、对话和经营事件尚未全面翻译**，不能把这版称为全游戏三语完成。

主菜单没有复制经营、员工和背包等游戏内功能；设置统一放语言、音效开关、音量滑杆。三种语言直接展示原生名称“简体中文 / 日本語 / English”，避免切换后找不到原语言。

## 行为

- 主菜单暂停会话并隐藏游戏 HUD，浏览菜单、设置和帮助不推进经营时间。
- 开始游戏创建新局，已有存档文件保留；替换本次尚未保存的游戏之前有确认。
- 加载页分别显示手动/自动存档及保存时间，空存档按钮禁用；继续沿用备份恢复和原文件保留机制。
- 读档失败留在菜单并显示当前语言的提示，不覆盖当前会话或坏档文件。
- 游戏内 Esc 打开统一游戏菜单，可保存、加载、打开设置/帮助/关于、返回主菜单或退出。
- 返回主菜单保留本次会话，可直接继续；退出和开始新局会说明未保存进度的后果。
- 语言即时刷新当前菜单与设置页，保存到独立的 PlayerPrefs 偏好，读档不改变语言。
- 菜单窗口随视口重新适配，修复启动首帧和运行中更改窗口尺寸后缩放不正确的问题。

## 文本与字体

三语文本在 `Assets/Resources/Localization/menu.json`，共 61 个稳定键。`MenuLocalization` 加载文本、格式化占位符并保存 `zh-CN / ja / en` 偏好；未知偏好回退简体中文。

字体继续沿用现有系统字体机制，日语优先 Yu Gothic UI、Meiryo 等，中文优先微软雅黑。已经在本机截图中检查中日英显示；随游戏携带的完整 CJK 字体资源仍属于后续发布工作。
