# 餐馆饮料加购（2026-11-02）

餐馆顾客对店内饮料的购买意愿提高，并实际接入堂食结账。此前餐馆关闭普通零售客流，货架即使摆了饮料，也不会通过餐馆订单售出；本次保留专用点餐流程，补上饮料加购。

## 当前规则

- 餐馆饮料购买意愿增加20个百分点，叠加原售价与有效销售员加成，总概率最高100%。提高售价仍会降低购买意愿；其他店型和非饮料商品无此加成。
- 沿用现有饮料货架分类：瓶装可乐、一箱饮料。按原有商品单位整件销售，不自动拆瓶；酒、点心、电脑配件不参与。
- 每笔堂食订单吃完结账时，仅从本店实际陈列的饮料中随机选一种，尝试加购一件。没有饮料货架、无陈列数量或缺货时不购买；后仓独有商品不直接出售。
- 成交立即扣除一件真实库存，以商品当前确认售价记入本店经营收入，账本记录商品、数量和订单来源，餐馆累计收入同步增加。堂食单数仍只加一次。
- 未吃完、等候离开、烧糊的订单不触发加购；多桌同时结账逐单检查库存，最后一件不会超卖。
- 既有 `Eating → Completed` 状态转换保证每单只尝试一次；完成后存读档不重复扣货、抽取或收款，无新增存档字段。旧存档尚在用餐的订单在完成时适用新规则。

## 操作与界面

库存页显示餐馆饮料加成提示。先将饮料放入店内库存，再摆放并配置“饮料”货架；仅有空饮料架和后仓处理器时，仍没有饮料可卖。

餐馆“定价”页保留菜单和餐馆操作，增加已陈列饮料的价格、购买意愿及调价入口。弹窗实时显示成交使用的购买概率和“餐馆+20”；点击确定后保存。没有陈列饮料时给出上架提示，销售员的额外加成在提示中说明。
