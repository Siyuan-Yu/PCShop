# PETSHOP 当前玩法与街坊小店界面交接

更新于 2026 年 11 月 23 日。工程名为 **PCShopSell**，Unity 版本为 **2022.3.6f1**。本文以 `main` 当前源码为准，归档自 `bdf22d7` 以来的改动。各系统的完整底座见 [全量玩法与工程交接](145-current-game-and-store-management-2026-11-19.md) 和 [开店、住宅及活动更新](149-current-gameplay-and-handoff-2026-11-22.md)。

## 湖城与游戏内容

- 湖城按城郊、社区、公园、花园推进。玩家在出租屋开局，做饭、租铺、装修、进货、完成首单并招聘。此后通过经营、人物引荐、实际展会和企业订单履约开放街区。城郊阶段需开业五家城郊门店、自有现金达到 ¥1,000,000，并结清贷款。第一章 WebGL 试玩到此收束，单独存档，可留在城郊继续经营。[主线及区域开放](story-and-district-progression.md)
- 完整版有电脑、宠物用品、服装、模型手办、二手旧物、餐馆及专用场馆等业态。各店使用独立库存、岗位、到货记录和账目。采购支持批发、网购、直供、员工固定清单及按库存补货，配送按地址、运力和实际到货结算。住宅支持租购、设主住处、分地址存放、装修及居家工作台。[门店经营及采购](145-current-game-and-store-management-2026-11-19.md) · [住宅与商铺](149-current-gameplay-and-handoff-2026-11-22.md)
- 人物有工作、住处、行程、喜好与关系。可邀约吃饭、唱歌、散步、钓鱼或参加球类活动。品牌、联展、MCN 合作与企业竞标使用真实库存、订单和付款。赛车提供登记、改装、维修、车库、跨区调车、练习和正式赛事。[人物、活动、品牌与赛车](145-current-game-and-store-management-2026-11-19.md#人物活动品牌与赛车)
- 随机事件按条件发生，有 120 项随机事件及两项独立流程配有开场或首次通知 CG。城市与室内沿用微缩 3D 场景，人物立绘、地图、报表和活动使用对应系统的数据。[事件明细](100-random-event-details.md) · [事件 CG 覆盖](142-event-cg-coverage-2026-11-19.md)
- 常用操作为 `WASD` 或方向键移动、`F` 交互、空格暂停或继续、`Tab` 收起功能栏。`B` 打开背包，`R` 打开任务，在家具预览时用于旋转。顶栏还有手机、联系人、日程、经营、物价、股市、品牌和赛车。底栏可选出行方式、快捷地点和货车。[操作与试玩范围](124-current-game-content-2026-11-17.md)

## 开场、签约与招聘

- 新游戏接入裁员开场 CG，画面表现公司业务受挫、裁员、离职和主角来到出租屋重新开始。影片以办公室、道具和第一人称取景为主，为日后自定义主角外貌留出空间。可按 `Esc` 或点跳过。影片缺失、解码失败或播放停滞时回到开场教学。出租屋里的饥饿引导有独立插图。[游戏内影片](../Assets/StreamingAssets/Opening/OpeningCg.mp4) · [影片预览](../output/opening-cg-preview/opening-cg-v02.mp4) · [接入代码](../Assets/Scripts/Game/UI/GameUi.OpeningCinematic.cs)
- 云帆技术服务公司是湖城内有实际地点的企业，并进入游戏内交易所。行业为软件服务，主营企业管理软件、实施交付和运维。证券新闻涉及签约、验收延期、云资源成本、交付标准化和缩减低毛利项目。开场 HR 在后续街区重遇仍是叙事设计项，当前源码未确认已接入专属重遇剧情。[上市公司配置](../Assets/Scripts/Core/Session/CityAssets.cs) · [证券新闻](../Assets/Scripts/Core/Session/GameSession.StockMarket.cs)
- 普通商铺签约成功回执显示本次实付、首周租金和押金，提前签约时补交房时间。签约后可选择店型。确认租铺任务完成后，高亮家具城任务入口，随后购买设施并装修。教学暂停与高亮使用界面已有按钮。
- 首单既可以是普通零售结账，也可以是符合条件的宠物寄养接单。柜台教学识别已到店待办理的寄养单。点结账或接待寄养后，角色走到收银台附近再执行，抵达时重新核对订单。
- 首店招聘在「员工」页高亮「贴招聘告示」。每次告示安排次日 09:00 到店的四名应聘者，18:00 离开。贴告示后先营业到打烊并处理收尾，之后回家休息。休息完成后任务按招聘时间切到前往店铺或等候。应聘者离开后可重贴告示。教学中可以在允许的岗位间切换，随后确认聘用。
- 餐馆开店分工需要服务员、厨师和进货员，宠物店需要收银员、进货员和饲养员。普通零售店需要收银员、进货员，二手旧物店需要收银员和鉴定岗位，专用场馆引导安排值守。采购教学从进货员所在行进入。
- 买手机、买小电驴、前往银行的阶段触发均最早在相应前置完成的次日 08:00。买手机和买车的现金门槛分别为 ¥1,600 与 ¥3,600，买车前还要开通收款码。第二家店的门槛按当前符合条件的最低签约账单的两倍计算。[开店教学](../Assets/Scripts/Core/Session/Quests.Opening.cs) · [后续经营任务](../Assets/Scripts/Core/Session/Quests.Growth.cs)

## 经营、生活与场景改动

| 系统 | 当前规则 |
| --- | --- |
| 玩家在店 | 所在自营门店进店客流系数与有效口碑乘以 1.2。柜台显示「玩家在店 +20%」，基础口碑与实际经营数据照常结算。 |
| 货架与装修 | 小、中、大店分别最多 6、12、20 个货架。旧档可保留已有的超额货架，达到上限时限制继续增加。住宅与商铺分别有装修面板，完成按钮固定在下方。选中家具后，鼠标移动和 `R` 旋转都反映在当前摆放预览。 |
| 宠物用品 | 商品基础零售倍率由 1.5 调为 1.8，批发倍率为 1.5。主人实际到店后柜台才显示送养、探望或接回单。订单页显示下次结算倒计时和照料状态。每名在岗饲养员能照顾四只宠物。 |
| 寄养收款 | 入住收取首周基础价的 30%。约一周后按实际状态计算首周账单，扣除已付预收。之后每周结算该周费用，末周结清后主人接回。存档记录预收、已结周数及下次探望时间。 |
| 餐馆 | 顾客坐到椅子上等餐，送餐后用筷子进食，桌椅之间留出间距。厨房从冰箱取米、配菜和鱼，后仓食材可移入冰箱。各道工序和收款沿真实订单状态推进。 |
| 住处与睡眠 | 在住处醒来的人物从床上躺姿过渡到撑起、坐到床沿、落脚和站立。清醒时饱腹每游戏小时下降 3，睡眠时下降 1。基础清醒精力消耗每小时 3.85，继续乘工作系数。 |
| 食物与钓鱼 | 有期限的食物延长两天，旧批次只迁移一次。冷藏成品继续暂停保质期。每锅只需一条鱼，可从格位选鱼。市售鱼改善餐食效果，需钓获的鱼按鱼种使智力、魅力、动手能力或体能加 1，同锅只生效一次，上限 100。 |
| 员工与采购 | 进货员空闲时站店外门口，外出仍按采购路线。工资详情合并排班时长、加班和预计工资，保留付款记录。固定采购清单支持拖拽排序及边缘自动滚动，越靠前越优先。 |
| 物价与股市 | 物价按类别订阅，历史行情仍可查看。模型异动提醒要求有完成布置的自营模型店。重新打开股市会清空待成交，保留当前游戏会话上次所选的加减股数。 |
| 二手旧物 | 统一调价只处理实际陈列且修复已结束的物品，受每件商品的挂牌价上限约束。 |
| 活动对话与通知 | 话题未走完时显示继续对话的选项，完成后才出现返回或结束动作。长通知按可用区域截断，完整消息可在通知记录查看。 |

## 街坊小店界面标准

全局窗口底色用米灰 `#ECE8DE`，补以深色常驻栏、灰绿选中态、低饱和金棕主按钮和同一套描边。窗口位置、按钮尺寸、数字对齐和滚动规则优先保证可读性。纸面与浅木用在有明确用途的物件上。说明文案集中在需要作选择、行动或处理异常时。静态图用于核对风格和比例，实装状态以 Unity 源码为准。[共用组件](../Assets/Scripts/Game/UI/Ui.cs) · [色彩与材质](../Assets/Scripts/Game/UI/Ui.FlatSkin.cs)

| 界面 | 实装要点 | 定稿参考 |
| --- | --- | --- |
| 任务 | 左上便签用轻纸纹、细边与浅阴影，保留任务名、进度、下一步和可用动作。详情目标沿用同类纸面。 | [任务便签](previews/neighborhood-ui/neighborhood-family-task.png) |
| 合同 | 办公纸承载费用与签名，合计用细分隔线，确认及返回放在纸外。 | [合同纸面](previews/neighborhood-ui/property-contract-paper-comparison.png) |
| 柜台 | 「今日经营」在柜台内容开头，营业额、进店、流失、待结账与口碑组成夹板账页。主人到店后显示带撕边的寄养小票。 | [柜台材质](previews/neighborhood-ui/neighborhood-counter-fixture-comparison.png) |
| 货架 | 保留略偏米灰的浅木原色，压低黄橙色。商品与价签按格位对齐，保留换品类、调价确认与购买意愿预估。 | [浅木色货架](previews/neighborhood-ui/neighborhood-family-shelf.png) |

## 工程、存档与交付状态

- 项目入口是 [Main.unity](../Assets/Scenes/Main.unity)。[Core](../Assets/Scripts/Core) 管理模拟、库存、账本与存档，[Game](../Assets/Scripts/Game) 管理场景、动作和界面，[Resources](../Assets/Resources) 及 [StreamingAssets](../Assets/StreamingAssets) 存放运行时资源。Windows 和 WebGL 的构建入口分别为 `WindowsPlayerBuild.Run` 与 `WebGlTrialBuild.Run`。
- Windows 存档在本机 Unity 的 `LocalLow/KnifeStudio/PCShopSell`（原为 DefaultCompany，改公司名后旧档需手动复制过来） 下。现行源码保存招聘告示和首店教学进度、寄养首周预收、物价订阅、食物期限迁移及鱼餐属性奖励。相关处理见 [存档数据](../Assets/Scripts/Core/Session/SaveData.cs) 和 [旧档读取](../Assets/Scripts/Core/Session/GameSession.Save.cs)。
- 当前 Core 和 Game 已使用 Unity 项目引用做 C# 编译检查。Unity 测试及实机逐页验收尚未进行。验收关注长文、分辨率变化、招聘高亮、采购拖动、寄养主人到店与旧档储物位置。
- 本机现有 Windows 目录为 `Builds/Windows-20261122-233004/`，早于街坊小店全局改造。本次归档版本以源码、运行时资源、预览、测试代码和文档为准。发布包和 Unity 生成缓存沿用仓库忽略规则。
