# 固定地图预生成与共享模型

更新日期：2026-11-18。

后续累计交接和最新验证边界见[第133篇](133-current-project-handoff-2026-11-18.md)。本篇的资源体积与生成验证记录按其当时版本理解。

## 无效旋转兼容修正

修正全零四元数导致的 `Quaternion To Matrix conversion failed`。Unity四元数的相等运算按旋转方向点积判断，不能用 `rotation == default` 检测全零。现在生成端和读取端按模长检查，零值、非有限值改为无旋转，非单位值规范化；新记录默认使用单位旋转。旧缓存读取也经过兼容处理，构建前源码指纹变化会刷新缓存，生成后额外检查旋转记录有效性。本次仅完成脚本编译，尚未重新生成地图或实机验证报错消失。

## 行为

Windows 和 WebGL 试玩沿用现有构建入口。构建前自动检查地图资源；缓存缺失或相关源码、资源发生变化时，先在编辑器中生成地图，再构建游戏。普通开始游戏通过异步资源读取加载预生成地图，保留进度条、阶段提示、已用时间，以及加载期间的后台运行。

玩家存档、店铺家具、顾客、主角、员工、营业状态和会展活动不烘焙进固定地图。运行时仍按当前会话初始化。开发用同步生成入口保留原有生成逻辑，缺失或不兼容的地图缓存也有生成回退路径。

## 控制资源体积

- 道路和建筑的固定网格提前保存；逐个模型按顶点属性、边界和三角形内容计算散列，完全相同的模型只保存一次。
- 树林按原有树形、高度、随机种子生成共用模型，每个实例只保存模型引用、位置和颜色分组；不保存整片树林重复展开后的顶点。
- 树林摆放数据使用独立二进制资源，多次引用不随地图实例化重复复制。
- 建筑窗框、屋顶瓦片、花草和道路绿化也按共用部件与变换记录保存，运行时按原材质分组合并，并恢复原有投影纹理坐标，避免把每栋楼细节展开后的顶点重复存储。
- 网格、材质和程序贴图保存为共用资源；材质、贴图、灯光参数沿用现有逻辑。
- 小于 64 世界单位的模型使用低档网格存储压缩，不减面；大型连续道路网格保留原精度，避免道路接缝出现量化偏差。低档存储压缩有轻微数值精度变化，不等同于无损压缩。
- 运行时仍按原有空间分块合并树林模型，保持分块剔除和绘制批次，避免每棵树增加多个独立游戏对象。
- 最终发布包体和加载速度需要在新包中测量；编辑器缓存文件大小不能直接当成最终包体增量。

## 交互与光照

预生成地图记录门店 ID、入口、标签、营业/关门物件、室内外切换对象、灯光和道路坡道信息。运行时恢复门店点击标记、道路高度查询、昼夜发光材质注册，以及赛车起跑灯和动态车辆容器。会展的动态展厅按当前游戏会话重新初始化。场景招牌字体在运行时使用对应平台和语言的字体。

## 版本与试玩隔离

`CityMapBaker` 通过源码与资源指纹判断缓存是否过期，运行时另外核对地图布局散列、缓存格式版本和试玩标记。Windows 构建选择完整地图；现有 WebGL 试玩入口选择第一阶段地图，沿用试玩的街区和道路限制。生成目录只保留当前构建所需的一个版本，避免完整地图资源被一起带进试玩包。

生成目录为 `Assets/Generated/CityBake`，已加入 Git 忽略。Git 保存生成工具和地图来源，构建时重建资源，不提交重复的大型模型数据。生成失败会阻止构建，不能把未完成的地图缓存当成成功结果。

## 资源生成记录

完整地图生成记录：3,941 个保存的独有网格、约 124.6 万个共用模型顶点、156,086 条树林部件摆放记录。这里是存储量，不是运行时完整场景的面数；实例化后的细节仍保留。

当前两份主要缓存资源合计约 139.1 MB 源文件，单独用 Deflate 压缩约 23.7 MB。此数值只用于资源体积估算，不是 Unity 最终发布包的增量，也不包含对启动耗时的保证。发布包需要另行授权构建后再核对。

## 首次场景显示顺序

开始新游戏或首次读档时，加载页由加载协程单独管理，清理普通窗口不会提前关闭它。加载页保持在开局介绍和教学界面之上，直到当前住所/门店的显隐、家具、角色和镜头已同步，再撤下遮罩。加载结束前不推进游戏时间，也不响应游戏移动输入，避免先露出室外地图、下一帧再切回家中的闪现。

## HUD 消息避让任务卡

左侧临时消息不再使用固定纵坐标。消息区域根据当前任务卡实际下边缘排列，保留 12 个界面单位的间距；任务文字/进度改变、任务卡隐藏、顶部功能栏折叠和窗口尺寸改变时重新定位，避免覆盖任务正文及操作按钮。保留原有消息数量、停留时间和历史通知入口。

## 开局煮饭与打包提示

首次做饭与日常电饭煲使用同一套等待界面，删除教学的“等到饭好”跳时按钮。正在煮饭时，电饭煲窗口不再持有自动暂停，显示实时剩余分钟、预计煮好时刻和进度条；关闭窗口后也继续煮，手动暂停和其他暂停窗口仍按原规则生效。饭好后自动切换到吃饭与打包界面，恢复正常窗口暂停。等待阶段隐藏强制高亮遮罩，避免挡住正常界面；饭好后继续吃饭/打包教学。

打包完成提示精简为两句，仅保留饭点或饿时自动吃、冰箱暂停保质期倒计时，并用强调样式标出操作关键词。
