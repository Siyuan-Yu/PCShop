# 资产页面、收支来源与连续物业地图

## 入口

顶栏“经营”改为“资产”，快捷键仍为J。资产按“经营中的店铺”“我的物业”“车产”分为三页。原收支、物业和单店财务入口统一指向前两页，不再生成五项跨功能导航。车产是2026-11-07新增：只有进入车产后才显示四区及“小电驴 → 三轮车 → 轿车”分类，查看车辆、已购和租用车位及其费用；公共车库建筑本身不作为玩家物业。详见[车库与车位](85-regional-garages-and-parking-spaces.md)。

## 经营中的店铺

左侧依次按街区、业态、门店选择，支持全店、街区、业态或单店汇总。右侧显示最近7个游戏日的收入、支出、收支差额与每日双折线；下方每家店有金额和小走势。

街区和店型均支持独立展开/折叠。点击箭头只切换该组显示，点击名称切换统计范围；折叠不会更改右侧正在看的报表。同一会话保留各组折叠状态，切换测试档或游戏进度后重置。

金额下方直接列出主要来源：商品销售、装机交付款、进货、工资、租金、运输、装修等，以实际有记录的分类为准。超过3项时合并显示其余金额，完整分类明细通过按钮查看。

数据来自明确归属门店的经营流水。自营物业维护费按物业ID归入对应店；新购买装修升级，以及明确送到店铺的家具付款，补齐门店归属。借款、押金、产权买卖、投资和内部资金划转不冒充经营收入。进货付款计入本期现金支出，差额不代表库存销售利润。

托管门店另记录最多31日的真实收入、变动成本、工资与租金结算，保存在门店数据中；资金留在店内周转金时也会显示营业额。总部补足固定费用不会再次计作一笔支出。二手车行的收车、检测、整备和成交记录明确归属车行。已经发生但没有历史记录的托管营业额不伪造七天走势。

## 我的物业

住宅和商铺直接以真实建筑方块展示，不再用数字标记替代。已购买为金色，实际租用为蓝色，其他建筑保持灰绿。颜色依据产权、门店租约、住宅租约及已签待交房租约判断；自有物业优先于租用状态，不重复归类。

每个建筑方块都可点击，包含完全不属于玩家的建筑。弹出地图内浮窗，显示名称、街区、产权或租用状态、相关售价与租金等基本信息；公共/专用场所明确说明不开放普通房产租购。浮窗随镜头移动定位并限制在地图内，拖动地图不会误选建筑。

右侧分“我拥有的”和“我租的”，列出真实资产或有效租约；分别汇总应收、应付月租。单击列表只选中并显示信息，双击才平滑定位聚焦；单击不会重建整张列表，以保留双击识别。购入住宅、自营商铺、租赁门店、租住住宅及待交房商铺按各自实际状态显示。

整页只有一个城市绘图实例，由权威城市的道路、湖岸和建筑坐标构建。全城与片区按钮用约0.7秒平滑移动、放大同一镜头；其他区域未被删掉或替换。支持滚轮和加减缩放、拖动，缩放范围0.85—8倍；双击物业列表聚焦对应建筑，单击建筑查看浮窗。

建筑保持真实位置和外形，不挪开方块或创建数字标签。点击判断按旋转后的实际占地计算，缩远时给予少量点击容差。地图只在用户操作或镜头动画时更新，不持续生成世界截图，不启动第二个3D场景，也不移动玩家。

应收租金按实际用途计算，自住、自营及无实际租户的住宅为0；托管商业出租扣15%管理与空置折损。买卖、出租及搬家仍在负责该片区的中介办理，资产页可直接导航并选中对应商铺或住宅。

## 其他功能归位

- 顶栏新增独立“采购”；商品补货、在途订单、直供协议和直供账款位于该窗口。门店多时用选择列表切换收货店。
- 企业采购订单从电脑店订单页进入；保留完整接约、履约与终止流程。
- 托管店管理从资产门店行进入；开设托管店和筹建园区在中介保留明确入口。
- MCN工作室管理在社区MCN提供入口，园区已有入口继续保留；各管理窗口固定自身业务，不再受另一个窗口所选标签影响。
- 证券买卖移至手机“证券”App，可在应用商店下载安装。作弊预置拥有智能手机时自动装好；交易后端也检查App权限。家庭大屏可跳转手机证券，资产页没有投资页。
